**General interview format expectations (Polish/EU market):**

| Round | Format | What's tested |
|---|---|---|
| 1. Recruiter screen | Phone, 30 min | Basics, motivation, salary range |
| 2. Tech screen | Live coding / theory, 45–90 min | Drill tier topics, basic problem-solving |
| 3. Pair / take-home | 1–4 hr | Real-world coding shape |
| 4. System design (mid+) | 60–90 min | HLD case studies — see `system_design_hld_high_level_design/` |
| 5. Behavioral / culture | 45–60 min | STAR-format stories — see `behavioral_leadership/` |
| 6. Final / leadership | 30–60 min | Trade-offs, prior incidents, team direction |
