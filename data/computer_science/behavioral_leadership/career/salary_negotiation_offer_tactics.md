### Salary Negotiation & Offer Tactics

**Definition:** the offer is the **starting point**, not the final number. Companies expect negotiation; not negotiating leaves money on the table. Approach with **research + leverage + reasoned counter** — not emotion or ultimatums.

**The three-step framework:**

| Step | Detail |
|---|---|
| 1 | **Don't give a number first** — deflect to range |
| 2 | **Receive offer, ask for time** — 3–5 business days |
| 3 | **Counter with specific number + reasoning** — anchored on data |

**Step 1 — Avoid anchoring against yourself:**

```
Recruiter: "What are your salary expectations?"

You: "I'd like to understand the full scope of the role first.
      What's the compensation range for this level?"

If pressed:
"Based on my research and recent offers, I'd expect total compensation
in the range of $X–$Y for this level. I'm flexible based on the full package."
```

| Property | Detail |
|---|---|
| First number anchors negotiation | Whoever says first usually loses |
| Use a range, not a point | Wider room |
| Tie to "research" | Defensible position |
| If forced to commit | Aim higher than your minimum |

**Step 2 — Time to evaluate:**

```
"Thank you, I'm excited about the opportunity. I'd like a few days
to review the full package. Can I get back to you by [date]?"
```

| Property | Detail |
|---|---|
| Always ask for time | 3–5 business days |
| Never accept on the spot | Even if it's the perfect offer |
| Use the time to evaluate alternatives | Compare with competing offers |
| Use the time to consult mentors | External perspective |

**Step 3 — Counter with reasoning:**

```
"I'm very excited about [company] and this role. After reviewing the offer,
I'd like to discuss compensation. Based on [competing offer / market data /
my experience in X], I was hoping for [specific number]. Is there flexibility
on [base / equity / signing bonus]?"
```

| Property | Detail |
|---|---|
| Lead with enthusiasm | Reaffirm interest |
| Reference data, not feelings | Defensible |
| Specific ask, not "more" | Clear target |
| Identify which lever is flexible | Helps recruiter help you |

**Components of total compensation (TC):**

| Component | Negotiable? | Notes |
|---|---|---|
| **Base salary** | Medium | Banded by level; some flex |
| **Signing bonus** | **High** | One-time; easiest to bump |
| **RSU / equity grant** | High | At public co; varies by year |
| **Annual bonus target** | Low | Usually fixed by level |
| **Refresh equity** | Medium | Annual; varies by company |
| **Start date** | High | Negotiate gap for rest |
| **Level / title** | Low–Medium | Hard but highest long-term impact |
| **Remote / hybrid** | Medium | More flexible post-2020 |
| **Vacation days** | Medium | Often standardized |
| **Relocation package** | Medium | If applicable |

**TC formula:**

```
Total Comp = Base + (Equity ÷ vesting years) + Annual Bonus + (Signing ÷ years)

Example: $200k base + $400k RSU/4yr + $30k bonus + $30k signing/4yr
       = $200k + $100k + $30k + $7.5k
       = ~$337.5k/year over 4 years
```

**Research sources:**

| Source | Detail |
|---|---|
| **levels.fyi** | Best for Big Tech band data |
| **Glassdoor** | Wider company coverage, less precise |
| **Blind** | Anonymous chat; recent offers; salary verification |
| **Paysa / SalaryExpert** | Aggregators |
| **Network** | Friends in the industry, recruiters |

**Competing offers — the strongest lever:**

```
"I have an offer from [Company B] at [higher number]. I'd prefer to join
[your company] because [genuine reason]. Can we close the gap on compensation?"
```

| Property | Detail |
|---|---|
| You don't need to share exact numbers | Range is fine |
| Verbal offers are leverage too | Even before written |
| **Never lie** about competing offers | Recruiters talk; reputation damage |
| Use it as a deadline driver | Forces movement |
| Multiple offers compound leverage | Each one strengthens the next |

**Equity specifics:**

| Property | Detail |
|---|---|
| **Vesting schedule** | 4-year, 1-year cliff is standard (Big Tech) |
| **Refresh / annual grants** | Some front-load year 1; some level year 1–4 |
| **RSU value** | Multiply by current stock or current 409A |
| **ISO vs NSO** (startups) | Tax implications differ |
| **Liquidation preference** | Investors get paid first if startup sells low |
| **Strike price + exercise window** | Cost to exercise + how long after leaving |

**Negotiating equity (startups):**

| Lever | Detail |
|---|---|
| Number of options | Negotiable |
| Strike price | Usually fixed (409A) |
| Vesting schedule | Sometimes flexible |
| Acceleration on change-of-control | Important — often one's biggest value |
| Early exercise | Can save tax |
| Extended exercise window | More than 90 days post-departure |

**When to push further:**

| Situation | Push? |
|---|---|
| First offer is at lower end of range | Yes |
| Have a competing offer | Yes |
| Recruiter says "limited flexibility" | One more attempt with reasoning |
| You've gone back-and-forth 2–3 times | Stop |
| Recruiter says "this is top of band" | Try level adjustment instead |
| The offer is genuinely competitive + you're happy | Don't push for principle |

**When NOT to push:**

| Signal | Don't push |
|---|---|
| Offer is at top of range | Acknowledge and accept |
| 3+ rounds of counter exhausted | Diminishing returns |
| You'd take it anyway | Don't kill the relationship |
| Cash-strapped startup | Look at equity / role instead |
| Very different role — career step | Long-term value matters more |

**Common scripts:**

**Asking about leveling:**
> "Based on the scope of work I'd be doing, this looks more like a [next level] role. Could you walk me through how you arrived at the level?"

**Pushing on signing:**
> "The base is solid; would there be flexibility on the signing bonus? I'd be leaving an unvested equity tranche behind."

**Pushing on equity:**
> "I'd like to understand if there's flexibility in the RSU grant. The base meets my expectations, but the equity is below the [levels.fyi p75] for this level."

**Closing the deal:**
> "If you can move the [base / equity / sign-on] to [number], I'm ready to sign today."

**Negotiation traps:**

| Trap | Avoid |
|---|---|
| Lying about offers | Reputation damage |
| Ultimatums on minor differences | Sounds entitled |
| Negotiating with the hiring manager (not recruiter) | Awkward |
| Accepting then trying to renegotiate | Burns bridges |
| Asking for everything at once | Unclear priority |
| Negotiating after signing | No leverage |
| Negotiating only base when sign-on is the lever | Missing easier wins |
| Not getting it in writing | Verbal can change |

**Common mistakes:**

| Mistake | Effect |
|---|---|
| Sharing your current salary too early | Anchors you low |
| Showing too much enthusiasm | "They'd take any offer" |
| Showing too little enthusiasm | Recruiter assumes you'll walk |
| Negotiating without a competing offer | Less leverage |
| Pushing past 2–3 rounds | Sours relationship |
| Not reading the contract | Surprises later (non-compete, IP, ugly clauses) |
| Forgetting to negotiate start date | Free vacation |

**Final-decision checklist:**

| Item | Detail |
|---|---|
| Total comp meets target | Number works |
| Role + scope is clear | Role description matches |
| Manager / team feels like a fit | Did 1:1s pre-decision |
| Tech / product / mission excite you | Long-term motivation |
| Growth path documented | Career progression |
| Reference checks done both ways | Glassdoor, Blind, your network |
| Contract reviewed (lawyer if equity-heavy) | Clauses understood |
| No outstanding red flags | Manager, comp, location |

**Rule of thumb:** **Always negotiate.** Counter with **data, not emotions**. The **signing bonus** is the easiest lever; **competing offers** are the strongest. **Never accept on the spot** — always ask for 3–5 days. The worst that happens is "this is our best offer" — they won't rescind. Get every change **in writing** before signing.
