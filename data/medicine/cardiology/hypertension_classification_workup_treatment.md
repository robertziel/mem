### Hypertension

**ACC/AHA 2017 classification:**

| Category | Systolic | Diastolic |
|----------|----------|-----------|
| Normal | <120 | and <80 |
| Elevated | 120-129 | and <80 |
| Stage 1 | 130-139 | or 80-89 |
| Stage 2 | ≥140 | or ≥90 |
| Hypertensive urgency | ≥180/120 | no end-organ damage |
| Hypertensive emergency | ≥180/120 | **+ end-organ damage** |

**Targets (ACC/AHA, simplified):**

| Population | Goal |
|------------|------|
| Most adults | <130/80 |
| Older adults (≥65) | <130 if tolerated |
| DM, CKD, ASCVD | <130/80 |

**Initial workup — every new HTN:**

| Test | Looking for |
|------|-------------|
| BMP, lipid, A1c | Renal, lipid, DM |
| UA + ACR | Proteinuria, hematuria |
| ECG | LVH, prior MI |
| TSH | Hyper/hypothyroid |

Repeat BP measurements over time. **Confirm** with home BP or ABPM (white coat 15-30%).

**Lifestyle (DASH + exercise + sodium):**

| Intervention | Approx ↓ SBP |
|--------------|--------------|
| Weight loss (10 kg) | 5-10 mmHg |
| DASH diet | 8-14 |
| Salt reduction (<2.4 g Na) | 2-8 |
| Aerobic exercise | 4-9 |
| Alcohol moderation | 2-4 |

**First-line drug choices (ACC/AHA):**

| Drug class | Notes |
|------------|-------|
| Thiazide (chlorthalidone, HCTZ, indapamide) | Cheap, effective; watch K, glucose, uric acid |
| Long-acting CCB (amlodipine) | Edema, gingival hyperplasia |
| ACEi or ARB | First in DM/CKD/HFrEF; not in pregnancy |
| (β-blocker) | **Not first-line** without compelling indication (HF, post-MI, AF) |

Black patients (no CKD/HF) → thiazide or CCB first.
Pregnancy → labetalol, nifedipine, methyldopa, hydralazine.

**Compelling indications (drives drug choice):**

| Condition | Preferred |
|-----------|-----------|
| HFrEF | ACEi/ARB + β-blocker + MRA + SGLT2i |
| Post-MI | β-blocker + ACEi |
| DM with albuminuria | ACEi/ARB |
| CKD | ACEi/ARB |
| AF (rate control) | β-blocker, non-DHP CCB |
| Pregnancy | Labetalol, nifedipine, methyldopa |
| BPH | α-blocker (doxazosin) |

**Secondary HTN — when to suspect:**

| Clue | Cause |
|------|-------|
| Onset <30 or >55, severe, resistant | Secondary suspicion |
| Renal bruit, fibromuscular dysplasia (young woman) | Renovascular (RAS) |
| Hypokalemia + metabolic alkalosis (low renin) | **Primary aldosteronism (Conn)** |
| Episodic HTN, sweating, palpitations, headache | **Pheochromocytoma** |
| Truncal obesity, striae, easy bruising | Cushing |
| Snoring, daytime somnolence | OSA |
| Differential BP arms / leg | Coarctation |
| Renal failure | CKD |

**Resistant HTN (uncontrolled on 3 meds incl. diuretic):**
- Confirm adherence + correct technique
- Add **MRA** (spironolactone) — best evidence
- Screen for secondary causes
- Optimize lifestyle

**Hypertensive emergency — pick the drug to the organ:**

| End-organ injury | Drug |
|------------------|------|
| Aortic dissection | Esmolol (HR first), then nitroprusside |
| Pulmonary edema (HFrEF) | Nitroglycerin + loop diuretic |
| Stroke (ischemic) | Permissive HTN; treat only if >220/120 or t-PA candidate |
| Stroke (hemorrhagic) | SBP 130-140 (nicardipine, labetalol) |
| Eclampsia | Labetalol, hydralazine, magnesium |
| Pheochromocytoma | **α before β** (phentolamine) |
| Renal failure | Fenoldopam, nicardipine |

Lower BP **gradually** (~25% in first hour) except for dissection (faster), eclampsia, pulmonary edema.

**Hypertensive urgency** (no end-organ damage): **Don't** rapidly lower in ED — restart/uptitrate oral meds, follow up.

**Common gotchas:**
- Don't use ACEi + ARB together (no benefit, more AKI/hyperK)
- **ACEi/ARB contraindicated in pregnancy** (renal dysgenesis, oligohydramnios)
- Thiazide → ↑ Ca, ↑ uric acid, ↑ glucose, ↓ K, ↓ Na
- Spironolactone → gynecomastia (eplerenone alternative)
- Cocaine HTN: avoid β-blocker monotherapy (unopposed α); use phentolamine or α + β
- White-coat HTN ≈ 15-30% of office HTN — confirm with ABPM/HBPM before lifelong drug

**Rule of thumb:** Most adults: <130/80. Pick agents from thiazide/CCB/ACEi-ARB. Compelling conditions drive drug class. Pregnancy and pheo invert the usual rules. Resistant HTN → spironolactone + secondary screen.
