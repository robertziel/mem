### Heart Failure

**HFrEF vs HFpEF:**

| Feature | HFrEF (systolic) | HFpEF (diastolic) |
|---------|------------------|-------------------|
| EF | ≤40% | ≥50% |
| LV problem | Can't contract | Can't relax/fill |
| Cause | Ischemic, dilated CM, valvular, viral | HTN, age, DM, obesity, HCM, restrictive |
| Wall | Thin, dilated | Thick, stiff |
| Survival benefit drugs | Many (see below) | **Few** — only SGLT2i so far |

HFmrEF (mid-range, EF 41-49%) treated more like HFrEF.

**NYHA functional class:**

| Class | Symptoms |
|-------|----------|
| I | No limit on ordinary activity |
| II | Slight limit, comfortable at rest |
| III | Marked limit, symptoms with less than ordinary |
| IV | Symptoms at rest |

**ACC/AHA stages (vs NYHA which is symptom-only):**

| Stage | Description |
|-------|-------------|
| A | At risk (HTN, DM, ASCVD), no structural disease, no symptoms |
| B | Structural disease (low EF, prior MI, valve), no symptoms |
| C | Structural disease + current/prior symptoms |
| D | Refractory, end-stage |

**Acute HF presentation (warm/cold × wet/dry):**

| | Wet (congested) | Dry (no congestion) |
|---|-----------------|---------------------|
| Warm (perfused) | Decompensated HF — diurese, vasodilator | Compensated — optimize meds |
| **Cold (hypoperfused)** | **Cardiogenic shock** — inotropes, mechanical support | Hypovolemia / advanced HF — consider inotrope, transplant eval |

**Diagnostic clues:**

| Test | Finding |
|------|---------|
| BNP / NT-proBNP | ↑ with stretch; **NPV high** to rule out HF |
| CXR | Cardiomegaly, Kerley B, cephalization, effusions, "bat-wing" pulm edema |
| Echo | EF, wall motion, valves, diastolic function (E/A, E/e′), LV mass |

BNP rises with renal failure, A-fib, sepsis, age. Falls with **obesity**.

**HFrEF "Four Pillars" of GDMT (mortality benefit):**

| Class | Examples | Notes |
|-------|----------|-------|
| 1. ARNI / ACEi / ARB | Sacubitril-valsartan > ACEi/ARB | Hold ACEi 36h before starting ARNI (angioedema) |
| 2. β-blocker | Carvedilol, metoprolol succinate, bisoprolol | Start low, go slow; **3 evidence-based agents** only |
| 3. MRA | Spironolactone, eplerenone | Watch K, Cr |
| 4. SGLT2 inhibitor | Dapagliflozin, empagliflozin | Mortality benefit even without DM |

Add: loop diuretic for symptoms (no mortality benefit), **hydralazine + isosorbide** in Black patients or ACEi-intolerant, **ivabradine** if HR≥70 on max β-blocker, **digoxin** for symptom control.

**Devices:**

| Device | Indication |
|--------|-----------|
| ICD | EF ≤35% + NYHA II-III + on GDMT ≥3 mo (primary prevention) |
| CRT | EF ≤35% + LBBB + QRS ≥150 ms + NYHA II-IV |
| LVAD / transplant | Stage D refractory |

**Acute decompensation triage:**
- Diurese (IV loop)
- Vasodilator (NTG) if SBP>100 — relieves preload + afterload
- Avoid β-blocker initiation in acute decompensation (can resume later)
- Inotrope (dobutamine, milrinone) for cardiogenic shock — bridge only, ↑ mortality long-term

**HFpEF — what works:**

| Therapy | Evidence |
|---------|----------|
| **SGLT2 inhibitor** | Mortality + HF hospitalization benefit |
| Diuretic for congestion | Symptomatic |
| Treat HTN, AF, DM, obesity | Indirect |
| MRA (spironolactone) | Mixed (TOPCAT subgroup) |
| ACEi/ARB/β-blocker | **No clear mortality benefit** |

**Common gotchas:**
- **Don't start β-blocker** during acute decompensation; resume euvolemic
- **ARNI angioedema risk** — wash out ACEi 36h
- **MRA hyperkalemia** — monitor K and Cr after start and dose change
- **SGLT2i can cause euglycemic DKA** in T1DM/insulin-deficient T2DM; hold periop
- BNP can be **misleadingly normal** in obesity → use NT-proBNP cautiously
- Diuretic resistance: try **thiazide + loop combo**, IV bolus, drip, or sequential nephron blockade

**Rule of thumb:** HFrEF = 4 pillars (ARNI/β-blocker/MRA/SGLT2i) + diuretic for symptoms. HFpEF = SGLT2i + diuretic + treat comorbidities. Ladder up GDMT before considering ICD/CRT.
