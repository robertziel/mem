### Imaging Modalities — When to Use What

**Quick comparison:**

| Modality | Mechanism | Strengths | Weaknesses | Radiation |
|----------|-----------|-----------|------------|-----------|
| **X-ray** | Ionizing | Cheap, fast, widely available | Limited soft-tissue, summative | Low |
| **CT** | Ionizing | Excellent anatomy, fast, widely available | Radiation, contrast nephropathy, allergy | **Moderate-high** |
| **MRI** | Magnetic + RF | **Best soft-tissue** detail, no radiation | Slow, expensive, claustrophobia, contraindications (pacemaker, metal, implants — many are now MRI-safe) | None |
| **Ultrasound** | Sound waves | Real-time, no radiation, bedside, **safe pregnancy** | Operator-dependent, poor through bone/air | None |
| **Nuclear medicine** | Radiotracers | Functional imaging | Resolution, radiation, time | Variable |
| **PET-CT** | FDG glucose uptake | Metabolic activity | Cost, glucose dependent (DM affects) | High |

**By body region:**

| Region | First-line |
|--------|-----------|
| Chest pain (cardiac) | ECG → CXR; CT angio (PE, dissection); coronary CTA / cath; echo |
| Acute abdomen | CT abd/pelvis with IV contrast |
| RUQ pain | **US first** (gallbladder, biliary), then HIDA / MRCP |
| Pancreas / pancreatitis | CT (severity, complications); MRCP for biliary |
| Renal stones | **Non-contrast CT** (best); US in pregnancy/young |
| Stroke | **Non-contrast CT first** (rule out bleed) → CTA/MRA, MRI for tissue at risk (DWI/perfusion) |
| Head trauma | Non-contrast CT |
| **Aortic dissection** | CT angiography chest/abd |
| **PE** | CTPA |
| Bone fracture | X-ray; CT for complex; MRI for occult fracture / stress / marrow |
| Spine | MRI for cord / nerve root / disc; CT for bony detail / fracture; X-ray initial screening |
| Joints | X-ray first; MRI for soft tissue, ligament, meniscus, cartilage |
| Pediatric appendicitis | **US first** (radiation-sparing); MRI alternative |
| Pregnant abdominal pain | **US first**, then MRI without contrast if needed |
| Brain tumor | **MRI with gadolinium** |
| Demyelinating disease (MS) | **MRI brain + spine with gadolinium** |
| Cancer staging | CT (most), PET-CT, MRI, bone scan |
| Suspected DVT | Doppler US |
| Cardiac function | Echocardiogram (TTE/TEE), cardiac MRI |
| Pelvic mass | Pelvic / transvaginal US first |

**CT contrast:**

| Type | Use |
|------|-----|
| **IV iodinated** | Vasculature, abscess, mass enhancement (lesion characterization), most acute abdomen |
| **Oral** | Bowel contents, anastomotic leak, fistula |
| **Rectal** | Pelvic abscess, fistula |
| **Non-contrast** | Stones, hemorrhage, calcification, RT planning |

**Contrast allergies / reactions:**

| Type | Detail |
|------|--------|
| Mild | Hives, itch — antihistamine |
| Moderate | Bronchospasm, laryngeal edema — epinephrine, steroids |
| Severe | Anaphylaxis — full anaphylaxis protocol |
| **Pre-medication** for prior contrast reaction | Steroid (50 mg pred at 13, 7, 1h before) + diphenhydramine 1h before |

**Contrast-associated AKI (CIN/CA-AKI):**

| Risk | Mitigation |
|------|-----------|
| Pre-existing CKD (especially eGFR <30) | Hydrate (isotonic saline) |
| DM, dehydration, HF | — |
| High contrast volume | Lowest dose |
| **Hold nephrotoxins** before / after if possible (NSAIDs) | — |
| Metformin | Hold periop if eGFR <60; restart 48h after if normal Cr |

NAC has weak / no evidence; routine bicarbonate not needed beyond saline.

**Gadolinium (MRI contrast):**

| Issue | Detail |
|-------|--------|
| **Nephrogenic systemic fibrosis (NSF)** | **eGFR <30** — avoid older agents; use group II agents (gadobutrol, gadoteridol, gadoterate) which carry minimal/no risk |
| Allergy | Less common than iodinated |
| Pregnancy | Generally avoid; case-by-case |
| Brain deposition | Linear agents — limit use of older linear agents |

**Pediatric / pregnant:**

| Setting | Approach |
|---------|----------|
| Pregnancy | **US and MRI without gadolinium** are safest; avoid CT/X-ray when possible; if necessary, single low-dose imaging unlikely teratogenic but counsel; lead shielding |
| Pediatric | US first when possible; MRI without sedation when able; ALARA principle for CT |

**Radiation dose comparison (approximate):**

| Modality | Dose (mSv) |
|----------|-----------|
| CXR | 0.1 |
| Mammogram | 0.4 |
| Head CT | 2 |
| Chest CT | 7 |
| **Abdominal CT** | 8-10 |
| **PET-CT** | 25 |
| Background annual | ~3 |

**Cumulative radiation matters** — cancer risk modeled linearly per dose; minimize repeat scans.

**FDG-PET — when?**

| Use |
|-----|
| Cancer staging (most) |
| Monitoring response to therapy |
| Restaging after treatment |
| Fever of unknown origin (selected) |
| Cardiac viability (FDG, rubidium) |
| Dementia evaluation (FDG distinguishes Alzheimer from FTD; amyloid PET available) |

Glucose dependent — DM patients need preparation.

**Bone scan (Tc-99m MDP):**

| Indication |
|------------|
| Bone metastases (especially blastic — prostate, breast) |
| Osteomyelitis (with WBC scan) |
| Stress fracture (early, before X-ray changes) |
| Paget disease, complex regional pain syndrome |

**Common gotchas:**
- **Don't delay non-contrast CT for stroke** waiting for labs/access
- **Pregnancy + abdominal pain** → US first (RUQ/RLQ), MRI if equivocal — avoid CT/X-ray when possible
- **CT for kidney stones** = non-contrast (contrast obscures stones)
- **MRI safety**: pacemakers (most newer ones MRI-conditional), aneurysm clips, cochlear implants, ocular foreign bodies, claustrophobia
- **Iodine allergy" myth** — shellfish allergy doesn't predict contrast reaction; previous contrast reaction does
- **Metformin holds** for contrast: only if eGFR borderline; restart 48h post
- **Cancer surveillance** — be deliberate about cumulative radiation, especially in young / Lynch / Li-Fraumeni patients

**Rule of thumb:** Match modality to question. US first for pregnancy / pediatric / RUQ / pelvic / vascular. CT for trauma / PE / dissection / acute abdomen / stones (non-contrast). MRI for brain / spine / soft tissue / cancer characterization. Watch radiation cumulative dose; gadolinium in low-eGFR — group II only.
