### Chest X-Ray — Systematic Interpretation

**Always check first:** patient identifiers, date, projection (PA vs AP, lateral, supine vs upright), penetration, rotation, inspiration.

**Systematic ABCDEF approach:**

| Letter | Item |
|--------|------|
| **A** | Airway — trachea midline, deviation, intubation tube position |
| **B** | Breathing — lung fields (zones, peripheral, apices, costophrenic angles) |
| **C** | Cardiac — silhouette, size (CT ratio <0.5 on PA), borders, mediastinum |
| **D** | Diaphragm — flat (COPD), elevation, free air below |
| **E** | Effusion / Edges (pleura, pneumothorax) |
| **F** | Foreign bodies / Findings (lines, tubes, devices, bones, soft tissue) |

**PA vs AP:**

| Feature | PA | AP |
|---------|-----|-----|
| X-ray source | Behind, film in front | In front, film behind |
| Heart size | Accurate | **Magnified** |
| Use | Outpatient / standing | Bedside / supine / unable to stand |

**Common findings — pattern recognition:**

| Finding | What it suggests |
|---------|------------------|
| Lobar consolidation | Bacterial pneumonia (esp. Strep pneumo) |
| Multifocal patchy | Atypical / viral / aspiration |
| Cavitary upper lobe | TB, Klebsiella, anaerobes (aspiration), septic emboli, fungal |
| Bilateral interstitial | PJP, viral, ILD, atypicals, cardiogenic edema |
| **Kerley B lines, cephalization, bat-wing** | Pulmonary edema (HF) |
| Pleural effusion | Blunt costophrenic angle (>200 mL) |
| **Tension pneumothorax** | Mediastinal shift away, depressed diaphragm, hyperlucent — **clinical diagnosis, don't wait for CXR** |
| Pneumothorax | Visceral pleural line, no markings beyond |
| **Free air under diaphragm** | Bowel perforation |
| Lobar collapse | Volume loss, hilum/diaphragm shift toward, mediastinal shift toward |
| Mass | Density, location, calcification |
| Hilar adenopathy | Sarcoid, lymphoma, infection, malignancy |
| Egg-shell calcified hilar nodes | Silicosis |
| **Widened mediastinum** | Aortic dissection, lymphoma, tumor, hematoma |
| Boot-shaped heart | Tetralogy of Fallot (RVH + small PA) |
| Snowman | TAPVR |
| "3 sign" / aortic notching | Coarctation |
| Rib notching | Coarctation (collateral intercostals) |
| Steeple sign | Croup (laryngotracheitis) on AP neck |
| Thumbprint sign | Epiglottitis on lateral neck |
| Honeycombing | End-stage ILD |
| Reticulonodular | ILD, sarcoid, infection |
| Eggshell-thin | Bullae (emphysema, ruptured) |
| Cannon-ball mets | Lung mets (testicular, renal, choriocarcinoma classic) |

**Lobar collapse patterns:**

| Lobe | Sign |
|------|------|
| RUL | Elevated minor fissure, "S sign of Golden" if mass causing it (lung cancer) |
| RML | Silhouettes right heart border on PA, wedge on lateral |
| RLL | Silhouettes right hemidiaphragm, retrocardiac density |
| LUL | "Veil" over left hemithorax, anterior shift |
| LLL | Triangular density behind heart ("silhouette of heart unobscured but veil behind") |

**Silhouette sign** — loss of normal border because adjacent structures have similar density (water density) → localizes pathology to the abutting lobe.

**Lines and tubes:**

| Device | Correct position |
|--------|------------------|
| ETT | 2-7 cm above carina (carina at T4-T5) |
| Central venous catheter | Tip in SVC just above right atrium |
| PA catheter | Tip in pulmonary artery main / RPA branch |
| NG tube | Below diaphragm, tip in stomach (not curled in esophagus, not in airway) |
| Chest tube | Pleural space; sideholes within thorax |
| Pacemaker leads | RA appendage, RV apex, ± LV via coronary sinus (CRT) |
| ICD generator | Pectoral pocket; lead tips as above |

**Cardiac silhouette:**

| Border | Adjacent chamber |
|--------|------------------|
| Right border | Right atrium |
| Inferior right | RV (silhouette with diaphragm) |
| Left upper | Aortic knob, then PA, then LA appendage |
| Left lower | LV |

Cardiomegaly (CT ratio >0.5 on PA): HF, cardiomyopathy, pericardial effusion.

**"Hidden" zones to deliberately check:**

| Zone | What can be missed |
|------|-------------------|
| Lung apices | Pancoast tumor, TB, pneumothorax |
| Costophrenic angles | Small effusion |
| Behind heart (retrocardiac) | LLL pneumonia, hiatal hernia, LA enlargement |
| Below diaphragms | Free air, masses, hepatic findings |
| Soft tissue | Subcutaneous emphysema, mastectomy, masses |
| Bones | Fractures, lytic / blastic lesions, scoliosis |

**Common gotchas:**
- **Tension pneumothorax = clinical diagnosis** — don't wait for CXR before decompression
- **Supine CXR** can hide free air, effusion, pneumothorax (anterior collection)
- "Deep sulcus sign" on supine = pneumothorax (anterior air, costophrenic angle deeper)
- "Silhouette sign" localizes opacity to adjacent lobe
- **Calcified granuloma** ≠ active TB — old infection
- **Single nodule on CXR** → CT for characterization (Lung-RADS)
- **Pleural effusion vs consolidation** — meniscus + density layers in dependent area = effusion
- **Subdiaphragmatic free air** in upright film — perforation; supine may obscure (look for falciform ligament, double-wall sign)

**Rule of thumb:** Always systematic ABCDEF. Compare with priors. Lateral helps localize. Most "missed" findings are at lung apices, behind the heart, costophrenic angles, and below diaphragm. Tension pneumo and free air can save lives — check actively.
