### Cell Organelles

**At a glance:**

| Organelle | Function | Disease/clue |
|-----------|----------|--------------|
| Nucleus | DNA storage, transcription | Inclusions in viral infection (CMV, HSV) |
| Nucleolus | rRNA synthesis, ribosome assembly | Prominent in active cells |
| Rough ER | Protein synthesis (secreted/membrane) | Plasma cells, pancreas exocrine |
| Smooth ER | Lipid synthesis, detox, Ca++ store | Hepatocyte, steroidogenic, muscle (SR) |
| Ribosome | Translation | Free vs RER-bound |
| Golgi | Modify, sort, package proteins | I-cell disease (loss of M6P tag) |
| Lysosome | Degradation (acid hydrolases) | Storage diseases (Tay-Sachs, etc.) |
| Peroxisome | Very-long-chain FA β-oxidation, H2O2 | Zellweger, X-ALD |
| Mitochondrion | ATP, apoptosis (cyt c), heme synthesis | mtDNA mutations (MELAS, LHON) |
| Proteasome | Ubiquitin-tagged protein degradation | — |
| Cytoskeleton (microfilaments) | Actin — shape, motility | Cytochalasin |
| Microtubules | Transport, mitosis, cilia | Vinca, taxanes, colchicine |
| Intermediate filaments | Structural | Tumor markers (cytokeratin, vimentin, GFAP) |

**Protein trafficking — secreted protein path:**
```
Ribosome (free) → SRP signal → RER lumen → vesicle → cis-Golgi 
→ medial → trans-Golgi → secretory vesicle → plasma membrane
```

**Lysosomal targeting:** mannose-6-phosphate tag added in cis-Golgi. Defective in **I-cell disease** (enzymes leak out into blood, "inclusion bodies" in cell).

**Mitochondrion features:**
- Double membrane; inner has cristae (↑ surface)
- Own DNA (circular, maternally inherited), ribosomes
- ETC + ATP synthase on inner membrane
- Site of: β-oxidation, TCA, urea cycle (partial), heme synthesis (partial)

**Microtubules — clinically relevant drugs:**

| Drug | Effect | Use |
|------|--------|-----|
| Vinca alkaloids (vincristine) | Inhibit polymerization | Cancer (M-phase) |
| Taxanes (paclitaxel) | Stabilize, prevent depolymerization | Cancer |
| Colchicine | Inhibit polymerization | Gout, FMF |
| Griseofulvin | Disrupts mitotic spindle | Dermatophytes |
| Mebendazole | Helminth tubulin | Antiparasitic |

**Lysosomal storage diseases (selected):**

| Disease | Enzyme | Substrate | Clue |
|---------|--------|-----------|------|
| Tay-Sachs | β-hexosaminidase A | GM2 ganglioside | Cherry-red macula, **no HSM** |
| Niemann-Pick | Sphingomyelinase | Sphingomyelin | Cherry-red, **HSM** |
| Gaucher | Glucocerebrosidase | Glucocerebroside | "Crinkled paper" macros, HSM, bone crises |
| Fabry | α-galactosidase A | Ceramide trihex | X-linked, neuropathic pain, renal, CV |
| Hurler / Hunter | α-iduronidase / iduronate sulfatase | GAGs | Coarse facies, corneal cloud (Hurler only) |

**Common gotchas:**
- Mitochondrial diseases follow **maternal inheritance** (sperm mito don't transmit)
- I-cell disease: lysosomal enzymes elevated in **blood** (because they didn't get tagged for lysosome)
- Cytokeratin = epithelial (ALL carcinomas); vimentin = mesenchymal — first IHC in undifferentiated tumor

**Rule of thumb:** Free ribosome → cytoplasm/nuclear/peroxisomal proteins. RER → secretory/membrane/lysosomal. M6P sorts to lysosome — lose it → I-cell disease.
