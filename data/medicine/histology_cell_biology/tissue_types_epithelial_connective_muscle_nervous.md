### Four Basic Tissue Types

| Tissue | Function | Cell types | Examples |
|--------|----------|-----------|----------|
| Epithelial | Barrier, secretion, absorption | Tightly packed cells | Skin, GI lining, glands |
| Connective | Support, fill, transport | Cells in matrix | Bone, blood, fat, cartilage |
| Muscle | Contraction | Myocytes | Skeletal, cardiac, smooth |
| Nervous | Signal transmission | Neurons + glia | Brain, spinal cord, nerves |

**Epithelial classification (shape × layers):**

| Layers | Squamous | Cuboidal | Columnar |
|--------|----------|----------|----------|
| Simple | Alveoli, endothelium | Kidney tubules, ducts | GI tract, stomach |
| Stratified | Skin (keratin), esophagus | Sweat glands | Conjunctiva (rare) |
| Pseudostratified | — | — | Trachea (ciliated), epididymis |
| Transitional | Bladder (umbrella cells) | — | — |

**Connective tissue subtypes:**

| Type | Matrix | Where |
|------|--------|-------|
| Loose (areolar) | Soft, fibroblasts, mast cells | Beneath epithelia |
| Dense regular | Parallel collagen | Tendons, ligaments |
| Dense irregular | Random collagen | Dermis, organ capsules |
| Adipose | Fat cells | Subcutaneous, visceral |
| Reticular | Reticular fibers | Lymph nodes, spleen, BM |
| Cartilage | Chondrocytes in lacunae | Hyaline (joint), elastic (ear), fibro (disc) |
| Bone | Osteocytes + mineralized matrix | Cortical, trabecular |
| Blood | Liquid plasma + cells | Vasculature |

**Muscle types:**

| Feature | Skeletal | Cardiac | Smooth |
|---------|----------|---------|--------|
| Striations | Yes | Yes | No |
| Nuclei per cell | Multinucleate, peripheral | Single, central | Single, central |
| Control | Voluntary | Involuntary | Involuntary |
| Intercalated discs | No | **Yes** | No |
| Regeneration | Limited (satellite cells) | Very limited | Yes |
| Ca++ source | T-tubules → SR | T-tubules + extracellular | Mostly extracellular |

**Cell junctions (epithelial):**

| Junction | Function | Molecule |
|----------|----------|----------|
| Tight (zonula occludens) | Seal — paracellular barrier | Claudins, occludins |
| Adherens (zonula adherens) | Mechanical connect | E-cadherin (Ca++ dep) |
| Desmosome (macula adherens) | Spot-weld | Desmoglein, desmocollin |
| Hemidesmosome | Cell to basement membrane | Integrin |
| Gap junction | Direct cytoplasmic comm | Connexin (6 → connexon) |

**Pathology recognition pearls:**

| Disease | Junction / molecule lost |
|---------|--------------------------|
| Pemphigus vulgaris | Desmoglein 3 (suprabasal blisters) |
| Bullous pemphigoid | Hemidesmosome (BP180/230) → subepidermal |
| Toxic shock (S. aureus exfoliative toxin) | Desmoglein 1 (superficial) |
| E-cadherin loss | Lobular breast carcinoma, diffuse gastric ca |

**Common gotchas:**
- "Pseudostratified" looks layered but every cell touches the basement membrane
- Transitional epithelium = urinary tract only
- Cardiac muscle has the unique **intercalated disc** (gap junctions + desmosomes — fast electrical + mechanical link)
- Cartilage has no blood supply → slow healing

**Rule of thumb:** Identify by location first, then shape × layers (epithelium) or matrix (connective). Intercalated disc = cardiac. Multinucleate peripheral = skeletal.
