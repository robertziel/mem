### Psoriasis

**Clinical types:**

| Type | Look | Distribution |
|------|------|--------------|
| **Plaque (most common)** | Well-demarcated, **silvery scale** on erythematous plaques; **Auspitz sign** (pinpoint bleeding when scale removed) | Extensor surfaces (elbows, knees), scalp, lumbosacral |
| Guttate | "Drop"-shaped small papules | Trunk; often **post-streptococcal pharyngitis**, young adults |
| Inverse | Smooth, no scale (moist) | Intertriginous (axilla, groin, inframammary) |
| Pustular | Sterile pustules; can be generalized (von Zumbusch — fever, systemic) | Localized or generalized |
| Erythrodermic | >75% body surface erythema; fluid/temperature loss; **emergency** | Diffuse |
| Nail psoriasis | Pitting, oil drop, onycholysis, subungual hyperkeratosis | Fingernails |
| **Psoriatic arthritis** | Asymmetric oligo / poly / DIP / spondylitis / arthritis mutilans; **dactylitis (sausage digit)**, enthesitis | Joints |

**Severity classification:**

| Severity | BSA / clinical impact |
|----------|----------------------|
| Mild | <3% BSA |
| Moderate | 3-10% BSA |
| Severe | >10% BSA or significant impact |

PASI (Psoriasis Area and Severity Index) used in trials; DLQI (quality of life) influences treatment escalation.

**Treatment ladder by severity:**

| Severity | Therapy |
|----------|---------|
| Mild localized | **Topical corticosteroids** (potency by site) ± vitamin D analog (calcipotriene) ± tazarotene; combination products |
| Scalp | Steroid solution / foam, calcipotriene, tar, coal-tar shampoo |
| Face / folds | Tacrolimus, pimecrolimus (avoid potent steroids) |
| Moderate-severe | **Phototherapy (NB-UVB)**, methotrexate, cyclosporine, acitretin (oral retinoid), apremilast (PDE-4 inhibitor) |
| Moderate-severe / refractory | **Biologics** |

**Biologics (revolutionized psoriasis care):**

| Class | Examples | Notes |
|-------|----------|-------|
| TNF-α inhibitors | Adalimumab, etanercept, infliximab, certolizumab | Effective; PsA benefit; HBV / TB screen |
| IL-12/23 | Ustekinumab | Less frequent dosing |
| **IL-17** (very effective for skin) | Secukinumab, ixekizumab, brodalumab, bimekizumab | Avoid in IBD (flare risk); brodalumab carries suicide warning |
| **IL-23** (selective) | Guselkumab, risankizumab, tildrakizumab | High response rates, durable |

**Pre-biologic screen:** TB (PPD/IGRA), HBV serology, HCV, HIV, CBC, LFT.

**Methotrexate pearls:**

| Item | Detail |
|------|--------|
| Dose | 7.5-25 mg weekly + folic acid daily |
| Monitor | CBC, LFTs at start, 1 month, 3 months, then quarterly |
| Avoid | Pregnancy (teratogen), liver disease, alcohol |
| Pneumonitis | Rare but serious — stop drug |

**Triggers / aggravators of psoriasis:**

| Trigger | Note |
|---------|------|
| Streptococcal infection | Especially **guttate** psoriasis |
| Stress | Common flare trigger |
| Trauma / surgery | **Koebner phenomenon** — psoriasis appears at injury sites |
| Drugs | **β-blockers, lithium, antimalarials, IFN-α, NSAIDs** can flare |
| Alcohol, smoking | Flares + reduces treatment response |
| HIV | Severe / refractory presentation |

**Comorbidities (don't miss):**

| Comorbidity | Detail |
|-------------|--------|
| **Psoriatic arthritis** | Develops in 20-30% of psoriasis patients; ask about morning stiffness, dactylitis |
| Cardiovascular disease | ↑ MI/stroke risk independent of traditional RFs (chronic inflammation); aggressive risk-factor management |
| Metabolic syndrome | Obesity, DM, lipids — common |
| **IBD** (Crohn especially) | Co-occurs; influences biologic choice |
| Uveitis | Can occur with PsA |
| Depression / anxiety | High prevalence |
| Liver disease (NAFLD) | Independent association |

**Erythrodermic / pustular psoriasis emergencies:**

| Issue | Action |
|-------|--------|
| Erythrodermic | Hospitalize, fluids, temp regulation, prevent infection; cyclosporine or infliximab acutely |
| Generalized pustular | Same; spesolimab (IL-36R) approved |

**Special situations:**

| Situation | Approach |
|-----------|----------|
| Pregnancy | Topicals (low-mid potency steroid, calcipotriene small areas), NB-UVB; certolizumab (no placental transfer); avoid MTX, acitretin (long teratogenic window — male and female) |
| HIV | UV phototherapy; cautious systemic; ART optimization |
| Breastfeeding | Topicals; some biologics acceptable |
| Children | Mostly topicals; biologics increasingly approved (etanercept, ustekinumab, ixekizumab, secukinumab) |

**Common gotchas:**
- **Don't use systemic corticosteroids** for psoriasis — abrupt withdrawal can precipitate **pustular flare / erythroderma**
- **Auspitz sign** (pinpoint bleeding under scale) is classic for plaque psoriasis
- **Guttate psoriasis** in a teen → ask about strep, treat strep if positive
- **Psoriatic arthritis** can predate or follow skin disease — ask every visit; can be dactylitis-only or enthesitis without obvious arthritis
- **IL-17 inhibitors** can worsen IBD — choose IL-23 or TNF if IBD coexists
- **β-blockers, lithium, antimalarials** are common flare triggers — review meds

**Rule of thumb:** Plaque + silvery scale + extensor + Auspitz = psoriasis. Topicals for mild; phototherapy / MTX / biologic for moderate-severe. Don't give systemic steroids. Always ask about joints, IBD, mood, CV risk. Pre-biologic: TB + HBV/HCV screen.
