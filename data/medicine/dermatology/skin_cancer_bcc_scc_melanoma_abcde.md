### Skin Cancer — BCC, SCC, Melanoma

**Three main types:**

| Type | Frequency | Cell origin | Behavior |
|------|-----------|-------------|----------|
| **Basal cell carcinoma (BCC)** | Most common | Basal layer | **Locally invasive, rarely metastasizes** |
| **Squamous cell carcinoma (SCC)** | 2nd most common | Keratinocyte | Locally invasive, **can metastasize** (esp. lip, ear, immunocompromised) |
| **Melanoma** | Less common | Melanocyte | **High metastatic potential**, mortality |

**Risk factors (shared, with emphases):**

| RF | Stronger for |
|----|--------------|
| UV exposure (cumulative) | SCC > BCC |
| Intermittent intense UV / sunburns (childhood) | Melanoma > BCC |
| Fair skin (Fitzpatrick I-II) | All |
| Older age | SCC > BCC > melanoma |
| Immunosuppression | **SCC** (transplant patients) |
| HPV | SCC (genital, periungual) |
| Chronic wounds, scars (Marjolin) | SCC |
| Radiation | All |
| Arsenic, tar | SCC, BCC |
| Genetic syndromes | BCC (Gorlin/basal cell nevus, xeroderma pigmentosum), melanoma (CDKN2A, BAP1) |

**BCC clues:**

| Subtype | Look |
|---------|------|
| Nodular (most common) | **Pearly papule with telangiectasias**, central ulcer ("rodent ulcer") |
| Superficial | Pink, scaly patch trunk |
| Pigmented | Brown/black, can mimic melanoma |
| Morpheaform/sclerosing | Scar-like, ill-defined |

**SCC clues:**

| Lesion | Look |
|--------|------|
| **Actinic keratosis** (precursor) | Rough, sandpapery on sun-exposed skin |
| **SCC in situ (Bowen's)** | Erythematous scaly plaque |
| Invasive SCC | Hyperkeratotic, crusted, ulcerated nodule |
| **Keratoacanthoma** | Rapidly growing dome with central keratin plug — well-differentiated SCC |

**Melanoma — ABCDE rule (asymmetric features):**

| Letter | Sign |
|--------|------|
| A | **Asymmetry** |
| B | **Border** irregularity |
| C | **Color** variation |
| D | **Diameter** >6 mm |
| E | **Evolution** (any change) |

Plus: "ugly duckling" sign — looks different from patient's other moles.

**Melanoma subtypes:**

| Type | Features |
|------|----------|
| Superficial spreading | Most common; horizontal growth phase first |
| Nodular | Vertical growth from start; aggressive |
| Lentigo maligna | Slow, sun-damaged skin (face), elderly |
| Acral lentiginous | Palms, soles, nail beds; **most common in dark skin**; not UV-related |

**Staging — Breslow depth is THE prognostic factor:**

| Breslow | Stage approx |
|---------|--------------|
| In situ | 0 |
| ≤1.0 mm | T1 |
| 1.01-2.0 mm | T2 |
| 2.01-4.0 mm | T3 |
| >4.0 mm | T4 |

**Sentinel lymph node biopsy (SLNB)** considered for ≥0.8 mm or ulcerated thinner; influences adjuvant treatment.

**Diagnosis & treatment:**

| Cancer | Diagnosis | Treatment |
|--------|-----------|-----------|
| BCC | Punch / shave biopsy | **Excision** (3-4 mm margin); **Mohs** for face / large / recurrent; topical (5-FU, imiquimod) for superficial; vismodegib (hedgehog inhibitor) for advanced |
| Actinic keratosis | Clinical ± biopsy | Cryotherapy, 5-FU, imiquimod, photodynamic therapy |
| SCC in situ | Biopsy | Excision, electrodesiccation, topical 5-FU, imiquimod |
| Invasive SCC | Excision | 4-6 mm margins; Mohs for high-risk areas / large; radiation; immunotherapy (cemiplimab) for advanced |
| Melanoma | **Excisional biopsy with narrow margins** (don't shave) | Wide local excision + SLNB; immunotherapy (anti-PD-1 ± anti-CTLA4: nivolumab, pembrolizumab, ipilimumab); BRAF + MEK inhibitors for BRAF-mutant (V600E/K) |

**Mohs surgery** — tissue-sparing, layer-by-layer with immediate margin assessment. Indicated for:
- High-risk locations (face, ears, genitalia, hands, feet)
- Large or recurrent tumors
- Aggressive histologic subtypes
- Immunocompromised host

**Immunotherapy in melanoma — checkpoint inhibitors:**

| Drug | Target |
|------|--------|
| Nivolumab, pembrolizumab | PD-1 |
| Atezolizumab | PD-L1 |
| Ipilimumab | CTLA-4 |
| Relatlimab | LAG-3 |

**Common immune-related AEs**: pneumonitis, colitis, hepatitis, endocrinopathies (thyroid, adrenal, pituitary), dermatitis, myocarditis (rare).

**Targeted therapy for BRAF-mutant melanoma:** dabrafenib + trametinib; encorafenib + binimetinib.

**Sun protection (primary prevention):**

| Measure |
|---------|
| Broad-spectrum sunscreen SPF ≥30, reapply Q2h |
| Protective clothing, hat, sunglasses |
| Avoid peak UV (10 AM-4 PM) |
| Avoid tanning beds (Class 1 carcinogen) |
| Annual full skin exam high-risk; self-exam monthly |

**Common gotchas:**
- **Never shave biopsy a suspected melanoma** — disrupts depth (Breslow) staging
- **Acral lentiginous melanoma in dark skin** — palms, soles, subungual; classic missed diagnosis (Hutchinson sign = pigment extending onto nail fold)
- **SCC of the lip / ear / scar / genital** = high-risk, more likely to metastasize
- **Sub-ungual streak**: benign in dark-skinned (linear melanonychia common); concerning if single, wide, irregular, changing, with Hutchinson sign
- **Transplant recipients** develop SCC at very high rates → close skin surveillance
- **Imiquimod / 5-FU** cause significant local inflammation — counsel
- BCC rarely kills but can be locally destructive (especially morpheaform near eye/nose)

**Rule of thumb:** Pearly + telangiectasia = BCC. Hyperkeratotic + sun-damage = SCC. ABCDE + ugly duckling = melanoma. **Excisional biopsy** for melanoma; punch/shave for BCC/SCC. Mohs for face / recurrent. Melanoma → checkpoint ± targeted; BRAF-mutant adds dabrafenib/trametinib.
