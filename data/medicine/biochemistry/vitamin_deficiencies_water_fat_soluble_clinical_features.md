### Vitamin Deficiencies

**Water-soluble (B + C) — usually no toxicity, depleted quickly:**

| Vitamin | Deficiency syndrome | Key features |
|---------|---------------------|--------------|
| B1 (thiamine) | Beriberi, Wernicke-Korsakoff | Wet (HF), dry (neuro); ophthalmoplegia, ataxia, confusion → confab |
| B2 (riboflavin) | — | Cheilosis, corneal vascularization, magenta tongue |
| B3 (niacin) | Pellagra | 3 D's: Diarrhea, Dermatitis, Dementia (+death) |
| B5 (pantothenate) | Rare | Dermatitis, alopecia, adrenal insufficiency |
| B6 (pyridoxine) | INH-induced, alcoholism | Sideroblastic anemia, peripheral neuropathy, seizures |
| B7 (biotin) | Raw egg whites | Dermatitis, alopecia |
| B9 (folate) | Pregnancy, MTX, alcohol | Megaloblastic anemia, **no neuro Sx**, neural tube defects |
| B12 (cobalamin) | Pernicious anemia, vegan, ileal disease | Megaloblastic + **subacute combined degeneration** (dorsal/lateral cord) |
| C (ascorbate) | Scurvy | Gum bleeding, perifollicular hemorrhage, poor wound healing, corkscrew hair |

**Fat-soluble (A, D, E, K) — stored, toxicity possible:**

| Vitamin | Deficiency | Toxicity |
|---------|-----------|----------|
| A | Night blindness, xerophthalmia, Bitot's spots, ↑ infections | Pseudotumor cerebri, teratogenic, hepatotoxic |
| D | Rickets (kids), osteomalacia (adults), hypocalcemic tetany | Hypercalcemia, stones |
| E | Hemolytic anemia, ataxia, peripheral neuropathy | ↑ bleeding (antagonizes K) |
| K | ↑ PT/INR, hemorrhage, neonatal HDN | Rare |

**B12 vs folate (don't miss this distinction):**

| Feature | B12 | Folate |
|---------|-----|--------|
| Megaloblastic anemia | Yes | Yes |
| Hypersegmented neutrophils | Yes | Yes |
| Methylmalonic acid | ↑ | Normal |
| Homocysteine | ↑ | ↑ |
| Neuro symptoms (SCD) | **Yes** | No |
| Causes | Pernicious, terminal ileum, vegan | Pregnancy, MTX, alcohol, phenytoin |

**Treating with folate alone in B12 deficiency** corrects the anemia but **lets neuro damage progress** — always check B12 first.

**High-yield associations:**

| Clinical clue | Vitamin |
|---------------|---------|
| Alcoholic + confusion + ophthalmoplegia | B1 (give before glucose!) |
| INH therapy + neuropathy | B6 |
| Vegan + macrocytic anemia + paresthesias | B12 |
| Bariatric surgery (any) | B12, B1, D, iron |
| Crohn's terminal ileum | B12 |
| Phenytoin or MTX | Folate |
| Sailor without citrus | C |
| Cystic fibrosis (fat malabs) | A, D, E, K |
| Warfarin reversal | K |

**Common gotchas:**
- Always give thiamine **before glucose** in alcoholics — glucose load can precipitate Wernicke
- Folate hides B12 deficiency on labs (corrects anemia) but neuro damage continues
- Vitamin K dependent factors: II, VII, IX, X + Protein C, S
- Newborns get IM K at birth (sterile gut, low milk K) to prevent HDN

**Rule of thumb:** Macrocytic anemia → check B12 *and* folate. Neuro symptoms swing it to B12. Fat malabsorption hits A, D, E, K together.
