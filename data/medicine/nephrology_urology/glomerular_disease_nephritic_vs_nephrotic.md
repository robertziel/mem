### Glomerular Disease — Nephritic vs Nephrotic

**Two syndromes:**

| Feature | Nephritic | Nephrotic |
|---------|-----------|-----------|
| Hallmark | **Hematuria + RBC casts** | **Proteinuria >3.5 g/d** |
| Mechanism | Inflammatory glomerular injury | Loss of glomerular barrier |
| Edema | Mild → moderate | **Marked**, pitting (low albumin) |
| BP | **Hypertension** | Normal / mild HTN |
| Protein | Sub-nephrotic, <3.5 g | >3.5 g |
| Albumin | Mild ↓ | **<3 g/dL** |
| Cholesterol | Normal | **High** |
| Hypercoagulable | No | Yes (loss of antithrombin) |

**Nephritic syndromes:**

| Disease | Trigger / Clue | Light micro | EM / IF |
|---------|---------------|-------------|---------|
| **PSGN** | 2-4 wk post-strep; ↓C3 | Hypercellular glomeruli | Subepithelial **"humps"**; granular IgG/C3 |
| **IgA nephropathy (Berger)** | Synpharyngitic gross hematuria (1-2d post-URI) | Mesangial proliferation | Mesangial **IgA deposits** |
| Henoch-Schönlein purpura (IgA vasculitis) | Kid; palpable purpura, abdominal pain, arthritis, IgA nephritis | — | Mesangial IgA |
| **Anti-GBM (Goodpasture)** | Lung + kidney; hemoptysis | Crescents | **Linear IgG** along GBM |
| **ANCA-associated** (GPA, MPA, EGPA) | Pauci-immune; systemic | Crescents | **No / few deposits** ("pauci-immune") |
| **Lupus nephritis** | SLE; ↓C3, ↓C4 | Six classes (ISN/RPS); class IV most severe | "Full house" (IgG, IgA, IgM, C3, C1q) |
| Cryoglobulinemic GN | HCV; ↓C3, ↓C4 | MPGN pattern | Cryoglobulins, IgM |
| Membranoproliferative GN | HCV, idiopathic | Tram-track BM | Subendothelial deposits |
| Alport | X-linked, sensorineural deafness, ocular | Type IV collagen abnormal | Basket-weave GBM on EM |
| Thin basement membrane | Asymptomatic isolated hematuria | Thin GBM | — |

**Nephrotic syndromes:**

| Disease | Population / clue | Light micro | EM | IF |
|---------|-------------------|-------------|----|----|
| **Minimal change disease** | **Children**; idiopathic, post-NSAID, Hodgkin | Normal | Foot-process effacement | Negative |
| **FSGS** | African-American adults, HIV, obesity, heroin | Segmental sclerosis | Effacement | Negative or mild IgM |
| **Membranous** | Adults; idiopathic (anti-PLA2R), HBV, HCV, SLE, solid tumors, drugs (NSAID, gold, penicillamine) | Diffuse BM thickening | "Spike and dome", subepithelial deposits | Granular IgG/C3 along BM |
| **Diabetic nephropathy** | Long-standing DM | **Kimmelstiel-Wilson** nodules | Diffuse mesangial expansion | Linear IgG (nonspecific) |
| **Amyloid** | MM, chronic inflammation | Apple-green birefringence under polarized light (Congo red) | Non-branching 8-10 nm fibrils | Light or heavy chain |
| **MPGN type I/II** | HCV, autoimmune (type II = dense deposit, C3 nephritic factor) | Tram-track BM | Subendothelial (I) / dense intra-membrane (II) | C3 ± Ig |

**Workup:**

| Test | Use |
|------|-----|
| UA + microscopy | RBC casts (nephritic), oval fat / Maltese cross (nephrotic) |
| 24h urine or spot ACR/PCR | Quantify proteinuria |
| Serum complement | ↓C3 ± C4: PSGN, lupus, MPGN, cryo, endocarditis, shunt nephritis; normal: IgA, ANCA, anti-GBM |
| Anti-streptolysin O / anti-DNase B | PSGN |
| ANA, dsDNA, C3, C4 | Lupus |
| ANCA (c/p), anti-GBM | Pulmonary-renal |
| HBV / HCV / HIV | Membranous, MPGN, FSGS |
| Anti-PLA2R | Idiopathic membranous |
| Cryoglobulins | HCV |
| SPEP / UPEP / FLC | Amyloid, myeloma |
| **Renal biopsy** | Definitive in many cases |

**Complement-low GNs (mnemonic — "PEMSC"):** PSGN, **E**ndocarditis-related, **M**PGN, **S**LE, **C**ryoglobulinemia.

**Treatment overview:**

| Disease | Treatment |
|---------|-----------|
| PSGN | Supportive; resolves |
| IgA nephropathy | ACEi/ARB; corticosteroids if persistent proteinuria; budesonide (Tarpeyo) |
| Anti-GBM | **Plasmapheresis + steroids + cyclophosphamide** (urgent) |
| ANCA vasculitis | Steroids + rituximab or cyclophosphamide; plasmapheresis selected |
| Lupus nephritis | Class III/IV: induction (MMF or cyclo + steroid) → maintenance (MMF or aza); class V: ACEi/ARB ± immunosuppression |
| Minimal change | Steroids (most respond) |
| FSGS | Steroids; treat secondary cause if identifiable |
| Membranous | Watch / wait if low risk; rituximab if high risk; address secondary cause |
| Diabetic nephropathy | ACEi/ARB + SGLT2i + finerenone + glycemic control |

**Common gotchas:**
- **PSGN** is **post**-strep — antibiotic for the strep doesn't prevent GN; serial complement: **C3 normalizes in 6-8 weeks** (long C3 ↓ → think MPGN or lupus instead)
- **Hypoalbuminemia** in nephrotic → **drug binding falls** → ↑ free drug levels (warfarin, phenytoin)
- Membranous in adult >60 — **screen for malignancy**
- **Crescents on biopsy** = rapidly progressive GN — treat fast
- **Anti-GBM** is a renal emergency — plasmapheresis ASAP

**Rule of thumb:** RBC casts + HTN = nephritic; massive proteinuria + edema = nephrotic. Complement ↓ = PEMSC. Linear IgG = anti-GBM; pauci-immune = ANCA; full house = lupus. Biopsy when treatment will change.
