### Acute Kidney Injury (AKI)

**KDIGO definition (any one):**

| Criterion |
|-----------|
| ↑ Cr ≥0.3 mg/dL within 48h |
| ↑ Cr ≥1.5× baseline within 7 days |
| Urine output <0.5 mL/kg/h for ≥6h |

**Three categories — "where" the problem is:**

| Type | Mechanism | Common causes |
|------|-----------|---------------|
| **Pre-renal** (~60%) | Hypoperfusion | Hypovolemia, hemorrhage, sepsis (early), HF, cirrhosis, NSAID/ACEi |
| **Intrinsic** (~30%) | Renal parenchyma | ATN, AIN, glomerulonephritis, vascular |
| **Post-renal** (~10%) | Obstruction | BPH, stones, malignancy, neurogenic bladder |

**Distinguishing pre-renal vs intrinsic (ATN):**

| Lab | Pre-renal | ATN |
|-----|-----------|-----|
| BUN:Cr | **>20:1** | <15:1 |
| Urine osm | >500 | <350 |
| Urine Na | <20 | >40 |
| FENa | **<1%** | >2% |
| FEUrea (on diuretic) | **<35%** | >50% |
| Urine sediment | Hyaline casts | **Muddy brown casts** |

**FENa = (UrineNa × PlasmaCr) / (PlasmaNa × UrineCr) × 100**. FENa unreliable on diuretics → use FEUrea.

**Intrinsic AKI subtypes:**

| Subtype | Clue | Findings |
|---------|------|----------|
| **ATN — ischemic** | Hypotension, sepsis, surgery | Muddy brown granular casts |
| **ATN — toxic** | Aminoglycosides, contrast, myoglobin (rhabdo), tumor lysis, ethylene glycol | Same casts |
| **AIN** | Drug exposure (β-lactams, PPI, NSAIDs, sulfa, allopurinol), fever, rash, eosinophilia, eosinophiluria | WBC casts, eos in urine |
| Glomerulonephritis | Hematuria + proteinuria + edema + HTN | RBC casts, dysmorphic RBCs |
| Vascular | Renal artery occlusion, malignant HTN, atheroembolic | Imaging, biopsy |

**Workup of AKI:**

| Step | Test |
|------|------|
| 1 | History + meds review (NSAID, ACEi, diuretic, contrast, antibiotic) |
| 2 | Volume status exam |
| 3 | UA + microscopy |
| 4 | Urine Na, Cr, urea (FENa, FEUrea) |
| 5 | Renal US — hydronephrosis? |
| 6 | Specific tests as indicated (ANCA, ANA, complement, anti-GBM, SPEP, light chains) |

**Indications for emergent dialysis (AEIOU):**

| Letter | Indication |
|--------|-----------|
| A | Acidosis (refractory) |
| E | Electrolyte (refractory hyperkalemia) |
| I | Ingestion (dialyzable: salicylate, lithium, methanol, ethylene glycol, metformin lactic acidosis) |
| O | Overload (volume, refractory pulmonary edema) |
| U | Uremia (encephalopathy, pericarditis, bleeding) |

**Contrast-associated AKI prevention:**

| Measure |
|---------|
| Hydration with isotonic saline / bicarb (the most evidence) |
| Hold NSAIDs, ACEi/ARB, diuretics if possible |
| Lowest contrast volume |
| **N-acetylcysteine has weak / no evidence** |

CIN risk: pre-existing CKD (esp. eGFR <30), DM, dehydration, HF.

**Specific scenarios:**

| Scenario | Action |
|----------|--------|
| Rhabdomyolysis (CK >5000, dark urine, ↑K, ↑PO4, ↓Ca) | Aggressive isotonic fluids; alkalinize urine controversial |
| Tumor lysis syndrome | Allopurinol / **rasburicase**, fluids, monitor K/PO4/uric acid/Ca |
| Hepatorenal syndrome | Albumin + **terlipressin** or norepi; transplant only true cure |
| Cardiorenal | Optimize cardiac function (diurese carefully) |
| ATN recovery | Polyuric phase 1-2 wk after — monitor electrolytes |

**Hyperkalemia in AKI — treatment ladder:**

| Severity | Action |
|----------|--------|
| Mild K 5-6 | Restrict K, oral binders (patiromer, sodium zirconium), loop diuretic if euvolemic+ |
| Moderate 6-7 | Insulin + glucose, β2 agonist (albuterol), bicarb if acidotic |
| Severe / EKG changes | **Calcium gluconate** (membrane stabilization) → insulin/dextrose, β-agonist → dialysis |

EKG: peaked T → wide QRS → sine wave → asystole. Calcium **first** if EKG changes.

**Common gotchas:**
- "Pre-renal" can become **ATN** if not corrected — same patient on a continuum
- BUN:Cr >20:1 also seen in **GI bleeding** (digested protein)
- **Contrast-associated AKI is usually self-limited** — Cr peaks 3-5d, recovers in 1-2 wk
- **NSAIDs + ACEi/ARB + diuretic** = "triple whammy" — frequent AKI cause
- Eosinophiluria not specific for AIN
- Don't hold ACEi/ARB long-term after AKI if renoprotective — restart once stable

**Rule of thumb:** Always exclude obstruction (US) and review meds. FENa <1% = pre-renal; muddy brown casts = ATN. Hyperkalemia with EKG changes → calcium first. Dialyze for AEIOU.
