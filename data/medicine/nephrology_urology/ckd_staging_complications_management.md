### Chronic Kidney Disease (CKD)

**KDIGO staging (G + A):**

| eGFR (G) | Description |
|----------|-------------|
| G1 | ≥90 (normal) — must have evidence of kidney damage |
| G2 | 60-89 (mild) — must have evidence of kidney damage |
| G3a | 45-59 |
| G3b | 30-44 |
| G4 | 15-29 |
| G5 | <15 (kidney failure) |

| Albuminuria (A) | Urine ACR (mg/g) |
|-----------------|------------------|
| A1 | <30 (normal-mild) |
| A2 | 30-300 (moderate) |
| A3 | >300 (severe) |

CKD requires markers of damage **and/or** eGFR <60 for ≥3 months.

**Common causes (US):**

| Cause | % |
|-------|---|
| Diabetes | ~38% |
| Hypertension | ~26% |
| Glomerular | ~16% |
| Cystic / hereditary (PKD) | ~5% |
| Other | balance |

**Slow progression — proven renoprotective:**

| Class | Notes |
|-------|-------|
| **ACEi / ARB** | All proteinuric CKD; check K and Cr |
| **SGLT2 inhibitor** | Dapagliflozin, empagliflozin — eGFR ≥20-25, T2DM or proteinuric CKD; mortality + renal benefit |
| **Finerenone** | Non-steroidal MRA — proteinuric DKD |
| **GLP-1 RA** | Renal + CV benefit in T2DM |
| BP control | <130/80 (KDIGO 2021: <120 systolic by office BP measurement) |
| Glycemic control | A1c 7% (individualize) |
| Smoking cessation | — |
| Salt restriction | <2 g Na/d |

**Complications and treatment:**

| Complication | Mechanism | Treatment |
|--------------|-----------|-----------|
| Anemia | ↓ EPO, iron deficiency | Iron repletion → ESA (epoetin, darbepoetin) target Hgb 10-11; HIF-PHIs (daprodustat) emerging |
| **CKD-MBD** (mineral bone) | ↓ 1,25-D, ↑ phosphate, ↑ PTH | Phosphate binders (sevelamer, calcium acetate, lanthanum, ferric citrate); active vitamin D (calcitriol) or analog (paricalcitol); calcimimetic (cinacalcet, etelcalcetide) |
| Acidosis | ↓ NH4 excretion | Sodium bicarbonate (target HCO3 ≥22) |
| Hyperkalemia | ↓ K excretion | Diet, loop diuretics, binders (patiromer, SZC); avoid renin-blockade if recurrent |
| Volume overload | Na/water retention | Salt restriction, loop diuretic |
| HTN | RAS, volume | Multi-drug; ACEi/ARB cornerstone |
| **Uremia** | Toxin retention | Dialysis or transplant when symptomatic |

**Dialysis indications (AEIOU + planning):**

| Indication | Detail |
|------------|--------|
| **A**cidosis (refractory) | pH <7.1 |
| **E**lectrolyte (refractory K) | K >6.5 not responsive |
| **I**ngestion (dialyzable toxin) | Lithium, salicylate, methanol, ethylene glycol |
| **O**verload (refractory pulm edema) | — |
| **U**remia (severe symptoms) | Pericarditis, encephalopathy, bleeding |
| Planning | Refer at eGFR ~30; create access at eGFR ~20; start usually at 8-15 |

**Dialysis modalities:**

| Mode | Setting | Notes |
|------|---------|-------|
| HD (in-center) | 3×/wk | AVF preferred, AVG, then catheter (worst) |
| Home HD | More frequent | Better outcomes |
| Peritoneal | Daily | Catheter-based, fewer hemodynamic shifts |

AVF maturation 4-8 wk; **fistula > graft > catheter** in outcomes.

**Transplant — preferred for most ESRD:**

| Type | Wait |
|------|------|
| Living donor | Best survival, can pre-empt dialysis |
| Deceased donor | Years (~3-5 in US) |

Contraindications (relative): active infection, active malignancy, severe CV disease, non-adherence.

**Drug dosing in CKD — common adjustments:**

| Drug | Adjustment |
|------|-----------|
| Metformin | Stop if eGFR <30; cautious 30-45 |
| Aminoglycosides, vanc | Dose by level/eGFR |
| Enoxaparin | Reduce or use UFH if eGFR <30 |
| Many antimicrobials | Renal dose |
| NSAIDs | **Avoid** in advanced CKD |
| Gadolinium | Avoid in eGFR <30 (NSF risk; group II agents safer) |
| Contrast | Hydration; weigh risk/benefit |

**Common gotchas:**
- **Stage 5 CKD ≠ dialysis automatically** — start when symptomatic (uremia) or refractory complications, not by number alone
- **Don't hold ACEi/ARB** for small Cr rise (<30%) — long-term renoprotection
- Add **finerenone** in DKD with persistent albuminuria on max ACEi/ARB
- **HD intra-dialytic hypotension** — common; adjust dry weight, midodrine, sodium profiling
- **Vascular access protection**: NO BP / IV / labs in fistula arm
- **Renal osteodystrophy** = umbrella for bone abnormalities — distinct from osteoporosis

**Rule of thumb:** GxAy stages CKD. ACEi/ARB + SGLT2i + finerenone + GLP-1 are the new pillars of renoprotection. Anemia + bone disease + acidosis + HTN need active treatment well before dialysis. Refer early.
