### Crystal Arthropathies — Gout & Pseudogout

**Compare:**

| Feature | Gout (MSU) | Pseudogout (CPPD) |
|---------|-----------|-------------------|
| Crystal | Monosodium urate | Calcium pyrophosphate dihydrate |
| Shape under polarized light | **Needle-shaped** | **Rhomboid** |
| Birefringence | **Negative** (yellow when parallel to compensator) | **Positive** (blue when parallel) |
| Joints | **MTP1 (podagra)**, midfoot, ankle, knee; rarely upper | **Knee, wrist** most common |
| Triggers | Diet (purines: red meat, seafood, alcohol — esp. beer; high-fructose), dehydration, surgery, diuretics | Trauma, surgery, illness; chondrocalcinosis |
| Imaging | "Tophi", erosions with overhanging edges; dual-energy CT shows urate | **Chondrocalcinosis** (calcium in cartilage on X-ray) |
| Onset | Sudden, severe, peak <24h | Often less explosive, can mimic gout or RA |
| Hyperuricemia required? | No (acute attack may have **normal** urate) | No |
| Comorbidities | HTN, CKD, metabolic syndrome, DM | **Hemochromatosis, hyperparathyroidism, hypomagnesemia, hypophosphatasia, hypothyroidism** |

**Confirm diagnosis:**

| Step | Detail |
|------|--------|
| **Joint aspiration** | Crystal identification + cell count + culture |
| WBC | Inflammatory (>2000); >50,000 — septic must be excluded |
| Polarized microscopy | Needle (negative birefringent) = gout; rhomboid (positive) = pseudogout |

Septic arthritis can coexist — always culture if any concern.

**Acute gout treatment (start within 24h ideally):**

| Drug | Notes |
|------|-------|
| **NSAIDs** | First-line if no contraindication; indomethacin classic, naproxen common |
| **Colchicine** | Within 24h; 1.2 mg → 0.6 mg 1h later → 0.6 mg BID until resolution; renal/hepatic dose; CYP3A4 + P-gp interactions (statins, macrolides, cyclosporine — toxicity) |
| **Glucocorticoids** | Oral prednisone 30-40 mg taper; intra-articular if 1-2 joints |
| **IL-1 inhibitors** | Anakinra, canakinumab — refractory or contraindicated to others |
| **Don't start urate-lowering during attack** unless already on it; if on it, don't stop |

**Urate-lowering therapy (ULT) — prevention:**

| Indication |
|-----------|
| ≥2 attacks/year |
| Tophi |
| Erosions on imaging |
| CKD |
| Urolithiasis (urate stones) |

**Targets:** serum urate **<6 mg/dL** (<5 if tophi).

**ULT options:**

| Drug | Mechanism | Notes |
|------|-----------|-------|
| **Allopurinol** | Xanthine oxidase inhibitor | First-line; start low (50-100 mg) and titrate; check **HLA-B*5801** in Asian/Black (SJS/TEN risk); interacts with **azathioprine / 6-MP** (toxicity); reduce dose in CKD |
| **Febuxostat** | Xanthine oxidase inhibitor | Useful in allopurinol allergy / nonresponse; CV warning |
| Probenecid | Uricosuric | Avoid in stones, low GFR |
| Pegloticase | Recombinant uricase (IV) | Severe refractory tophaceous; immunogenic |

**ULT initiation pearls:**

| Item |
|------|
| Always **co-prescribe colchicine 0.6 mg daily or low-dose NSAID** for first 3-6 months to prevent flares |
| Don't stop ULT during a flare |
| Lifelong therapy in most patients |

**Lifestyle for gout:**
- Avoid beer, hard liquor (somewhat); moderate wine
- Reduce purine-rich foods (red meat, organ, seafood)
- Avoid sugary drinks, high-fructose corn syrup
- Hydration
- Weight loss
- Treat HTN with losartan (mild uricosuric); avoid thiazides if possible
- Cherries, dairy may help

**Pseudogout treatment:**

| Step | Detail |
|------|--------|
| Acute | NSAIDs, colchicine, intra-articular steroid, oral prednisone — same as gout |
| Chronic | Colchicine prophylaxis if recurrent; treat **underlying metabolic disease** (hemochromatosis, hyperparathyroidism, hypoMg) |
| No long-term ULT-equivalent for CPPD |

**Drug-induced hyperuricemia (mnemonic CAN'T LEAP):**

| Letter | Drug |
|--------|------|
| C | Cyclosporine |
| A | Alcohol |
| N | Nicotinic acid (niacin) |
| T | Thiazides |
| L | Loop diuretics |
| E | Ethambutol |
| A | Aspirin (low dose) |
| P | Pyrazinamide |

**Common gotchas:**
- **Acute gout with normal serum urate** is common — don't rule out by urate alone
- **Allopurinol + azathioprine / 6-MP** — block metabolism → severe marrow toxicity; use **febuxostat** alternative or reduce thiopurine to 25%
- **HLA-B*5801** screening in high-risk ethnicities before allopurinol — SJS/TEN
- **Tumor lysis syndrome** is a hyperuricemia emergency — rasburicase (G6PD-aware)
- **Septic + crystal arthritis** can coexist; treat the septic
- **Pseudogout in young patient** → search hemochromatosis, hyperparathyroidism, Wilson, hypomagnesemia

**Rule of thumb:** Acute monoarthritis → tap, polarize. Negative needles = gout; positive rhombi = pseudogout. Treat acute flare with NSAID / colchicine / steroid. ULT only after attack resolves; allopurinol first-line, target urate <6. Pseudogout → workup metabolic causes.
