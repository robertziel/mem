### Systemic Lupus Erythematosus (SLE)

**Demographics:**

| Item | Detail |
|------|--------|
| Female:male | 9:1 (childbearing age) |
| Race | More prevalent / severe in Black, Hispanic, Asian populations |
| Onset | Typically 15-45 years |

**EULAR/ACR 2019 classification — entry criterion: ANA ≥1:80 + at least 1 clinical and ≥10 weighted points (selected items):**

| Category | Items (selected) |
|----------|------------------|
| Constitutional | Fever |
| Mucocutaneous | Acute (malar), subacute / discoid, oral / nasal ulcers, alopecia |
| Hematologic | Leukopenia, thrombocytopenia, AIHA |
| Neuropsychiatric | Delirium, psychosis, seizure |
| Serositis | Pleural / pericardial effusion |
| Musculoskeletal | Joint involvement (Jaccoud's = non-erosive) |
| Renal | Proteinuria, **biopsy class III/IV** weighted heavily |
| Antiphospholipid | aPL antibodies |
| Complement | ↓C3 / ↓C4 |
| **SLE-specific antibodies** | **Anti-dsDNA**, **anti-Smith** |

**Highly specific antibodies:**

| Antibody | Specificity |
|----------|-------------|
| **Anti-dsDNA** | High; correlates with disease activity & nephritis |
| **Anti-Smith** | Highest specificity (~99%), low sensitivity |
| Anti-histone | Drug-induced lupus |
| Anti-Ro (SSA) / Anti-La (SSB) | Sjögren overlap; **neonatal lupus + congenital heart block** in pregnancy |
| Anti-ribosomal P | CNS lupus |
| **Antiphospholipid** (LA, anti-cardiolipin, anti-β2-GPI) | Thrombosis, pregnancy loss |
| ANA | Sensitive but not specific (>95%) |

**Drug-induced lupus** — hydralazine, procainamide, isoniazid, minocycline, anti-TNF, methyldopa, chlorpromazine, quinidine. **Anti-histone**+, dsDNA usually negative; spares CNS / kidney.

**Lupus nephritis (ISN/RPS):**

| Class | Description | Treatment |
|-------|-------------|-----------|
| I | Minimal mesangial | Observation |
| II | Mesangial proliferative | RAS blockade |
| **III** | Focal proliferative (<50% glomeruli) | **Induction (MMF or cyclophosphamide) + steroid; maintenance MMF or AZA** |
| **IV** | Diffuse proliferative (≥50%) | Same — **most severe + most common in SLE** |
| V | Membranous | RAS blockade ± immunosuppression depending on proteinuria |
| VI | Advanced sclerosing | Supportive / transplant |

**Treatment overview:**

| Severity | Treatment |
|----------|-----------|
| All SLE | **Hydroxychloroquine** (reduces flares, improves survival, eye exam baseline + annually after 5 yr) |
| Mild | NSAIDs, low-dose prednisone, hydroxychloroquine |
| Moderate (joints, skin refractory) | Methotrexate, azathioprine, leflunomide, belimumab |
| Severe / nephritis / CNS | **High-dose steroid + MMF or cyclophosphamide**; biologics: **belimumab** (BLyS), **anifrolumab** (IFN-α-R), **rituximab** (off-label severe) |
| Maintenance | MMF or AZA + lower steroid + hydroxychloroquine |
| Antiphospholipid syndrome | **Warfarin** (DOACs inferior, esp. triple-positive) |

**Pregnancy in SLE:**

| Item | Detail |
|------|--------|
| Plan during quiescence | Best outcomes |
| Continue hydroxychloroquine | Pregnancy-safe and reduces flares |
| Avoid | MMF, MTX, cyclophosphamide, leflunomide, belimumab (not enough data) |
| Anti-Ro / La | **Neonatal lupus** — rash, transaminitis; **congenital heart block** ~2% — fetal echo monitoring 16-26 wk |
| APS | Aspirin ± LMWH per criteria |
| Lupus flare in pregnancy | Steroid (low dose), hydroxychloroquine |
| Preeclampsia mimics | Renal flare; can be hard to distinguish |

**Complications and screening:**

| Complication | Screening |
|--------------|-----------|
| Accelerated atherosclerosis | Lipid, BP control aggressive |
| Infection | Vaccinations (pneumococcal, flu, COVID, Shingrix; HPV if appropriate) |
| Avascular necrosis (steroid) | Imaging if symptoms |
| Osteoporosis | DEXA, vitamin D, calcium |
| Malignancy (lymphoma slight ↑) | Standard screening |
| Cataract / glaucoma (steroid) | Eye exam |
| Hydroxychloroquine retinopathy | Annual after 5 yr |

**SLE flare clues:**

| Clue |
|------|
| ↑ anti-dsDNA |
| ↓ C3, C4 |
| Proteinuria (new / ↑) |
| New cytopenia |
| Hematuria with active sediment |
| New rash, joint pain |

Distinguishing from infection in immunosuppressed SLE: PCT, cultures, careful exam, often empirical treatment.

**Common gotchas:**
- **All SLE patients on hydroxychloroquine** unless contraindicated — mortality benefit
- **Anti-Ro+ in pregnancy** = monitor fetal heart at 16-26 weeks; treat heart block early with hydroxychloroquine ± dexamethasone
- **APS triple positive** is highest thrombosis risk; **warfarin only** (DOACs inferior)
- **Drug-induced lupus** — anti-histone+, spares CNS/kidney, resolves on stopping drug
- **Lupus mesenteric vasculitis / lupus enteritis** — abdominal pain in flare; CT shows bowel wall thickening / "target sign"
- **Hydroxychloroquine retinopathy** — usually after 5+ years; annual screening (visual fields, OCT, fundus)

**Rule of thumb:** Multi-system + ANA + dsDNA/Smith = SLE. Hydroxychloroquine for everyone. MMF or cyclophosphamide for severe nephritis. Anti-Ro+ pregnancy → neonatal heart block. APS → warfarin. Aggressive CV risk control.
