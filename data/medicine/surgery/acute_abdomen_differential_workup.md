### Acute Abdomen

**Pain location → likely diagnoses:**

| Region | Diagnoses |
|--------|-----------|
| **RUQ** | Cholecystitis, biliary colic, choledocholithiasis, cholangitis, hepatitis, hepatic abscess, Fitz-Hugh-Curtis (perihepatitis) |
| **Epigastric** | PUD, gastritis, pancreatitis, MI (inferior), AAA, esophagitis |
| **LUQ** | Splenic injury, splenic infarct, gastric ulcer, MI |
| **RLQ** | **Appendicitis**, mesenteric adenitis, Crohn ileitis, ovarian (cyst, torsion), ectopic, PID, cecal volvulus |
| **LLQ** | Diverticulitis, ovarian, sigmoid volvulus, ischemic colitis |
| **Suprapubic** | UTI, retention, PID, ovarian, cystitis |
| **Diffuse** | Peritonitis (perforation), early appendicitis, mesenteric ischemia, gastroenteritis, ileus, obstruction, DKA, sickle crisis |
| **Flank** | Renal stone, pyelonephritis, AAA |
| **Periumbilical** | Early appendicitis (visceral), small-bowel issues, AAA, mesenteric ischemia |

**Migration patterns to recognize:**

| Pattern | Diagnosis |
|---------|-----------|
| Periumbilical → RLQ | Appendicitis |
| Epigastric → RLQ then back/scrotum | Renal stone (radiates to groin) |
| Tearing back to chest | Aortic dissection |
| Periumbilical pain out of proportion to exam | **Mesenteric ischemia** |
| RUQ → R shoulder | Diaphragmatic irritation (cholecystitis) |

**Initial workup (any acute abdomen):**

| Test |
|------|
| Vitals + serial exams |
| CBC, CMP, lipase, lactate, INR, T&S (or T&C if surgery likely) |
| UA, β-hCG (any female reproductive age) |
| ECG (esp. older) |
| Lactate (ischemia) |
| **Imaging**: bedside US (FAST, RUQ, gyn), upright CXR (free air), CT abd/pelvis (most diagnostic), MRCP if biliary |

**Peritoneal signs:**

| Sign | Detail |
|------|--------|
| Rigidity, guarding | Involuntary contraction |
| **Rebound tenderness** | Pain on release |
| Cough / heel-tap pain | Peritoneal irritation |
| Murphy sign | Inspiratory arrest with RUQ palpation — **cholecystitis** |
| Rovsing | LLQ palpation → RLQ pain — **appendicitis** |
| Psoas | Pain with hip extension — retrocecal appendicitis |
| Obturator | Pain with hip flexion + internal rotation — pelvic appendicitis |
| McBurney point | 1/3 from ASIS to umbilicus — appendicitis |

**Time-critical diagnoses:**

| Diagnosis | Why urgent |
|-----------|-----------|
| **Ruptured AAA** | Hypotension + abdominal/back pain in older male; bedside US → immediate OR |
| **Mesenteric ischemia** | Pain out of proportion; AF / atherosclerosis; ↑ lactate; CT angiography |
| **Perforated viscus** | Free air, peritonitis; emergent surgery |
| **Ectopic pregnancy** | + β-hCG with adnexal mass / free fluid; rule out always |
| **Ovarian / testicular torsion** | Time-critical organ salvage (~6 hours) |
| **Necrotizing soft tissue** | Crepitus, severe pain; CT/imaging; OR |
| **Septic shock** with intra-abdominal source | Antibiotics + source control |
| **Aortic dissection** | Tearing pain ± neurologic / pulse asymmetry |
| **Strangulated hernia** | Tender, irreducible, ± obstruction |
| **Toxic megacolon** | UC/Crohn, C. diff; >6 cm + systemic |

**Specific conditions — high-yield:**

| Condition | Hallmark |
|-----------|----------|
| **Appendicitis** | Migrating periumbilical → RLQ, anorexia, low-grade fever, ↑ WBC; CT (95%+ accurate); appendectomy; antibiotics alone for selected uncomplicated |
| **Cholecystitis** | RUQ pain >6h, Murphy +, fever, ↑ WBC; US shows wall thickening, pericholecystic fluid, sonographic Murphy; cholecystectomy + antibiotics |
| **Ascending cholangitis** | **Charcot triad** (fever, jaundice, RUQ pain); **Reynolds pentad** + AMS + hypotension; **ERCP urgent** + antibiotics |
| **Acute pancreatitis** | Lipase >3× ULN; alcohol or gallstones most common; supportive (IV fluids LR, pain, NPO → early enteral feeding) |
| **Diverticulitis** | LLQ + fever + ↑ WBC; CT; uncomplicated → outpatient antibiotics or observation; complicated (abscess, perforation, fistula, obstruction) → surgery / drainage |
| **SBO** | Distention, vomiting, obstipation, high-pitched bowel sounds; CT shows transition point; NG decompression + IVF + monitor; surgery if strangulation, ischemia, complete |
| **LBO** | More gradual; r/o sigmoid volvulus, cancer; CT |
| **Volvulus** | Sigmoid (older, "coffee bean" sign on KUB), cecal (younger); decompress endoscopically (sigmoid) or surgery |
| **Mesenteric ischemia** | Embolic (AF, post-MI), thrombotic, NOMI, venous; CT angiography; revascularize; resect necrotic bowel |
| **AAA rupture** | Pulsatile mass, hypotension, back pain; OR or endovascular |
| **Ectopic pregnancy** | + β-hCG + no IUP on TVUS; rupture → hypotension; methotrexate (stable, small) or laparoscopy |
| **Ovarian torsion** | Acute pelvic pain, adnexal mass, Doppler may be normal early; surgical detorsion |

**Common gotchas:**
- **Pain out of proportion to exam** = mesenteric ischemia until proven otherwise (especially older + AF)
- **Always check β-hCG** in reproductive-age female with abdominal pain
- **Older patient with abdominal pain** has higher acuity threshold — image more, observe carefully
- **Perforation may have minimal pain** in elderly, immunocompromised, on steroids
- **Cholangitis** = surgical / GI emergency — ERCP same day
- **Renal stone** can refer pain to scrotum/labia; **AAA can mimic** — image elderly with new "stone"
- **Appendicitis on CT** sensitivity high but no imaging in pregnancy — US first; MRI if unclear
- **Don't miss DKA, MI, sickle crisis** as causes of acute abdomen

**Rule of thumb:** Location + migration + peritoneal signs + β-hCG + lactate + lipase. Image early — CT for most. Always rule out time-critical (AAA rupture, mesenteric ischemia, perforation, ectopic, cholangitis, torsion). Source control + antibiotics + surgery as indicated.
