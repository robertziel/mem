### Wound Healing

**Three intentions:**

| Type | Description | Examples |
|------|-------------|----------|
| **Primary** | Edges approximated (sutures, staples, glue) immediately | Surgical incision, clean laceration |
| **Secondary** | Wound left open to heal by granulation, contraction, epithelialization | Pressure ulcer, dehisced wound, abscess after I&D |
| **Tertiary (delayed primary)** | Initially open, closed later (after infection / contamination resolves) | Contaminated wound, sternal wound infection |

**Phases of healing:**

| Phase | Time | Cells | Events |
|-------|------|-------|--------|
| **Hemostasis** | Minutes | Platelets | Vasoconstriction, platelet plug, fibrin |
| **Inflammation** | 0-3 days | **Neutrophils** (early) → **macrophages** (Day 2-3, key cells) | Phagocytosis, debris clearance |
| **Proliferation** | 3-21 days | Fibroblasts, endothelial, keratinocytes | Granulation tissue (collagen III), angiogenesis, epithelialization, contraction |
| **Remodeling** | 3 wk - 1 yr+ | Fibroblasts | **Collagen III → I**, scar maturation, ↓ vascularity, gradual strengthening |

Tensile strength: ~10% at 1 wk, ~50% at 6 wk, ~80% maximum at 1 year. Skin **never** fully regains pre-injury strength.

**Macrophage = central orchestrator** — coordinates inflammation → proliferation transition.

**Factors impairing healing:**

| Local | Systemic |
|-------|----------|
| Infection | DM (poor glycemic control) |
| Ischemia / poor perfusion | Smoking |
| Foreign body | Malnutrition (esp. albumin <3, prealbumin) |
| Mechanical stress | Vitamin C, A, zinc, copper, iron deficiency |
| Radiation | Steroids (impair fibroplasia, vit A reverses some) |
| Edema | Chemotherapy, immunosuppression |
| Necrotic tissue | Liver / kidney failure |
| Pressure | Age (less robust collagen) |
| Desiccation / over-drying | Obesity (poor perfusion to fat) |
| Microbial colonization | Anemia, hypoxia |

**Vitamin C (scurvy)** — needed for hydroxylation of proline / lysine in collagen synthesis.
**Zinc** — cofactor for many enzymes; deficiency → poor wound healing.
**Vitamin A** — counteracts steroid effect on healing.

**Nutrition checks:**

| Test | Use |
|------|-----|
| Albumin | Long-term (3-wk half-life) |
| Prealbumin (transthyretin) | Acute (~2-day half-life) |
| Total lymphocyte count | Cell-mediated immunity |
| Transferrin | Iron + protein status |

**Sutures / closure:**

| Type | Use |
|------|-----|
| Absorbable (Vicryl, Monocryl, PDS, chromic) | Subcutaneous, internal |
| Non-absorbable (silk, nylon, prolene) | Skin closure (remove later); CV vessels |
| Staples | Quick skin closure, scalp |
| Glue (Dermabond) | Small, low-tension lacerations |

**Suture removal timing:**

| Site | Days |
|------|------|
| Face | 5 |
| Scalp | 7-10 |
| Extremities | 10-14 |
| Joint surfaces | 14 |
| Trunk | 7-10 |

**Wound dressings — match to wound:**

| Wound | Dressing |
|-------|----------|
| Dry, healing well | Cover with non-adherent / film |
| Exudative / draining | Foam, alginate (alginate also hemostatic) |
| Infected / heavy bioburden | Silver dressings; silver sulfadiazine |
| Necrotic / slough | Debridement (sharp, enzymatic, mechanical, autolytic) |
| Deep cavity | Negative-pressure wound therapy (wound vac) |
| Burn | Silver sulfadiazine (avoid in sulfa allergy, G6PD deficiency in small infants) |

**Pressure injury staging (NPUAP):**

| Stage | Finding |
|-------|---------|
| 1 | Non-blanchable erythema, intact skin |
| 2 | Partial-thickness, exposed dermis |
| 3 | Full-thickness, fat visible, no exposed bone/tendon |
| 4 | Full-thickness, exposed bone / tendon / muscle |
| Unstageable | Slough / eschar obscures depth |
| Deep tissue injury | Persistent non-blanchable purple discoloration |

**Prevention:** repositioning, support surfaces, nutrition, skin care, moisture management.

**Diabetic foot ulcer (Wagner):**

| Grade | Description |
|-------|-------------|
| 0 | Pre-ulcer (callus, deformity) |
| 1 | Superficial ulcer |
| 2 | Deep to tendon / bone |
| 3 | Abscess / osteomyelitis |
| 4 | Localized gangrene |
| 5 | Extensive gangrene |

**Management:** glycemic control, offloading, debridement, dressings, antibiotics for infection, vascular assessment (ABI, TBI), revascularization if PAD; **probe-to-bone** suggests osteomyelitis.

**Surgical site infection (SSI) classification:**

| Class | Risk |
|-------|------|
| Clean | <2% |
| Clean-contaminated | 5-15% |
| Contaminated | 15-30% |
| Dirty | >30% |

**SSI prevention:**

| Measure |
|---------|
| Prophylactic antibiotic within 60 min of incision (120 min for vanco/FQ) |
| Glycemic control |
| Normothermia |
| Skin prep (chlorhexidine-alcohol > povidone-iodine) |
| Hair removal with clippers, not razors |
| Smoking cessation |
| Nutrition |
| Wound closure technique |

**Complications:**

| Issue | Detail |
|-------|--------|
| Dehiscence | Wound separation; risk: infection, malnutrition, poor closure, ↑ intra-abdominal pressure (cough, obesity); often need re-operation |
| Evisceration | Bowel through wound — emergency, sterile saline-soaked gauze + OR |
| Hematoma / seroma | Drain if symptomatic |
| Hypertrophic scar / **keloid** | Hypertrophic stays within original wound; **keloid** extends beyond — silicone, steroid injection, pressure |
| Contracture | Across joint, limits motion |
| Chronic non-healing | Reassess (perfusion, infection, malignancy — Marjolin ulcer, malnutrition) |

**Common gotchas:**
- **Steroids impair wound healing** — vitamin A 25,000 IU/d may partially reverse
- **Smoking** — strong negative effect; counsel cessation 4+ weeks before/after surgery
- **Diabetes** — perioperative glycemic control reduces infection
- **Negative pressure wound therapy** — useful for large / dehisced / chronic wounds
- **Marjolin ulcer** — SCC arising in chronic wound / scar; biopsy non-healing wounds
- **Wound packing** ≠ closure; promotes secondary intention
- **Chronic ulcer in setting of arterial disease** → ABI, vascular consult; revascularize before debridement

**Rule of thumb:** Phases: hemostasis → inflammation (macrophage central) → proliferation → remodeling. Tensile peaks at ~80%, never 100%. Optimize systemic factors (DM, nutrition, smoking). Match dressing to wound. Pressure injury / DM ulcer / SSI prevention through standardized bundles.
