### HIV — ART and Opportunistic Infections

**Diagnosis algorithm:**

| Step | Test |
|------|------|
| 1 | **4th-gen HIV Ag/Ab combo** (window ~2-4 wk) |
| 2 if positive | HIV-1/2 differentiation immunoassay |
| 3 if discordant | HIV RNA (viral load) — confirms acute |

Test annually high-risk; once for all 13-64 (universal screening).

**Acute (primary) HIV:**
- Mono-like illness 2-4 wk post-exposure: fever, lymphadenopathy, pharyngitis, rash, myalgia
- Antibody often **negative**, viral load **very high**

**ART — preferred starting regimens (2024):**

| Regimen | Components |
|---------|-----------|
| **Bictegravir / TAF / FTC** (Biktarvy) | Single tablet |
| **Dolutegravir + (TAF or TDF) + (FTC or 3TC)** | Or combined |
| **Dolutegravir + 3TC** (Dovato) | Two-drug regimen |

INSTI (integrase strand transfer inhibitor)–based: bictegravir, dolutegravir, raltegravir, elvitegravir, cabotegravir.

**Drug class essentials:**

| Class | Examples | Toxicity |
|-------|----------|----------|
| NRTI | TAF/TDF, FTC/3TC, abacavir, AZT | TDF (renal, bone), AZT (anemia, lipoatrophy), abacavir (HSR — **HLA-B*5701** screen) |
| NNRTI | Efavirenz, rilpivirine, doravirine | Rash, neuropsych (efavirenz), CYP interactions |
| INSTI | Bictegravir, dolutegravir, raltegravir | Weight gain, well-tolerated |
| PI | Darunavir, atazanavir | GI, hyperlipidemia, hyperbilirubinemia (atazanavir), CYP3A4 |
| Entry inhibitors | Maraviroc (CCR5), enfuvirtide, fostemsavir | Specific |
| Long-acting | **Cabotegravir + rilpivirine IM Q monthly or Q2 monthly** | Adherence option |
| Capsid inhibitor | Lenacapavir SC Q6 mo | Multi-drug-resistant |

**Pre-ART workup:**

| Test |
|------|
| CD4, viral load |
| HIV genotype (resistance) |
| HLA-B*5701 if abacavir |
| HBV, HCV, syphilis, TB (IGRA), Toxo IgG, CMV IgG |
| CBC, BMP, LFTs, lipids, A1c, UA, pregnancy |
| Vaccinations (Pneumovax, COVID, Hep A/B, HPV, Tdap, flu, Shingrix) |

**Opportunistic infections by CD4:**

| CD4 | OI / risk |
|-----|-----------|
| <500 | Oral candidiasis, oral hairy leukoplakia (EBV), HPV / cervical cancer, bacterial pneumonia, TB, zoster |
| <200 | **PJP** — TMP-SMX prophylaxis |
| <100 | **Toxoplasmosis** — TMP-SMX (also covers PJP); **Cryptococcus** |
| <50 | **MAC**, CMV (retinitis, colitis), primary CNS lymphoma (EBV), disseminated histo |

**OI prophylaxis:**

| CD4 | Drug | OI |
|-----|------|-----|
| <200 | TMP-SMX | PJP |
| <100 | TMP-SMX (covers Toxo if Toxo IgG+) | Toxo |
| <50 (controversial; ART-era often skipped) | Azithromycin weekly | MAC |

Stop after CD4 sustained >200 for 3 months on ART.

**Common OIs and treatment highlights:**

| OI | Treatment |
|----|-----------|
| **PJP** | TMP-SMX 21 days; **adjunctive steroid if PaO2 <70 on RA or A-a >35**; pentamidine, atovaquone, dapsone alternatives |
| **Toxoplasmosis** | Sulfadiazine + pyrimethamine + leucovorin; ring-enhancing brain lesions (multiple) |
| **Cryptococcal meningitis** | Amphotericin B + flucytosine → fluconazole; serial LPs for ↑ICP |
| **CMV retinitis** | Valganciclovir / ganciclovir; ophthalmology |
| **MAC** | Azithromycin / clarithromycin + ethambutol ± rifabutin |
| **TB** | RIPE; if on ART, ART continued unless paradoxical IRIS |
| **Candidiasis** | Topical for thrush; fluconazole for esophageal |
| **Syphilis** | Penicillin G; LP if neuro symptoms or RPR ≥1:32 |
| **Kaposi sarcoma (HHV-8)** | ART; chemo or local for severe |

**IRIS (Immune Reconstitution Inflammatory Syndrome):**
- Worsening of OI 2-12 wk after ART start as immunity recovers
- Don't stop ART; treat underlying OI ± steroid

**PrEP / PEP:**

| | Detail |
|---|--------|
| **PrEP** (HIV-negative, high risk) | Daily tenofovir / FTC; **cabotegravir IM Q2mo**; testing every 3 mo |
| **PEP** (post-exposure) | Within 72h, ideally <2h; **3-drug ART for 28 days** (e.g., TDF/FTC + dolutegravir or raltegravir); HIV testing baseline + 6 wk + 3-4 mo |
| **Prevention** | U=U (Undetectable = Untransmittable); condoms; PrEP partner |

**Pregnancy:**

| Detail |
|--------|
| Continue / start ART (preferred dolutegravir-based now) |
| Check viral load at delivery — vaginal delivery if <1000 copies/mL; **C-section if higher** |
| IV zidovudine intrapartum if VL high |
| Newborn ART (zidovudine ± more depending on risk) |
| Avoid breastfeeding in resource-rich settings (formula); WHO recommends ART + breastfeed where formula not safe |

**Common gotchas:**
- **Acute HIV** has negative antibody — order HIV RNA when suspected
- **HLA-B*5701** screen before abacavir (HSR can be fatal)
- **TDF nephrotoxicity / bone loss** → switch to TAF
- **Efavirenz** → vivid dreams, depression, suicide; avoid in significant psych history
- **Dolutegravir + neural tube defect** signal **disproved** in larger studies — now used in pregnancy
- **PJP**: lactate elevated, hypoxia worse than CXR; high LDH; β-D-glucan ↑
- **Cryptococcal meningitis** ICP — serial LPs life-saving (more than antifungal alone)

**Rule of thumb:** 4th-gen Ag/Ab + viral load for acute HIV. INSTI-based ART for everyone, ASAP. PJP/Toxo prophylaxis at CD4 <200/<100. PEP <72h, PrEP for ongoing exposure. U=U. Don't stop ART for IRIS.
