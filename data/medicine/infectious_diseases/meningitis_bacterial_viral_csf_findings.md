### Meningitis

**CSF profiles:**

| Type | Opening pressure | WBC | Predominant | Glucose | Protein |
|------|------------------|-----|-------------|---------|---------|
| Bacterial | ↑↑ | **>1000** | **Neutrophils** | **↓↓** (<40 or CSF:serum <0.4) | **↑↑ (>200)** |
| Viral (aseptic) | Normal/↑ | <500 | Lymphocytes (early may be neutrophils) | Normal | ↑ mildly (50-200) |
| TB | ↑ | 100-500 | Lymphocytes | Low | High |
| Fungal (Crypto) | **↑↑↑** | 10-500 | Lymphocytes | Low | High |
| HSV encephalitis | Normal/↑ | <500 | Lymphocytes; **RBCs** | Normal | ↑ |

**Bacterial pathogens by age (community-acquired):**

| Age | Most common |
|-----|-------------|
| Neonate (0-1 mo) | **GBS, E. coli, Listeria** |
| 1-23 mo | Strep pneumoniae, Neisseria meningitidis |
| 2-50 yr | **S. pneumoniae, N. meningitidis** |
| >50 / immunocompromised / pregnancy | + **Listeria** (need ampicillin) |
| Hospital-acquired / post-neuro surgery | + Pseudomonas, Staph (MRSA) |
| HIV / immunocompromised | + Crypto, TB, Toxo, CMV, HSV |

**Empirical antibiotic regimen (adult):**

| Group | Regimen |
|-------|---------|
| 2-50 y, immunocompetent | **Ceftriaxone + vancomycin + dexamethasone** |
| >50, immunocompromised, pregnancy, alcoholism | + **Ampicillin** (Listeria) |
| Hospital-acquired / post-op | Cefepime or meropenem + vancomycin |
| Suspected encephalitis | Add **acyclovir** (HSV) |

**Dexamethasone (adjunctive):**
- 0.15 mg/kg q6h × 4 days
- Give **before or with first antibiotic dose** (not later)
- Greatest benefit in **S. pneumoniae**
- Continue if pneumococcal confirmed; can stop if other organism

**Workup:**

| Step | Detail |
|------|--------|
| Symptoms | Fever, headache, neck stiffness, altered mental status (any 2 of 4 = sensitive) |
| Exam | Kernig, Brudzinski, jolt accentuation, photophobia |
| Labs | CBC, chemistry, coags, blood cultures × 2 |
| **CT before LP** | If: ≥60 yr, immunocompromised, prior CNS disease, seizure <1 wk, papilledema, focal deficit |
| **Don't delay antibiotics** for imaging — **draw cultures, start empirical Tx, image, then LP** |
| LP | Opening pressure, cell count, glucose (with serum), protein, Gram stain, culture, PCR (HSV, enterovirus, meningococcus, pneumococcus) |
| Specific tests | Cryptococcal Ag, India ink (HIV); AFB / TB PCR; West Nile / arbo serology; syphilis if suspected |

**Special considerations:**

| Scenario | Detail |
|----------|--------|
| **Neisseria meningitidis** | Petechiae, purpura fulminans, Waterhouse-Friderichsen (adrenal hemorrhage); **ceftriaxone + chemoprophylaxis for close contacts** (rifampin, ciprofloxacin, ceftriaxone) |
| **Listeria** | Brainstem (rhombencephalitis), older / immunocompromised; **ampicillin + gentamicin synergy** |
| **HSV encephalitis** | Temporal lobe involvement (MRI), seizures, behavioral; PCR sensitive; **acyclovir 10 mg/kg q8h × 14-21 days** |
| **TB meningitis** | Subacute, basilar enhancement, hydrocephalus, vasculitis; RIPE + dex |
| **Cryptococcal** | HIV CD4 <100; ↑↑ ICP — serial therapeutic LPs vital |
| **Aseptic** | Enterovirus most common; supportive |

**Vaccinations:**

| Disease | Vaccine |
|---------|---------|
| Meningococcal | MenACWY routine 11-12 + 16; MenB for higher-risk teens / young adults / outbreaks; asplenia, complement deficiency need both |
| Pneumococcal | PCV13/15/20, PPSV23 per age + risk |
| H. flu type B | Routine childhood; near elimination of Hib meningitis |

**Encephalitis — distinct from meningitis:**

| Feature | Meningitis | Encephalitis |
|---------|------------|--------------|
| Cardinal | Stiff neck | **Altered mental status, behavior, seizures** |
| Imaging | Often normal | Parenchymal changes (HSV temporal) |
| Top cause | Bacterial (above) | **HSV-1**; arboviruses; autoimmune (NMDA-R) |

**Common gotchas:**
- **Empirical antibiotics within 1 hour** — never delay for LP / imaging if true meningitis suspected
- **Dexamethasone before antibiotics** — give right before / with first dose
- **HSV PCR negative early** — repeat in 24-48h if clinical suspicion remains
- **Cryptococcal ICP** — serial LPs may be life-saving more than antifungals
- **Subacute / chronic meningitis** (weeks) → think TB, fungal, syphilis, malignancy, autoimmune
- **Aseptic meningitis on NSAID, IVIG, sulfa, TMP-SMX** — drug-induced, resolves on discontinuation

**Rule of thumb:** Fever + headache + stiff neck + altered MS → cultures + empirical antibiotics + dex within 1h → CT then LP if criteria. CSF pattern narrows. Add ampicillin for >50 / immunocomp. Add acyclovir if encephalitis suspected. Pneumococcal is the dex-benefits group.
