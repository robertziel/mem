### Tuberculosis (TB)

**Latent vs active TB:**

| Feature | Latent (LTBI) | Active TB |
|---------|--------------|-----------|
| Symptoms | None | Cough >2-3 wk, fever, night sweats, weight loss, hemoptysis |
| CXR | Normal | Upper-lobe cavitary, infiltrates, lymphadenopathy, miliary |
| Sputum AFB / culture / NAAT | Negative | Positive |
| TST / IGRA | Positive | Positive |
| Contagious | No | **Yes** |

**Diagnosis of LTBI:**

| Test | Use |
|------|-----|
| **TST (PPD)** | Skin induration at 48-72h; thresholds vary by population |
| **IGRA** (QuantiFERON, T-SPOT) | Single visit; **not affected by BCG**; recommended in BCG-vaccinated |

**TST induration thresholds:**

| ≥5 mm positive | ≥10 mm positive | ≥15 mm positive |
|----------------|-----------------|-----------------|
| HIV | Recent immigrants from high-prev (<5 yr) | Low-risk persons |
| Recent TB contact | IVDU | (uncommon to test) |
| Fibrotic CXR (old TB) | Healthcare workers | |
| Organ transplant | High-risk medical (DM, CKD, silicosis, gastrectomy, bypass, low body weight, malignancies) | |
| Immunosuppression (≥15 mg pred ≥1 mo, anti-TNF) | Children <4, kids exposed to high-risk adults | |

**Active TB diagnosis:**

| Test | Detail |
|------|--------|
| Sputum × 3 (AFB smear + culture + NAAT) | NAAT also detects rifampin resistance (Xpert MTB/RIF) |
| CXR / CT | Cavitary upper-lobe, miliary, lymphadenopathy, consolidations |
| Bronchoscopy / EBUS / pleural / extra-pulm tissue | If sputum negative or extrapulmonary |
| HIV testing | Mandatory in all TB |

**LTBI treatment regimens:**

| Regimen | Duration | Notes |
|---------|----------|-------|
| **3HP** (Isoniazid + rifapentine weekly) | 12 weeks (DOT) | Preferred per CDC |
| 4R (rifampin daily) | 4 months | If INH intolerant or resistance suspected |
| 3HR (INH + rifampin daily) | 3 months | Alternative |
| 6-9 INH daily | 6-9 months | Older, longer; pyridoxine to prevent neuropathy |

Always **rule out active disease** before starting LTBI treatment (mono-therapy in active TB → resistance).

**Active TB treatment — RIPE × 4 then continuation:**

| Phase | Drugs | Duration |
|-------|-------|----------|
| Intensive | **R**ifampin + **I**soniazid + **P**yrazinamide + **E**thambutol | 2 months |
| Continuation | Rifampin + Isoniazid | 4 months (longer for cavitary, HIV, slow culture conversion) |
| Total | | 6 months minimum |

DOT (directly observed therapy) recommended.

**Drug toxicities:**

| Drug | Toxicity |
|------|----------|
| Rifampin | **Orange secretions** (urine, tears), **CYP inducer** (OCP, warfarin, ARV interactions), hepatotoxic, flu-like syndrome |
| Isoniazid (INH) | Hepatitis, **peripheral neuropathy** (give B6/pyridoxine), drug-induced lupus, hepatotoxic |
| Pyrazinamide | Hepatitis, **hyperuricemia** (gout), arthralgia |
| Ethambutol | **Optic neuritis** — color vision Δ, loss of acuity (baseline + monthly Ishihara) |

Baseline LFTs, vision testing, uric acid; monitor monthly.

**Drug-resistant TB:**

| Type | Definition |
|------|-----------|
| MDR-TB | Resistant to **isoniazid + rifampin** (at minimum) |
| Pre-XDR | MDR + fluoroquinolone or 2nd-line injectable resistance |
| XDR-TB | MDR + FQ + bedaquiline or linezolid resistance |

Treatment: **bedaquiline + pretomanid + linezolid (BPaL)** for 6 months — major advance for MDR/XDR.

**Special situations:**

| Situation | Approach |
|-----------|----------|
| Pregnancy | RIPE without pyrazinamide in some guidelines (or include); INH + B6 + rifampin + ethambutol |
| HIV | Treat TB first (or together); start ART within 2 wk if CD4 <50, within 8-12 wk if >50; **IRIS risk** |
| Child | Smaller pill burden; ethambutol ok if visual exam reliable |
| Liver disease | Avoid pyrazinamide; longer regimens with non-hepatotoxic drugs |
| Renal failure | Adjust ethambutol, pyrazinamide |
| Steroid + biologic candidates | Treat LTBI before starting |

**Extrapulmonary TB (~20% in HIV-negative; more in HIV):**

| Site | Detail |
|------|--------|
| Lymphatic (scrofula) | Cervical lymph nodes, painless |
| Pleural | Effusion (lymphocyte-predominant, low glucose, **ADA elevated**), pleural biopsy yields |
| **Miliary** | Disseminated, "millet-seed" CXR; high mortality without treatment |
| Bone (Pott) | Vertebral, especially thoracic |
| GU | Sterile pyuria, infertility |
| **CNS** (TB meningitis) | Subacute, basilar enhancement, hydrocephalus; **ADD steroid (dexamethasone)** |
| GI / peritoneal | Ascites, abdominal pain |

**Common gotchas:**
- **Don't treat LTBI without ruling out active TB** (single-drug in active disease → resistance)
- **Rifampin** wrecks OCP / warfarin / DOAC / HIV PI / methadone via CYP induction
- INH + alcohol → **higher hepatotoxicity** risk
- Ethambutol vision changes — counsel and check
- BCG vaccination → use **IGRA** (not TST) to avoid false positives
- Old healed TB (fibrotic upper lobe) on CXR + positive TST/IGRA → **treat as LTBI**
- HIV + TB: **start ART early** but watch for IRIS

**Rule of thumb:** Suspect TB → isolate, sputum × 3 + NAAT, CXR, HIV. RIPE × 2 mo → RH × 4 mo. LTBI: 3HP or 4R preferred. Always **rule out active disease before LTBI treatment**. Drug-resistant: BPaL.
