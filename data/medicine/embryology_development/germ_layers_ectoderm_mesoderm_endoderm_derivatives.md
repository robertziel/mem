### Germ Layer Derivatives

**Three germ layers form during gastrulation (week 3).**

**Ectoderm — "outside, brain, sensory":**

| Subdivision | Derivatives |
|-------------|-------------|
| Surface ectoderm | Epidermis, hair, nails, lens, cornea epi, salivary/sweat/mammary glands, anterior pituitary (Rathke's pouch), inner ear epi |
| Neuroectoderm | CNS (brain, spinal cord), retina, posterior pituitary, pineal gland, oligodendrocytes, astrocytes |
| Neural crest | PNS (Schwann, DRG, autonomic ganglia), melanocytes, adrenal medulla, enterochromaffin, parafollicular C cells, aorticopulmonary septum, pharyngeal arch cartilage, odontoblasts |

**Mesoderm — "muscle, bone, blood, kidney, gonads":**

| Subdivision | Derivatives |
|-------------|-------------|
| Paraxial (somites) | Skeletal muscle, axial skeleton, dermis of back |
| Intermediate | Kidneys, ureters, gonads, reproductive ducts |
| Lateral plate (somatic + splanchnic) | Body wall + visceral wall (smooth muscle of gut, cardiac muscle, blood vessels, blood, mesothelial linings) |

Also: spleen (from mesentery), connective tissue, dura mater, adrenal cortex.

**Endoderm — "innermost, gut tube and outpouchings":**

| Region | Derivatives |
|--------|-------------|
| Foregut | Esophagus, stomach, proximal duodenum, liver, pancreas, biliary tree, lungs, thyroid follicular cells |
| Midgut | Distal duodenum to proximal 2/3 transverse colon |
| Hindgut | Distal 1/3 transverse colon to upper rectum |
| Other | Anal canal (above pectinate), bladder, urethra, eustachian tube, middle ear epi, parathyroids, thymus |

**Quick recognition cheats:**

| If asked about… | Layer |
|----------------|-------|
| CNS / PNS | Neuroectoderm / neural crest |
| Adrenal cortex vs medulla | Mesoderm vs neural crest |
| Anterior vs posterior pituitary | Surface ectoderm (Rathke) vs neuroectoderm |
| Gut **lining** | Endoderm |
| Gut **muscle wall** | Mesoderm |
| Lung **epithelium** vs **vasculature** | Endoderm vs mesoderm |
| Pancreas | Endoderm |
| Spleen | **Mesoderm** (special — looks gut-like but it's not) |
| Aortopulmonary septum | **Neural crest** (defects → TGA, persistent truncus, tetralogy) |

**Neural crest defects:**

| Condition | Defect |
|-----------|--------|
| Hirschsprung | Failed migration → aganglionic colon |
| Tetralogy of Fallot, persistent truncus, TGA | AP septum migration |
| Treacher Collins, DiGeorge | Pharyngeal arch derivatives |
| Neurofibromatosis | Schwann/melanocyte lineage |
| Waardenburg | Pigmentary + sensorineural deafness |
| Albinism | Melanocyte enzyme defect |

**Common gotchas:**
- **Spleen = mesoderm** (despite foregut association) — supplied by celiac trunk because of location, not lineage
- **Adrenal medulla = neural crest**; adrenal cortex = mesoderm — different lineages, same organ
- **Both pituitary lobes have different origins**: anterior (oral ectoderm), posterior (neural ectoderm)
- **Thymus + parathyroids** are endoderm (pharyngeal pouches), not mesoderm

**Rule of thumb:** Outside + brain + crest derivatives = ecto. Muscle + bone + blood + kidney = meso. Gut tube lining + foregut buds (liver, pancreas, lungs) = endo.
