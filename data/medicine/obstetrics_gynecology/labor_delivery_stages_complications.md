### Labor & Delivery — Stages and Complications

**Three (or four) stages of labor:**

| Stage | Definition | Length (nullip / multip) |
|-------|-----------|--------------------------|
| **1st** — onset of regular contractions to full dilation (10 cm) | Latent (0-6 cm) + Active (6-10 cm) | <20 / <14h |
| **2nd** — full dilation to delivery of fetus | Pushing | <3h (with epidural) / <2h |
| **3rd** — delivery of placenta | | <30 min |
| **4th (informal)** — first hour postpartum | Hemodynamic stabilization | 1h |

**Active phase = ≥6 cm** (modern definition; older definitions used 4 cm).

**Cardinal movements (vertex):**

| Movement | Detail |
|----------|--------|
| Engagement | Biparietal at pelvic inlet |
| Descent | Through pelvis |
| Flexion | Chin to chest |
| Internal rotation | OA position |
| Extension | Head delivers |
| External rotation (restitution) | Shoulders align |
| Expulsion | Body delivers |

**Fetal heart rate categories (NICHD, 3-tier):**

| Category | Description | Action |
|----------|-------------|--------|
| **I (normal)** | Baseline 110-160, moderate variability, accelerations, **no late or variable decels** | Continue routine |
| **II (indeterminate)** | Anything not I or III | Workup, intrauterine resuscitation |
| **III (abnormal)** | Absent variability + **any** of: recurrent late, recurrent variable, bradycardia; or sinusoidal | **Urgent evaluation**, prepare for expedited delivery |

**Decelerations:**

| Type | Cause | Pattern |
|------|-------|---------|
| Early | Head compression | Mirrors contraction; **benign** |
| Late | Uteroplacental insufficiency | Onset after contraction peak; concerning |
| Variable | Cord compression | Abrupt, V-shaped, variable timing; common |
| Prolonged | Sustained ≥2 min | Multiple causes |

**Intrauterine resuscitation (cat II/III):**
- Reposition (left lateral)
- IV fluid bolus
- Stop / reduce oxytocin
- O2 (controversial benefit)
- Tocolysis (terbutaline) for tachysystole / refractory
- Treat hypotension (ephedrine, phenylephrine)

**Operative delivery:**

| Mode | Indications |
|------|-------------|
| Forceps / vacuum | Prolonged 2nd stage, maternal exhaustion, non-reassuring tracing at low station |
| C-section | Failure to progress, non-reassuring fetal status, malpresentation, placenta previa, prior classical C/S, eclampsia not stabilizing, cord prolapse |

**Postpartum hemorrhage (PPH):**

| Definition | ≥500 mL after vaginal, ≥1000 mL after C/S; or symptomatic blood loss |

**Causes — 4 T's:**

| Letter | Cause | Treatment |
|--------|-------|-----------|
| **T**one (atony, ~80%) | Uterine atony | Bimanual massage; uterotonics: **oxytocin** first → methylergonovine (avoid if HTN) → carboprost (avoid if asthma) → misoprostol; **tranexamic acid** within 3h; intrauterine balloon (Bakri); B-Lynch suture; uterine artery ligation; hysterectomy |
| **T**rauma | Lacerations, uterine inversion, rupture | Repair, manual reduction |
| **T**issue | Retained placenta | Manual removal, D&C |
| **T**hrombin | Coagulopathy (DIC, AFE) | Replace factors, treat cause |

**Shoulder dystocia (obstetric emergency):**

| Step (HELPERR) |
|----------------|
| Help — call team |
| Evaluate for episiotomy |
| Legs (McRoberts maneuver: hyperflex maternal hips) |
| Pressure (suprapubic) |
| Enter (rotational maneuvers — Rubin, Woods screw) |
| Remove posterior arm |
| Roll (all-fours / Gaskin) |

Avoid fundal pressure (worsens). Consequences: brachial plexus injury, hypoxic injury.

**Postpartum endometritis:**

| Risk | Treatment |
|------|-----------|
| C/S, prolonged labor / ROM, chorio | **Clindamycin + gentamicin** ± ampicillin (broader); afebrile 48h then stop |

**Group B strep prophylaxis:**

| Indication | Drug |
|------------|------|
| GBS-positive screen at 35-37 wk | **Penicillin G** intrapartum (cefazolin if PCN allergy low risk; clindamycin if high risk + sensitive; vancomycin if resistant or clindamycin-resistant) |
| GBS bacteriuria any time | Same |
| Prior infant with GBS disease | Same |
| Unknown status + risk factors (preterm, ROM ≥18h, intrapartum fever) | Treat |

**Magnesium sulfate uses (OB-specific):**

| Use | Detail |
|-----|--------|
| **Eclampsia / severe preeclampsia** seizure prophylaxis / treatment | Loading + maintenance; monitor reflexes (hyporeflexia → toxicity), respirations |
| **Neuroprotection** for preterm <32 wk | Reduces cerebral palsy |
| Tocolysis (controversial, less now) | — |

Mg toxicity: ↓ DTRs, RR, hypotension → **calcium gluconate** rescue.

**Preterm labor management:**

| GA | Action |
|----|-------|
| <34 wk | **Antenatal corticosteroids** (betamethasone 12 mg × 2) |
| 24-32 wk | **Mg for neuroprotection** |
| <34 wk | Tocolysis (nifedipine, indomethacin <32 wk) for short delay (steroid window) |
| <34 wk | GBS prophylaxis if labor active |
| Late preterm 34-37 wk | Steroid course considered |

**Common gotchas:**
- **Failure to progress** — formal definitions: ≥4 hr no change in active phase with adequate contractions; protracted labor doesn't always need C/S
- **Cord prolapse** — emergent C/S; elevate presenting part with examiner's hand; knee-chest position
- **Uterine rupture** — sudden severe pain, loss of station, fetal distress; classical scar > LTCS; prior C/S risk
- **Amniotic fluid embolism** — sudden cardiac collapse + DIC at delivery; supportive
- **Magnesium toxicity** — keep calcium gluconate at bedside
- **RhoGAM** post-delivery within 72h if Rh-negative mother + Rh-positive infant

**Rule of thumb:** 3 stages; active phase ≥6 cm; cat III tracing → urgent delivery. PPH = 4 T's, oxytocin first. Shoulder dystocia → HELPERR. GBS+ → intrapartum penicillin. Preterm <34 wk → steroids + Mg.
