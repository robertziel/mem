### Prenatal Care — Visits & Screening

**Visit schedule (uncomplicated):**

| Trimester | Visits |
|-----------|--------|
| 1st | Initial 6-8 wk → every 4 wk |
| 2nd | Every 4 wk |
| 28-36 wk | Every 2 wk |
| 36-delivery | Weekly |

**Initial visit labs:**

| Category | Tests |
|----------|-------|
| Standard | CBC, blood type + Rh + antibody screen, RPR / VDRL, HIV, HBsAg, HCV, rubella IgG, varicella, urinalysis + culture, urine pregnancy, Pap (if due), GC/Chlamydia, TSH if indicated |
| Genetic | Cell-free DNA (NIPT) at 10 wk, or 1st-trimester combined screen 11-13 wk, or quad screen 15-22 wk; carrier screening (CF, SMA, hemoglobinopathy ± expanded panel) |
| Risk-based | TB (IGRA), tox screen, lead, parvovirus, CMV, Toxoplasma |

**First trimester (1-13 wk):**

| Test | Detail |
|------|--------|
| Confirm viability | Transvaginal US 6-9 wk |
| Dating | CRL most accurate <13 wk |
| Aneuploidy screening | NIPT (best detection rate, after 10 wk); first-trimester combined (NT + PAPP-A + β-hCG); quad screen alt |
| CVS | 10-13 wk diagnostic |

**Second trimester (14-27 wk):**

| Test | Detail |
|------|--------|
| **Anatomy ultrasound** | 18-22 wk |
| Quad screen | If 1st-trimester missed (15-22 wk): AFP, hCG, estriol, inhibin A |
| Amniocentesis | 15+ wk diagnostic |
| Glucose challenge | 24-28 wk (1h 50g GCT — earlier if high risk) |
| Fetal kick counts | Begin ~28 wk |

**Third trimester (28-40+ wk):**

| Time | Test/intervention |
|------|-------------------|
| 28 wk | Repeat CBC, RhoGAM if Rh-negative + Ab screen-negative |
| 28-32 wk | Tdap (every pregnancy) |
| 32-36 wk | RSV vaccine (Sept-Jan); maternal influenza any time |
| **35-37 wk** | **GBS (Group B strep) screen** — vaginal-rectal swab; intrapartum penicillin if positive |
| 36 wk | Position assessment; ECV considered for breech |
| 38-39 wk | Plan delivery; induction by 41 wk |

**RhoGAM (anti-D Ig) indications:**

| Indication |
|-----------|
| Rh-negative mother at **28 wk** |
| Postpartum if baby Rh-positive (within 72h) |
| Bleeding events (threatened miscarriage, ectopic, abortion, amniocentesis, CVS, trauma) |
| Higher dose if larger fetal-maternal hemorrhage (Kleihauer-Betke test) |

**Vaccinations during pregnancy:**

| Vaccine | When |
|---------|------|
| Tdap | **27-36 wk every pregnancy** (passive immunity for newborn) |
| Influenza | Any trimester (inactivated) |
| **RSV (RSVPreF)** | 32-36 wk during RSV season (or give nirsevimab to baby) |
| COVID | Per current guidance |
| Hepatitis B | If at risk |
| Avoid | **Live**: MMR, varicella, yellow fever (give pre/post-pregnancy) |

**Screening for gestational diabetes (GDM):**

| Step | Detail |
|------|--------|
| 24-28 wk **1h 50g GCT** | If ≥140 → 3h 100g OGTT |
| Diagnosis (Carpenter-Coustan, ≥2 abnormal): | Fasting ≥95, 1h ≥180, 2h ≥155, 3h ≥140 |
| Early screening if obesity, prior GDM, family history, PCOS | At first visit |

**GDM treatment:**

| Step | Treatment |
|------|-----------|
| First | Diet (med carb), exercise |
| Targets | FBG <95, 1h <140, 2h <120 |
| Insulin | Preferred medication if needed |
| Metformin / glyburide | Used in some settings (cross placenta — counsel) |
| Postpartum | 75g OGTT 4-12 wk postpartum (T2DM screen) |

**Hypertensive disorders of pregnancy:**

| Diagnosis | Criteria |
|-----------|----------|
| Chronic HTN | BP ≥140/90 before 20 wk |
| Gestational HTN | New BP ≥140/90 after 20 wk, no proteinuria |
| **Preeclampsia** | New BP ≥140/90 + proteinuria (≥300 mg/24h or P/Cr ≥0.3) **OR** new end-organ dysfunction |
| Severe features | BP ≥160/110, plt <100K, ↑LFTs, AKI, pulmonary edema, persistent visual / cerebral, RUQ pain |
| **Eclampsia** | Preeclampsia + seizure |
| HELLP | Hemolysis, ↑Liver, ↓Plt — variant of severe preeclampsia |

**Preeclampsia management (high-yield):**

| Severity | Action |
|----------|--------|
| Mild without severe features | Expectant to 37 wk |
| **Severe features any GA** | Delivery indicated (>34 wk); 34 wk steroid + delivery; <34 wk individualize |
| Eclampsia | **Magnesium sulfate** + delivery; antihypertensive (labetalol IV, hydralazine, nifedipine) |
| Postpartum BP | May worsen first 1-2 wk |

**Aspirin prophylaxis:**

| Indication | Dose / time |
|------------|-------------|
| ≥1 high-risk factor (prior preeclampsia, multifetal, chronic HTN, T1/T2 DM, CKD, autoimmune) **OR** ≥2 moderate risk factors | **Low-dose aspirin 81 mg starting 12-28 wk through delivery** |

**Common drug categories during pregnancy:**

| Avoid | Examples |
|-------|----------|
| **Teratogens** | ACEi/ARB, warfarin, methotrexate, valproate, isotretinoin, lithium (1st), tetracycline (2nd-3rd), sulfonamide (3rd, kernicterus), fluoroquinolone (cartilage), MMF, leflunomide, statins (counsel; risk re-evaluated), live vaccines |
| Allowed | Acetaminophen, most antibiotics (β-lactams, macrolides, clindamycin), labetalol, methyldopa, hydralazine, nifedipine, insulin, hydroxychloroquine, sertraline / certolizumab |

**Common gotchas:**
- **Folic acid 400-800 mcg / d** preconception + 1st trimester (4 mg if prior NTD or AED use)
- **VTE risk ↑** in pregnancy — anticoagulate with **LMWH** (warfarin teratogenic 1st tri, fetal bleed late)
- **Gestational HTN can become preeclampsia** — keep checking BP / urine
- **Listeria** — soft cheese, deli meat, unpasteurized; pregnant women warned
- **Toxoplasma** — cat litter, undercooked meat
- **Pertussis** — Tdap each pregnancy (newborn antibody)
- **Aspirin** is preventive; once preeclampsia diagnosed, doesn't reverse

**Rule of thumb:** Confirm + date + screen aneuploidy first trimester. Anatomy + GDM + Tdap + GBS through trimesters. Aspirin 81 if high preeclampsia risk. Magnesium for preeclampsia/eclampsia. RhoGAM at 28 wk + post-event. Avoid teratogens.
