### Otitis Media and Otitis Externa

**Three "otitis" patterns:**

| Type | Site | Cause | Pain on tragal tug |
|------|------|-------|---------------------|
| **Acute otitis media (AOM)** | Middle ear | Viral upper resp → bacterial: **Strep pneumo, H. flu (NTHi), Moraxella** | No |
| **Otitis media with effusion (OME)** | Middle ear effusion without signs of infection | Eustachian dysfunction post-AOM or allergy | No |
| **Otitis externa (swimmer's ear)** | External canal | **Pseudomonas, Staph aureus** | **Yes** |

**Acute otitis media — diagnosis (AAP 2013):**

| Required |
|----------|
| Acute onset (within 48h) |
| **Bulging tympanic membrane** OR **new otorrhea** not from external otitis OR moderate-severe TM swelling with otalgia |
| Middle ear effusion (immobile TM on pneumatic otoscopy) |

**AOM treatment — observe vs antibiotics:**

| Group | Approach |
|-------|----------|
| <6 mo | **Antibiotics always** |
| 6-23 mo, **bilateral or severe** (≥48h or temp ≥39 / severe pain) | Antibiotics |
| 6-23 mo, unilateral non-severe | Antibiotics or **observation 48-72h** with shared decision |
| ≥2 yr, severe | Antibiotics |
| ≥2 yr, non-severe | Antibiotics or observation |
| Otorrhea / craniofacial / immune issues | Antibiotics |

**First-line antibiotic:**

| Choice | Drug |
|--------|------|
| **First-line** | **Amoxicillin** 80-90 mg/kg/day divided BID × 5-10 days (5d for ≥2 yr non-severe; 10d for younger / severe) |
| If recently on amox / persistent / non-responsive at 48-72h | Amoxicillin-clavulanate |
| PCN allergy (mild) | Cefdinir, cefuroxime, cefpodoxime |
| PCN allergy (severe) | Macrolide (less effective) or clindamycin |

**Pain management:** acetaminophen / ibuprofen; topical anesthetic drops if perforation excluded.

**Recurrent / chronic:**

| Indication for tympanostomy tubes |
|----------------------------------|
| ≥3 episodes in 6 mo or ≥4 in 12 mo |
| Persistent OME ≥3 mo bilateral |
| Hearing loss / speech delay associated |

**Complications of AOM:**

| Complication | Detail |
|--------------|--------|
| TM perforation | Often resolves; topical antibiotic if persistent otorrhea |
| Mastoiditis | Tender, edematous over mastoid; imaging + IV antibiotics ± surgery |
| Cholesteatoma | Pearly retraction pocket; surgical |
| Meningitis, brain abscess, lateral sinus thrombosis | Rare but serious |
| Facial nerve palsy | Adjacent inflammation |
| Conductive hearing loss | Usually transient |

**Otitis externa:**

| Feature | Detail |
|---------|--------|
| Pain, tragal tenderness | Hallmark |
| Discharge, erythema, edema of canal | TM normal if visible |
| Causes | Water exposure, trauma, eczema, foreign body |
| Pathogens | **Pseudomonas, Staph aureus**, fungal less commonly |

**Otitis externa treatment:**

| Severity | Treatment |
|----------|-----------|
| Standard | **Topical fluoroquinolone (ofloxacin)** ± steroid (if intact TM); ciprofloxacin-dexamethasone (Ciprodex) |
| Aminoglycoside drops | Avoid if TM perforation (ototoxicity) |
| Severe / fungal | Ear wick + cleansing; antifungal (clotrimazole) for fungal |
| Pain | Acetaminophen/NSAID |
| Avoid water | During treatment |

**Malignant (necrotizing) otitis externa:**

| Setting | Detail |
|---------|--------|
| Diabetic / immunocompromised | Pseudomonas extends to skull base |
| Severe pain, granulation tissue at osseo-cartilaginous junction | Sign |
| Imaging (CT/MRI), bone scan | Confirms |
| Treatment | **Long-course IV anti-pseudomonal** (cipro, pip-tazo, cefepime); ENT consult |
| Mortality | Significant if not aggressively treated |

**Specific scenarios:**

| Scenario | Detail |
|----------|--------|
| Tympanic membrane perforation | Avoid water; usually heals; observe; ENT for persistent / large |
| Foreign body | Remove (insect — kill first with mineral oil, then irrigate); urgent if button battery |
| Cerumen impaction | Drops, irrigation (avoid in TM perforation), curette; **don't insert sharp objects** |
| Bullous myringitis | Mycoplasma classic; analgesics + macrolide if AOM features |
| TMJ pain mimicking ear pain | Click, jaw movement; refer dental |
| Referred pain (oropharynx, dental, cervical spine, neck mass) | Examine sources |

**Common gotchas:**
- **Don't routinely treat OME** with antibiotics — observation, hearing testing if persistent
- **Aminoglycoside drops** ototoxic if TM perforated → use **ofloxacin** instead
- **Pneumatic otoscopy** is essential to confirm AOM (immobile TM)
- **Mastoid tenderness** + AOM → suspect mastoiditis → image + IV antibiotics
- **Diabetic with severe ear pain out of proportion** + granulation tissue → necrotizing otitis externa
- **Button battery in ear** → urgent removal (caustic injury risk)
- **Cholesteatoma** suspected if recurrent foul-smelling otorrhea + TM retraction; ENT referral

**Rule of thumb:** Bulging TM + otalgia = AOM → amoxicillin first-line. OME = effusion without inflammation, often watch. Otitis externa = pain on tragal tug → ofloxacin (avoid aminoglycoside if TM perforated). Severe diabetic ear pain → necrotizing otitis externa.
