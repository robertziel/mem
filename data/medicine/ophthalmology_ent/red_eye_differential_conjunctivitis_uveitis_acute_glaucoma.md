### Red Eye — Differential and Approach

**The high-yield differential:**

| Cause | Pain | Vision | Discharge | Pupil | Photophobia |
|-------|------|--------|-----------|-------|-------------|
| **Viral conjunctivitis** | Mild irritation | Normal | Watery | Normal | Mild |
| **Bacterial conjunctivitis** | Mild | Normal | **Mucopurulent** | Normal | Mild |
| **Allergic conjunctivitis** | Itching > pain | Normal | Watery | Normal | Mild |
| **Subconjunctival hemorrhage** | None | Normal | None | Normal | None |
| **Episcleritis** | Mild | Normal | None | Normal | Mild |
| **Scleritis** | **Deep, severe**, awakens at night | May be ↓ | None | Normal | Yes |
| **Anterior uveitis (iritis)** | Yes | Variable | None | **Small, sluggish** | **Severe** |
| **Acute angle-closure glaucoma** | **Severe** | **↓**, halos | None | **Mid-fixed, hazy cornea** | Yes |
| **Corneal abrasion / ulcer / keratitis** | Severe, foreign body | ↓ | Tearing | Normal | Yes |
| **Endophthalmitis** | Severe | ↓ | ± | Hypopyon | Yes |

**Red flags requiring urgent ophthalmology referral:**

| Red flag |
|----------|
| Severe pain |
| Vision loss |
| Photophobia |
| Pupil abnormality |
| Ciliary flush (limbal redness) |
| Hazy cornea |
| Hypopyon (pus in anterior chamber) |
| Fluorescein uptake |
| History of contact lens use + red eye |
| Hyphema (blood in anterior chamber) |
| Trauma |

**Conjunctivitis (most common):**

| Type | Cause | Treatment |
|------|-------|-----------|
| Viral (most adenovirus) | Adenovirus, sometimes herpes | Cold compress, lubricant, hand hygiene; usually self-limited |
| Bacterial | Staph, Strep, H. flu, Moraxella | Topical antibiotics (erythromycin, polymyxin-trimethoprim, fluoroquinolone if contact lens) |
| Gonococcal | N. gonorrhoeae | **Hyperacute, severe purulent**, needs IM ceftriaxone + topical + saline irrigation; **emergency** (corneal perforation) |
| Chlamydial (adult) | C. trachomatis | Doxycycline / azithromycin; treat partner |
| Allergic | IgE-mediated | Topical antihistamine / mast cell stabilizer (olopatadine), cool compress, allergen avoidance |
| **Neonatal** | Chemical (silver nitrate, day 1) → Gonococcal (2-5 d) → Chlamydial (5-14 d) → HSV | Erythromycin prophylaxis fails for chlamydial (use systemic) |

**Acute angle-closure glaucoma — emergency:**

| Feature |
|---------|
| Severe pain, headache, nausea/vomiting |
| Halos around lights |
| ↓ vision |
| **Mid-dilated, fixed pupil**, hazy cornea, hard globe |
| Risk: hyperopia, dilation (anticholinergic, antihistamine, antidepressant), Asian descent |

**Treatment:**

| Step | Drugs |
|------|-------|
| 1 | Topical β-blocker (timolol), α2-agonist (apraclonidine), miotic (pilocarpine 1-2% only after IOP ↓) |
| 2 | Topical CAI (dorzolamide), prostaglandin analog |
| 3 | **Oral / IV acetazolamide**, IV mannitol if severe |
| 4 | **Definitive: laser peripheral iridotomy** |

**Anterior uveitis (iritis):**

| Item | Detail |
|------|--------|
| Pain, photophobia, ciliary flush | Hallmark |
| Cells + flare in anterior chamber | Slit lamp |
| Synechiae (pupil adhesions) | Long-standing |
| Causes | HLA-B27 (AS, IBD, reactive arthritis, psoriatic), sarcoid, Behçet, JIA, syphilis, TB, herpes |
| Treatment | Topical steroid + cycloplegic (prevent synechiae) — needs ophthalmology |

**Scleritis:**

| Feature |
|---------|
| Deep, severe pain (boring) |
| Often associated with autoimmune (RA, GPA, lupus, IBD, relapsing polychondritis) |
| Treat: NSAID (mild), oral steroid + immunosuppressant (severe) |

**Episcleritis** — superficial, mild, often idiopathic, self-limited; **phenylephrine blanches** (vs scleritis, deeper vessels don't blanch).

**Corneal abrasion:**

| Workup | Detail |
|--------|--------|
| Fluorescein + slit lamp / Wood's | Reveals defect |
| **Contact lens wearer** → urgent | Pseudomonas keratitis risk; **fluoroquinolone topical** |
| Treatment | Topical antibiotic (erythromycin, polymyxin / trimethoprim); **don't patch contact-lens-related** |
| Pain control | Topical NSAID short-term; cycloplegic for deeper pain; **avoid topical anesthetic** longer than exam (corneal toxicity) |

**Herpes simplex keratitis (dendritic ulcer):**

| Feature | Detail |
|---------|--------|
| Recurrent | Pain, photophobia, decreased vision |
| Fluorescein | **Dendritic / branching pattern** |
| **Avoid steroids** | (Worsens) — needs antiviral first (oral acyclovir, valacyclovir, or topical trifluridine, ganciclovir gel) |
| Refer | Ophthalmology |

**Herpes zoster ophthalmicus (V1):**

| Hutchinson sign | Vesicles on tip of nose → nasociliary nerve involvement → eye disease likely |
| Treatment | Oral antiviral (valacyclovir / acyclovir) + ophthalmology referral |

**Subconjunctival hemorrhage:**

| Feature | Detail |
|---------|--------|
| Bright red blood under conjunctiva | Often after Valsalva, trauma, anticoagulant |
| Painless, normal vision | Reassure; resolves 1-2 wk |
| Recurrent → coag workup | — |

**Common gotchas:**
- **Contact-lens red eye = Pseudomonas keratitis** until proven otherwise → urgent ophthalmology + fluoroquinolone topical
- **Acute angle-closure glaucoma** can be precipitated by anticholinergic / dilating drops — monocular blindness if delayed
- **Don't give topical steroids** in red eye without diagnosis (worsens HSV, fungal, pseudomonas)
- **Hyperacute purulent conjunctivitis in adult** → gonococcal → systemic ceftriaxone urgent
- **Trauma + red eye + decreased vision** → think globe rupture (Seidel sign), hyphema, retrobulbar hemorrhage
- **Ophthalmia neonatorum**: chlamydia is now most common in resource-rich settings; gonococcal is sight-threatening

**Rule of thumb:** Triage by pain, vision, photophobia, pupil. Severe + photophobia + pupil change + ↓ vision = uveitis / glaucoma / keratitis / endophthalmitis → ophthalmology. Most red eye is conjunctivitis (allergic / viral / bacterial). Contact-lens user → urgent referral. No empirical steroids.
