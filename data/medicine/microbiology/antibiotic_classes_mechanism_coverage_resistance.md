### Antibiotic Classes — Mechanism, Coverage, Resistance

**Cell wall (β-lactams + others) — bactericidal:**

| Class | Examples | Spectrum | Resistance mechanism |
|-------|----------|----------|---------------------|
| Penicillins (natural) | Pen G, Pen V | G+ cocci (strep), Treponema | β-lactamase |
| Amino-PCN | Ampicillin, amoxicillin | + Listeria, enterococcus, some G− | β-lactamase |
| Anti-staph PCN | Nafcillin, oxacillin, dicloxacillin | MSSA only | mecA → MRSA |
| Anti-pseudomonal | Piperacillin (-tazo) | Broad G+/−/anaerobes + pseudo | ESBL, AmpC |
| Cephalosporins (1st-5th) | Cefazolin → ceftaroline | Generation-dependent | β-lactamase, ESBL |
| Carbapenems | Meropenem, imipenem, ertapenem | Very broad (no MRSA, no atypicals) | KPC, NDM (carbapenemases) |
| Monobactam | Aztreonam | G− only (incl. pseudo) | Used in PCN allergy |
| Glycopeptides | Vancomycin | G+ only (incl. MRSA) | VRE (D-Ala→D-Lac) |
| Lipopeptides | Daptomycin | G+ (incl. VRE, MRSA); **no lung** (surfactant) | rare |

**Cephalosporin generations:**

| Gen | Drugs | Coverage |
|-----|-------|----------|
| 1st | Cefazolin, cephalexin | G+ (MSSA, strep), some G− |
| 2nd | Cefoxitin, cefuroxime | + H. flu, anaerobes (cefoxitin) |
| 3rd | Ceftriaxone, ceftazidime, cefotaxime | Broader G−, **ceftriaxone for meningitis**; **ceftazidime → pseudomonas** |
| 4th | Cefepime | Pseudo + G+ |
| 5th | Ceftaroline | **MRSA** + G− |

**Protein synthesis — usually bacteriostatic:**

| Class | Subunit | Examples | Notes |
|-------|---------|----------|-------|
| Aminoglycosides | 30S | Gentamicin, tobra, amikacin | Bactericidal; nephro/oto-toxic; **synergy with β-lactam** |
| Tetracyclines | 30S | Doxycycline, minocycline, tigecycline | Atypicals, rickettsia, lyme, MRSA (some) |
| Macrolides | 50S | Azithromycin, clarithromycin, erythromycin | Atypicals, **QT↑**, CYP3A4 inhibitor |
| Lincosamide | 50S | Clindamycin | Anaerobes (above diaphragm), **C. diff risk** |
| Chloramphenicol | 50S | — | Aplastic anemia, gray baby |
| Oxazolidinones | 50S | Linezolid | MRSA, VRE; serotonin syndrome (MAOI), thrombocytopenia |
| Streptogramins | 50S | Quinupristin/dalfopristin | VRE |

**Nucleic acid / folate:**

| Class | Mechanism | Examples | Notes |
|-------|-----------|----------|-------|
| Fluoroquinolones | DNA gyrase / topo IV | Cipro, levo, moxi | Tendon rupture, QT↑, dysglycemia, pediatric caution |
| Rifamycins | RNA polymerase | Rifampin | Orange secretions, CYP **inducer**, TB |
| Metronidazole | DNA damage (free radicals) | — | Anaerobes (below diaphragm), C. diff, protozoa; disulfiram + EtOH |
| Sulfa + trimethoprim | DHPS / DHFR (folate) | TMP-SMX | UTI, PJP, MRSA (skin/soft tissue) |
| Nitrofurantoin | Multiple (free radicals) | — | Uncomplicated UTI only |

**Quick "what to use" table:**

| Pathogen / scenario | First-line |
|---------------------|-----------|
| MRSA | Vanc (IV), TMP-SMX or doxy (PO/SSTI), linezolid, daptomycin |
| Pseudomonas | Pip-tazo, cefepime, ceftazidime, meropenem, cipro/levo, amino |
| Anaerobes (above diaphragm) | Clindamycin |
| Anaerobes (below diaphragm) | Metronidazole |
| Atypical pneumonia (Myco/Chlamy/Legi) | Macrolide or doxy |
| Enterococcus (incl. VRE) | Amp/vanc → linezolid/dapto |
| C. diff | Oral vanc, fidaxomicin |
| Rickettsia / Lyme / chlamydia | Doxycycline |
| TB (RIPE) | Rifampin, INH, pyrazinamide, ethambutol |

**Resistance mechanisms (how organisms evade):**

| Mechanism | Examples |
|-----------|----------|
| β-lactamase / ESBL / carbapenemase | Most G− |
| Altered PBP | MRSA (mecA), pen-resistant strep |
| Altered ribosomal target | Macrolide, aminoglycoside |
| Drug efflux pumps | Tetracyclines |
| Altered metabolic enzyme | Sulfa, TMP |
| Altered cell wall (D-Ala → D-Lac) | VRE |
| Reduced uptake / porin loss | Aminoglycosides, β-lactams |

**Common gotchas:**
- **Daptomycin** is inactivated by lung surfactant — never use for pneumonia
- **Aminoglycosides** need O2 for uptake → useless against anaerobes
- **Linezolid** is reversible MAOI → serotonin syndrome with SSRI
- **Clindamycin** has the highest C. diff risk
- **Vancomycin** alone → "red man" (rate-related, not allergy); slow infusion or pretreat with antihistamine
- **Rifampin** is a CYP inducer — wrecks OCPs, warfarin, HIV meds

**Rule of thumb:** β-lactam = wall (cidal). 30S/50S = ribosome (mostly static, except amino + linezolid). Quinolones = gyrase. Vanc = G+ only. Metronidazole = below-diaphragm anaerobes + protozoa.
