### Gram Stain & Bacterial Classification

**Gram stain at a glance:**

| Result | Cell wall | Color | Examples |
|--------|-----------|-------|----------|
| Gram-positive | Thick peptidoglycan + teichoic acid | Purple | Staph, Strep, Bacillus, Listeria, Clostridium, Corynebacterium |
| Gram-negative | Thin peptidoglycan + outer membrane (LPS) | Pink | E. coli, Klebsiella, Pseudomonas, Salmonella, Neisseria, H. flu |

**Atypical (don't gram stain well):**

| Organism | Why |
|----------|-----|
| Mycobacteria | Mycolic acid wall — use **acid-fast** (Ziehl-Neelsen) |
| Mycoplasma | **No cell wall** — penicillins useless |
| Treponema, Borrelia, Leptospira | Too thin — darkfield, silver stain |
| Rickettsia, Chlamydia | Obligate intracellular |
| Legionella | Stains poorly — silver stain |

**Gram-positive cocci (G+ cocci):**

| Organism | Catalase | Coagulase / Hemolysis / Test |
|----------|----------|-----|
| Staph aureus | + | Coagulase + |
| Staph epidermidis / saprophyticus | + | Coagulase −; novobiocin S (epi) / R (sapro) |
| Strep pyogenes (Group A) | − | β-hemolytic, **bacitracin S** |
| Strep agalactiae (Group B) | − | β-hemolytic, **bacitracin R**, CAMP+ |
| Strep pneumoniae | − | α-hemolytic, **optochin S**, bile-soluble |
| Viridans strep | − | α-hemolytic, **optochin R**, bile-insoluble |
| Enterococcus | − | γ-hemolytic, grows in 6.5% NaCl + bile |

**Gram-positive rods (G+ rods):**

| Organism | Spores? | Clue |
|----------|---------|------|
| Bacillus anthracis / cereus | + (aerobic) | Anthrax, food poisoning (reheated rice) |
| Clostridium (botulinum, tetani, perfringens, difficile) | + (anaerobic) | Toxin-mediated diseases |
| Listeria monocytogenes | − | Tumbling motility, cold growth, pregnant + neonate |
| Corynebacterium diphtheriae | − | Pseudomembrane, exotoxin (ADP-ribosylates EF-2) |

**Gram-negative cocci / coccobacilli:**

| Organism | Clue |
|----------|------|
| Neisseria meningitidis | Petechiae, Waterhouse-Friderichsen, ferments maltose |
| Neisseria gonorrhoeae | No vaccine, no maltose, gonococcal arthritis |
| Moraxella catarrhalis | Otitis, sinusitis, COPD exacerbation |
| Haemophilus influenzae | Needs factors V (NAD) + X (heme); type B → meningitis pre-vaccine |
| Bordetella pertussis | Whooping cough, lymphocytosis |

**Gram-negative rods (lactose fermentation key):**

| Group | Organisms |
|-------|-----------|
| Lactose fermenters (pink on MacConkey) | E. coli, Klebsiella, Enterobacter, Citrobacter, Serratia |
| Slow / weak | Shigella (some), Yersinia, Citrobacter |
| Non-lactose, **oxidase-negative** | Shigella, Salmonella, Proteus |
| Non-lactose, **oxidase-positive** | Pseudomonas (blue-green pigment, fruity grape odor), Vibrio, Helicobacter, Campylobacter |

**Special / zoonotic:**

| Organism | Source |
|----------|--------|
| Brucella | Unpasteurized dairy, livestock |
| Francisella tularensis | Rabbits, ticks |
| Pasteurella multocida | Cat/dog bites |
| Bartonella henselae | Cat scratch |
| Yersinia pestis | Fleas, prairie dogs |
| Leptospira | Water + animal urine |

**Acid-fast (mycobacteria):**

| Organism | Disease |
|----------|---------|
| M. tuberculosis | TB, cavitary apex, latent → active |
| M. leprae | Leprosy (Hansen) |
| M. avium-intracellulare (MAC) | HIV CD4 <50, disseminated |
| M. kansasii, abscessus, marinum | Skin/lung |

**Common gotchas:**
- Gram **stain alone** can mislead (low organisms, prior antibiotics) — culture confirms
- Mycoplasma: **no cell wall** → β-lactams useless, treat with macrolide / doxy
- Pseudomonas: **green pus**, fruity smell, oxidase+, treat with anti-pseudomonal β-lactam (pip-tazo, cefepime, mero, ceftazidime) ± aminoglycoside
- Lactose-fermenting + mucoid colony → **Klebsiella**; lactose+ + green metallic sheen on EMB → **E. coli**

**Rule of thumb:** Gram color first, then morphology, then biochemistry (catalase, coagulase, hemolysis). For G− rods, lactose ± oxidase narrows it fast.
