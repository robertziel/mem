### Informed Consent

**Required elements (all must be present):**

| Element | Detail |
|---------|--------|
| **Disclosure** | Diagnosis, prognosis, proposed treatment, alternatives (including no treatment), risks, benefits, expected outcomes |
| **Comprehension** | Patient understands at appropriate level (avoid jargon, use teach-back) |
| **Voluntariness** | No coercion (family pressure, financial duress, institutional) |
| **Capacity** | Patient can make this decision (decision-specific) |
| **Documentation** | Written + signed for major procedures; verbal for routine |

**What to disclose (the "reasonable person" standard predominates in US):**

| Item |
|------|
| Nature of the condition |
| Nature of the proposed treatment |
| Material risks (those a reasonable person would want to know) |
| Benefits |
| Alternatives, including no treatment |
| Probable outcomes |
| Recovery / aftercare expectations |

**Capacity assessment — 4 elements:**

| Component | Question to test |
|-----------|------------------|
| **Communicate a choice** | "What do you want to do?" |
| **Understand** | "Tell me in your own words what we discussed" (teach-back) |
| **Appreciate** | "What does this mean for you specifically?" |
| **Reason / weigh** | "How did you decide?" "Tell me the reasons for and against" |

Capacity is **decision-specific** + **time-specific** (can fluctuate). A capacitated patient may refuse intervention even if it's life-saving.

**Capacity vs competency:**

| Capacity | Competency |
|----------|-----------|
| Clinical judgment | Legal determination |
| Decision-specific | Global |
| Determined by physician | Determined by court |
| Can fluctuate | Stable until court reverses |

**Common factors impairing capacity (assess and treat reversible causes):**

| Cause |
|-------|
| Delirium |
| Dementia |
| Acute psychosis |
| Severe depression / suicidality |
| Intoxication |
| Hypoxia, hypoglycemia, electrolyte derangement |
| CNS event (stroke, trauma) |
| Severe pain |
| Fear / acute anxiety |
| Language barrier (use professional interpreter, not family) |

**Exceptions to informed consent:**

| Exception | Detail |
|-----------|--------|
| **Emergency** | Life- / limb-threatening, unable to consent, no surrogate immediately available — implied consent |
| **Therapeutic privilege** (rare, controversial) | Withholding information that would seriously harm — narrow + must document |
| **Waiver** | Patient explicitly waives detailed consent ("just do what's needed") |
| **Incompetent patient** | Surrogate consents per state hierarchy |
| Public health (TB treatment, vaccination mandates in some) | Statutory |

**Special populations:**

| Group | Consent considerations |
|-------|------------------------|
| Minors | Generally parental; **emancipated minor** (married, military, court-declared, financially independent) consents for self; **mature minor** (cognitively capable, varies by state) for some decisions |
| Adolescent **confidential** services | Sexually transmitted infections, contraception, pregnancy, mental health, substance use — vary by state |
| Pregnant minor | Often can consent for pregnancy-related care |
| Cognitively impaired adult | Surrogate; assess decision-specific capacity, may differ across decisions |
| Imprisoned | Heightened concern about voluntariness |
| Limited English | Professional interpreter required; family interpreter problematic |
| Sensory impaired | Accommodations |

**Refusal of treatment:**

| Scenario | Approach |
|----------|----------|
| Capacitated adult refuses | Respect autonomy; explore reasons; document |
| Capacitated adult refuses life-saving | Same — autonomy; document understanding of consequences |
| Incapacitated patient refuses (e.g., dementia, agitated, paranoid) | Use surrogate decision-making per advance directive or hierarchy |
| Suicidal patient refuses | Capacity often impaired by mental illness; involuntary hold for evaluation per state law |
| Pediatric — parents refuse life-saving (e.g., transfusion in JW child) | Court order overriding |
| Pediatric — parents accept but child refuses | Generally parents decide; consider mature minor / assent |

**"Assent" (pediatric / cognitive impairment):**

| Concept |
|---------|
| Even when surrogate provides legal consent, obtain **assent** from the patient (child, cognitively impaired) when developmentally / cognitively able |
| Acknowledges autonomy and dignity |
| Document |

**Consent for research:**

| Additional elements (Common Rule) |
|-----------------------------------|
| Statement that this is research |
| Purpose |
| Procedures, duration |
| Risks / benefits |
| Alternatives outside research |
| Confidentiality |
| Compensation, treatment for injury |
| Voluntariness, can withdraw |
| IRB-approved consent form |

**Practical tips:**

| Tip |
|-----|
| Discuss in patient's preferred language; use professional interpreter |
| Avoid jargon; teach-back to confirm understanding |
| Allow time for questions |
| Family / support person if patient wishes |
| Document the conversation, not just the form |
| Obtain consent **before** the procedure / drug administered |
| Re-consent if circumstances change significantly |

**Common gotchas:**
- **Capacity ≠ "I agree with the doctor"** — a patient who refuses can still have capacity
- **Don't equate cognitive impairment with incapacity** — assess for the specific decision
- **Avoid family as interpreter** — bias, accuracy, confidentiality
- **Document the conversation**: what was discussed, what patient understood, what they decided
- **Consent obtained by the operator / proceduralist** preferred over assistant — they own the conversation
- **"No surrogate" in emergency** — proceed under implied consent for emergent intervention; ethics / SW consult for prolonged decisions
- **Coercion** can be subtle — financial, family pressure, institutional
- **Consent for blood transfusion** is often a separate document; some patients (JW) may refuse
- **HIV testing** typically opt-out in many US settings now (no separate consent needed)

**Rule of thumb:** All four elements (disclosure, comprehension, voluntariness, capacity). Capacity is decision-specific + time-specific + clinical. Document the conversation. Emergency and therapeutic privilege are narrow exceptions. Refusal of treatment by a capacitated adult must be respected.
