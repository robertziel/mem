### History Taking — HPI Frameworks

**Sections of a complete history:**

| Section | Content |
|---------|---------|
| Chief complaint (CC) | Patient's words |
| HPI | Onset, character, location, timing, associations, modifiers, severity |
| PMH | Conditions, surgeries, hospitalizations, OB history |
| Medications | Names, doses, OTC, herbal, supplements, recent changes |
| Allergies | Drug, food, environmental — describe reaction |
| Family history | First-degree relatives, hereditary patterns |
| Social history | Smoking, alcohol, drugs, sexual, occupation, exercise, diet, living situation |
| Review of systems | Targeted by complaint, full when broad |
| Functional status | ADLs, IADLs, baseline |
| Advance directives, code status | Especially in chronic / severe illness |

**HPI mnemonics for symptom characterization — pick one:**

| **OPQRST** | **OLDCARTS** | **SOCRATES** |
|------------|--------------|--------------|
| Onset | Onset | Site |
| Provoking / palliating | Location | Onset |
| Quality | Duration | Character |
| Radiation | Character | Radiation |
| Severity | Aggravating | Associations |
| Timing | Relieving | Time course |
| | Timing | Exacerbating / relieving |
| | Severity | Severity |

Most clinicians use OLDCARTS or OPQRST. SOCRATES popular in UK.

**Pain history (the 7-question deep dive):**

| Question |
|----------|
| When did it start? |
| What were you doing? |
| Where is it? |
| Does it move/radiate? |
| What does it feel like (sharp, dull, crampy, burning)? |
| Does anything make it better or worse? |
| How severe (0-10)? |
| Any associated symptoms? |
| Constant or intermittent? |
| Ever had this before? |
| Have you tried any treatment? |

**Common pitfalls / pearls:**

| Pearl | Detail |
|-------|--------|
| Open-ended first | "Tell me about it" — don't lead |
| Active listening | Reflect, summarize, allow silence |
| Patient's words | Document chief complaint verbatim |
| Severity in patient's frame | "Worst pain ever" / impact on activities |
| Quality | Patient describes; don't put words in their mouth |
| Timing | Continuous vs intermittent; sudden vs gradual |
| Triggers / alleviators | Foods, positions, medications, sleep |
| Associated symptoms | System-specific based on complaint |
| Functional impact | "What can't you do now?" |

**ROS (Review of Systems) by complaint — focused:**

| System | Examples |
|--------|----------|
| Constitutional | Fever, weight loss, fatigue, night sweats, anorexia |
| HEENT | Headache, vision, hearing, sore throat, congestion, neck mass |
| Cardiac | Chest pain, palpitations, dyspnea on exertion, orthopnea, PND, edema |
| Pulmonary | Cough, sputum, hemoptysis, wheezing, dyspnea |
| GI | Nausea, vomiting, diarrhea, constipation, melena, hematochezia, abdominal pain, jaundice |
| GU | Frequency, urgency, dysuria, hematuria, flank pain, sexual function |
| MSK | Joint pain, swelling, stiffness, weakness |
| Neuro | Headache, weakness, numbness, vision change, speech, gait, syncope, seizure |
| Heme/lymph | Bleeding, bruising, lymphadenopathy |
| Endocrine | Heat/cold intolerance, polyuria, polydipsia, weight change |
| Psych | Mood, sleep, suicidal ideation, anxiety |
| Skin | Rash, lesion, itch |

**Social history — the sensitive parts:**

| Topic | How to ask |
|-------|-----------|
| Tobacco | Pack-years (packs/day × years); current/former/never |
| Alcohol | **CAGE** (Cut down, Annoyed, Guilty, Eye-opener); AUDIT-C; ounces/drinks |
| Drugs | "Other recreational substances?" non-judgmental, including cannabis, opioids, stimulants, hallucinogens; route (smoke, inject, snort) |
| Sexual | Partners (number, sex), practices, prevention, prior STIs, problems, satisfaction (5 P's) |
| Domestic violence | Privacy first, "Do you feel safe at home?" |
| Mental health | "How have you been emotionally?" "Any thoughts of harming yourself or others?" |

**Adolescent-specific (HEEADSSS):** Home, Education/Employment, Eating, Activities/Affect, Drugs, Sexuality, Suicide/depression, Safety/abuse.

**SBAR for handoff:**

| Letter | Content |
|--------|---------|
| **S** | Situation — current presenting issue |
| **B** | Background — relevant history, reason for admission |
| **A** | Assessment — your impression / vitals / labs |
| **R** | Recommendation — what you want next |

**Documentation tips:**

| Tip | Detail |
|-----|--------|
| HPI in narrative | Logical flow, patient's words for CC |
| Negative findings | Document pertinent negatives that change differential |
| Sources of information | "Per chart", "per family", "patient unable to provide" |
| Time-sensitive info | Document time of last known well, last meal |
| Update | At each encounter, dynamic |

**Common gotchas:**
- **Don't lead the patient** — "Is the pain sharp?" → leads. "What does it feel like?" → open
- **Silence is a tool** — pause after "What else?" to elicit hidden concerns
- **OLDCARTS / OPQRST is for symptom characterization** — wrap with associated symptoms + ROS
- **Functional impact** is often the most patient-relevant — what can't they do now?
- **Always re-ask CAGE** with positive findings; even one positive deserves follow-up
- **Sexual history** — non-judgmental, all ages; STIs across the lifespan
- **Ask about violence privately** — partner / family in waiting room
- **Last known well** in stroke / cardiac arrest / sepsis is the most important time question

**Rule of thumb:** Open question → OLDCARTS / OPQRST → focused ROS → PMH/Meds/Allergies/FH/SH/functional. Document in patient's words. Always assess pertinent negatives, social context, advance directives. Use SBAR for handoffs.
