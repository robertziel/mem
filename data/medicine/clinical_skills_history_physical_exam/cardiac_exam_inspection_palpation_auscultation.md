### Cardiac Examination

**Four steps + setup:**

| Step | What to do |
|------|-----------|
| Setup | Quiet room, patient at 30-45°, expose chest, warm hands/stethoscope |
| **Inspection** | General appearance, JVP, peripheral edema, clubbing, cyanosis, scars, deformities (pectus), pulsations |
| **Palpation** | Apical impulse / PMI, parasternal heave, thrills, peripheral pulses |
| **Percussion** | (Limited utility; cardiac dullness rarely used) |
| **Auscultation** | Systematic at all 4 areas + dynamic maneuvers |

**Auscultation areas:**

| Area | Location | Best for |
|------|----------|----------|
| **A**ortic | 2nd ICS right sternal border | AS, AR (early diastolic best at LSB) |
| **P**ulmonic | 2nd ICS left sternal border | PS, PR; loud P2 |
| **E**rb's point | 3rd ICS left sternal border | AR, S3, S4 |
| **T**ricuspid | 4th-5th ICS left sternal border | TR, TS, RV S3/S4 |
| **M**itral (apex) | 5th ICS midclavicular line | MS (left lateral decubitus, bell), MR |

**A**ll **P**eople **E**njoy **T**he **M**enu — APE TM areas.

**Heart sounds — what they mean:**

| Sound | Cause |
|-------|-------|
| **S1** | Mitral + tricuspid closure (start of systole) |
| **S2** | Aortic + pulmonic closure (start of diastole); **physiologic split** with inspiration |
| Wide split S2 | Delayed RV (RBBB, ASD, PS) |
| Fixed split S2 | **ASD** |
| Paradoxical split | Delayed LV (LBBB, AS, HCM) |
| Single S2 | AS severe, single ventricle |
| **S3** ("Kentucky") | Rapid early ventricular filling — HF (sensitive), normal in young/athletes/pregnancy |
| **S4** ("Tennessee") | Atrial kick into stiff ventricle — HFpEF, HCM, HTN, AS |
| Opening snap | After S2 — **MS** |
| Ejection click | Early systolic — bicuspid AV, AS |
| Mid-systolic click | **MVP** |
| Pericardial knock | Constrictive pericarditis (early diastolic) |
| Friction rub | Pericarditis (3-component: ventricular systole, ventricular diastole, atrial systole) |

**Murmurs — systolic:**

| Murmur | Best heard | Pattern |
|--------|-----------|---------|
| **AS** | RUSB → carotids | Crescendo-decrescendo, ejection |
| **HCM** | LLSB | ↑ with Valsalva (paradox to AS) |
| **MR** | Apex → axilla | Holosystolic |
| **MVP** | Apex | Mid-systolic click + late murmur |
| **TR** | LLSB | Holosystolic, ↑ with inspiration |
| **VSD** | LLSB | Holosystolic, harsh |
| **Pulmonic stenosis** | LUSB | Crescendo-decrescendo |
| **Innocent / flow** | LSB / pulmonic | Soft, brief, position-dependent |

**Murmurs — diastolic:**

| Murmur | Best heard | Pattern |
|--------|-----------|---------|
| **AR** | LSB sit forward, exhale | Decrescendo, early diastolic |
| **MS** | Apex, left lateral, bell | Mid-late diastolic rumble + opening snap |
| Pulmonic regurgitation | LUSB | Decrescendo |
| **Austin-Flint** | Apex | Mid-diastolic rumble in AR (no MS) — functional MR from AR jet |

**Continuous murmurs (both phases):**

| Murmur | Cause |
|--------|-------|
| **PDA** | Continuous "machine-like" |
| AV fistula, coronary AV fistula | Same |
| Venous hum | Innocent in kids |
| Mammary souffle | Pregnancy / lactation |

**Grading murmurs:**

| Grade | Description |
|-------|-------------|
| 1 | Barely audible |
| 2 | Soft but easily heard |
| 3 | Moderate, no thrill |
| 4 | Loud, **palpable thrill** |
| 5 | Very loud, audible with stethoscope partly off chest |
| 6 | Audible without stethoscope |

Diastolic murmurs are **always abnormal** in adults.

**Maneuvers (the practical part):**

| Maneuver | Mechanism | Effect |
|----------|-----------|--------|
| **Valsalva, standing** | ↓ preload | Most murmurs ↓; **HCM, MVP click** ↑ |
| **Squat, leg-raise, handgrip** | ↑ preload (squat/leg) / ↑ afterload (handgrip) | Most murmurs ↑; HCM ↓; MVP click later |
| **Inspiration** | ↑ R-sided venous return | R-sided murmurs ↑ (Carvallo for TR) |
| Expiration | — | L-sided murmurs ↑ |
| Left lateral decubitus + bell at apex | Brings MV closer | **MS, S3, S4** more audible |
| Sitting up, leaning forward, exhale | Brings AV closer | **AR** decrescendo more audible |

**Pulse exam:**

| Site | Findings |
|------|----------|
| Carotid | Rate, rhythm, contour, **bruit** |
| Radial / brachial | Rate, rhythm, comparison |
| Femoral | Rate, presence (radio-femoral delay = coarctation in young; aortoiliac PAD in older) |
| Popliteal, posterior tibial, dorsalis pedis | PAD evaluation |
| Comparison both sides | Asymmetry → dissection, occlusion, coarctation |

**Pulse contour clues:**

| Pulse | Cause |
|-------|-------|
| Bounding (water-hammer / Corrigan) | AR, hyperthyroid, anemia, thiamine def, AV fistula |
| **Pulsus parvus et tardus** | AS (slow rising, low amplitude) |
| **Pulsus paradoxus** (>10 mmHg drop in SBP with inspiration) | Tamponade, severe asthma/COPD, tension pneumothorax |
| **Pulsus alternans** (alternating strong/weak) | Severe LV dysfunction |
| Bisferiens (double peak) | AR + AS (mixed), HCM |
| Dicrotic | Sepsis, shock |

**JVP (jugular venous pressure):**

| Item | Detail |
|------|--------|
| Position | 30-45° head of bed |
| Locate | Internal jugular meniscus |
| Measure | Vertical height above sternal angle + 5 cm = right atrial pressure |
| Normal | ≤8 cm H2O (≤3 cm above sternal angle) |

**JVP waveform:**

| Wave | Meaning |
|------|---------|
| **a** | Atrial contraction (absent in AF, large "cannon a" in complete heart block, large in TS / PS / RV hypertrophy) |
| **c** | Tricuspid bulge during ventricular contraction |
| **x descent** | Atrial relaxation (steep in tamponade) |
| **v** | Atrial filling (passive, large in TR) |
| **y descent** | Tricuspid opens (steep "Friedreich" in constrictive pericarditis) |

**Hepatojugular reflux** — sustained pressure on liver elevates JVP if RV / global volume overload (HF).

**Kussmaul sign** — JVP **rises** with inspiration → constrictive pericarditis, severe RV failure (paradoxical to normal).

**Common gotchas:**
- **Diastolic murmur in adult = pathologic**
- **Loud P2** = pulmonary HTN
- **HCM increases** with maneuvers that **decrease** preload (Valsalva, standing)
- **MVP click** moves earlier with ↓ preload
- **AS** murmur intensity does NOT correlate with severity; **late peak + soft S2 + slow rise pulse** does
- **Quiet precordium with severe HF** common — signs may be subtle
- **Kussmaul + pulsus paradoxus** can both occur in tamponade and constriction
- **Auscultate carotid for bruit** before palpating both at once (no bilateral pressure)

**Rule of thumb:** Inspect → palpate → systematically auscultate APE TM. Identify murmur phase (S/D/continuous), location, radiation, intensity, dynamic response. JVP + carotid + peripheral pulses complete the cardiac exam. Maneuvers separate HCM/MVP from other systolic murmurs.
