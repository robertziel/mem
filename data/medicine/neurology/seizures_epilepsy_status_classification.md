### Seizures and Epilepsy

**ILAE classification (2017 framework):**

| Onset | Awareness | Motor / Non-motor |
|-------|-----------|-------------------|
| **Focal** | Aware vs impaired awareness | Motor (clonic, atonic, automatisms, hyperkinetic) or non-motor (autonomic, behavior arrest, cognitive, emotional, sensory) |
| **Generalized** | Always impaired | Motor (tonic-clonic, clonic, tonic, atonic, myoclonic, epileptic spasms) or non-motor (typical/atypical absence) |
| **Unknown onset** | — | — |

**Common patterns:**

| Type | Hallmark |
|------|----------|
| Generalized tonic-clonic (GTCS) | Sudden LOC, tonic stiffening → clonic jerks; postictal confusion; tongue bite (lateral), incontinence |
| Absence (childhood) | Brief 5-15s staring; **3 Hz spike-and-wave**; provoked by hyperventilation; ethosuximide first |
| Juvenile myoclonic epilepsy | Adolescent; morning myoclonus (drop coffee), GTCS, photosensitive; valproate / lamotrigine / levetiracetam |
| Focal aware (formerly simple partial) | Awareness preserved, focal symptoms; aura |
| Focal impaired awareness (formerly complex partial) | Temporal lobe — staring + automatisms + post-ictal confusion |
| Atonic ("drop attacks") | Sudden loss of tone — Lennox-Gastaut |
| Infantile spasms | Salaam attacks, hypsarrhythmia EEG; **ACTH or vigabatrin** (vigabatrin if tuberous sclerosis) |

**Provoked vs unprovoked:**

| | Provoked (acute symptomatic) | Unprovoked / epilepsy |
|---|------------------------------|----------------------|
| Trigger | Trauma, stroke, infection, electrolyte, alcohol withdrawal, hypoglycemia, drug, sleep deprivation | None / chronic |
| Treatment | Treat trigger; usually no chronic AED | Antiepileptic drug if recurrent or high risk |

**Workup of first seizure:**

| Step | Test |
|------|------|
| Glucose, electrolytes (Na, Ca, Mg), CBC, BMP, LFTs | Reversible causes |
| Tox screen, alcohol level | Withdrawal, intoxication |
| ECG | QT prolongation, Brugada (mimics) |
| **CT head** (urgent) | Bleed, mass |
| **MRI brain** (best) | Structural cause; ideal seizure protocol |
| **EEG** within 24-48h | Epileptiform discharges |
| LP if febrile / immunocompromised / suspected meningitis | — |

**Choosing AED — by type:**

| Seizure type | First-line options |
|--------------|--------------------|
| Focal | Lamotrigine, levetiracetam, lacosamide, oxcarbazepine, carbamazepine |
| GTCS | Valproate, lamotrigine, levetiracetam, topiramate |
| Absence | **Ethosuximide** (or valproate, lamotrigine) |
| Myoclonic (JME) | **Valproate, lamotrigine, levetiracetam** |
| Lennox-Gastaut | Valproate, lamotrigine, rufinamide, clobazam, cannabidiol |
| Status epilepticus | See below |
| Infantile spasms | ACTH, prednisolone, vigabatrin |

**AED side-effect highlights:**

| Drug | Watch for |
|------|-----------|
| Phenytoin | Gingival hyperplasia, hirsutism, ataxia, nystagmus, lupus-like, **purple glove syndrome** (IV) |
| Carbamazepine | SIADH, agranulocytosis, **SJS/TEN (HLA-B*1502)** screen Asian; CYP inducer |
| Valproate | **Teratogen (NTD, IQ)**, hepatotoxicity, pancreatitis, weight gain, alopecia, thrombocytopenia |
| Lamotrigine | **SJS/TEN** with rapid titration; safest in pregnancy |
| Topiramate | Cognitive slowing, weight loss, paresthesias, kidney stones, glaucoma |
| Levetiracetam | Behavioral / mood (irritability) |
| Ethosuximide | GI, drowsiness; absence-only |
| Phenobarbital | Sedation; cognitive in children |
| Vigabatrin | Visual field constriction (irreversible) |
| Lacosamide | PR interval prolongation |

**Status epilepticus:**

| Definition (operational) |
|--------------------------|
| Seizure **>5 min** continuous OR **≥2 without recovery** |

**Treatment ladder:**

| Time | Step | Drug |
|------|------|------|
| 0-5 min | Stabilize, glucose, thiamine if alcohol risk | — |
| 5 min | **First-line: benzodiazepine** | IV lorazepam 4 mg, IM midazolam 10 mg, rectal diazepam |
| 20 min | **Second-line** | IV levetiracetam, fosphenytoin, or valproate (ESETT showed equivalent) |
| 40 min | **Third-line / refractory** | Continuous infusion (midazolam, propofol, pentobarbital), intubate, EEG monitoring |

**Driving and safety:**
- Most US states require seizure-free interval (varies, often 3-12 months) before driving
- Counsel about swimming, heights, machinery, bath vs shower

**Pregnancy:**

| Drug | Notes |
|------|-------|
| Valproate | **Avoid** — high teratogen |
| Topiramate | Cleft palate risk |
| Lamotrigine | Safer; needs dose ↑ (clearance ↑) |
| Levetiracetam | Safer |
| Folate | All pregnant women on AED — **5 mg/day** to reduce NTD |

**Common gotchas:**
- "Status" definition shortened to **5 min** — treat immediately, don't wait
- **Hyponatremia from carbamazepine / oxcarbazepine** — common, sometimes presents as worsening seizures
- **PNES (psychogenic non-epileptic seizures)** — pelvic thrusting, eyes closed, asynchronous movements, no postictal lactate; video-EEG diagnostic
- **Rapid lamotrigine titration → SJS** — go slow
- Phenytoin IV must be slow + diluted; **fosphenytoin** preferred (less infusion reaction, can give IM)
- Don't stop AEDs abruptly (rebound seizures, status)

**Rule of thumb:** First seizure → MRI + EEG + glucose/electrolytes/tox; treat trigger if provoked. Status >5 min → benzo → leveti/PHT/valproate → infusion. Match AED to seizure type. Avoid valproate / topiramate in pregnancy; lamotrigine + levetiracetam safer.
