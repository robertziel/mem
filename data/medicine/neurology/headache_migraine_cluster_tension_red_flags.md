### Headache — Primary Types and Red Flags

**Primary headaches:**

| Type | Classic features |
|------|------------------|
| **Migraine** | Unilateral throbbing, mod-severe, 4-72h, **photo/phonophobia, nausea**, ± aura; worsened by activity |
| **Tension** | Bilateral, **band-like / pressure**, mild-moderate, no nausea, no aggravation by activity |
| **Cluster** | **Unilateral periorbital, severe**, 15-180 min, autonomic features (lacrimation, rhinorrhea, ptosis, miosis), restless / pacing; clusters over weeks |
| Trigeminal autonomic cephalalgias (chronic paroxysmal hemicrania, hemicrania continua, SUNCT) | Less common; respond to indomethacin (paroxysmal hemicrania, hemicrania continua) |

**Red flags — SNOOP10 (any one → workup):**

| Red flag |
|----------|
| **S**ystemic symptoms (fever, weight loss) |
| **N**eoplasm history |
| **N**eurologic deficit (focal, LOC, papilledema) |
| **O**nset sudden ("thunderclap") |
| **O**lder age (>50, new headache) |
| **P**attern change (escalating, change in quality) |
| **P**ositional (worse with Valsalva, lying flat — ↑ICP) |
| **P**recipitated by Valsalva / exertion |
| **P**apilledema / pulsatile tinnitus |
| **P**regnancy / postpartum (CVT, eclampsia) |
| **P**ainful eye / visual / Horner's |
| **P**ost-traumatic |
| **I**mmunocompromised (HIV, transplant) |
| **I**nfection (meningitis suspicion) |

**Secondary causes by clue:**

| Clue | Diagnosis |
|------|-----------|
| Thunderclap, "worst headache of life" | **SAH**, RCVS, CVT, dissection, pituitary apoplexy |
| Fever + neck stiffness + photophobia | Meningitis |
| Postural (worse standing) | Spontaneous intracranial hypotension; post-LP |
| Worse lying / morning + papilledema | ↑ICP — mass, IIH, CVT |
| Older + scalp tenderness + jaw claudication + ↑ESR | **Giant cell arteritis** — start steroids immediately, biopsy temporal artery |
| Sudden Horner + neck pain | Carotid dissection |
| HIV with new headache | CNS toxoplasmosis, cryptococcus, primary CNS lymphoma |
| New headache + cancer history | Brain mets |
| Postpartum / OCP / pregnancy + headache | CVT, posterior reversible encephalopathy syndrome, eclampsia |

**Migraine — phases:**

| Phase | Detail |
|-------|--------|
| Prodrome (hours-days) | Mood change, food cravings, neck stiffness |
| Aura | Visual (most), sensory, language; gradual onset, <60 min |
| Headache | Throbbing, unilateral, photo/phono, nausea, 4-72h |
| Postdrome | Fatigue, malaise |

**Migraine treatment:**

| Class | Drugs |
|-------|-------|
| Acute (abortive) | NSAIDs, acetaminophen, **triptans** (sumatriptan), gepants (ubrogepant, rimegepant), ditans (lasmiditan), antiemetic (metoclopramide), DHE for status |
| Preventive (≥4 days/mo or severe) | β-blockers (propranolol, metoprolol), topiramate, valproate, amitriptyline, candesartan, **CGRP mAbs** (erenumab, fremanezumab, galcanezumab), **CGRP gepants** (rimegepant), botulinum toxin (chronic) |

**Triptan contraindications:** ASCVD, uncontrolled HTN, basilar/hemiplegic migraine, recent MAOI/SSRI (some).

**Cluster headache:**

| Acute | Preventive |
|-------|------------|
| **High-flow O2** (12-15 L/min × 15 min) | **Verapamil** |
| **Sumatriptan SC or intranasal** | Lithium, topiramate |
| | Galcanezumab |
| | Steroid bridge / occipital nerve block |

**Tension-type headache:**

| Acute | Preventive |
|-------|------------|
| NSAIDs, acetaminophen | Amitriptyline (most evidence) |

**Medication overuse headache (MOH):**

| Threshold |
|-----------|
| Acute analgesics ≥10 days/mo (triptans, opioids, combination) or ≥15 days/mo (NSAIDs, simple analgesics) for >3 months |

Treatment: stop the offender (taper if opioid/butalbital), bridge with NSAID or steroid, start preventive.

**Idiopathic intracranial hypertension (IIH / pseudotumor cerebri):**

| Feature |
|---------|
| Young, obese woman |
| Headache + papilledema + visual disturbance + tinnitus |
| Normal imaging (rule out CVT) |
| LP with **opening pressure >25 cm H2O** + normal CSF |

| Treatment | Detail |
|-----------|--------|
| Weight loss | Cornerstone |
| Acetazolamide | First-line drug |
| Topiramate | Adjunct (also weight loss) |
| Serial LPs | Selected |
| Optic nerve sheath fenestration / VP shunt | Vision-threatening |

**Common gotchas:**
- **Thunderclap = SAH workup** — CT head, then LP if CT negative (xanthochromia) within 6h-2 wk
- **Don't anchor** on migraine in older first-headache patient — workup
- **Triptans + SSRI** — serotonin syndrome theoretically but rarely clinically significant
- **Migraine with brainstem aura ≠ stroke** (vertigo, dysarthria, diplopia, ataxia) — but image first time
- **GCA** — start steroids before biopsy if clinical suspicion high
- IIH untreated → permanent vision loss; ophthalmology consult is mandatory

**Rule of thumb:** Pattern + red-flag screen first. Migraine: triptan acute, β-blocker / topiramate / CGRP mAb preventive. Cluster: O2 + SC sumatriptan, verapamil prevent. Thunderclap → image + LP. Postural worse standing → SIH. Older + temporal pain + jaw → GCA → steroid now.
