### Pulmonary Embolism (PE)

**Risk-stratified workup:**

| Wells score (PE) | Points |
|------------------|--------|
| Clinical signs of DVT | 3 |
| PE most likely diagnosis | 3 |
| HR >100 | 1.5 |
| Immobilization >3d / surgery <4 wk | 1.5 |
| Prior DVT/PE | 1.5 |
| Hemoptysis | 1 |
| Malignancy | 1 |

| Wells | PE probability | Action |
|-------|----------------|--------|
| ≤4 (PE unlikely) | Low | **D-dimer**; if neg → ruled out |
| >4 (PE likely) | High | **Skip D-dimer → CTPA directly** |

**Age-adjusted D-dimer** (>50y): cutoff = age × 10 ng/mL — improves specificity.

**PERC rule** — if all 8 negative + low pre-test probability, PE essentially excluded without D-dimer:

| PERC criteria (NO to all = rule out) |
|--------------------------------------|
| Age ≥50, HR ≥100, SpO2 <95%, hemoptysis, exogenous estrogen, prior DVT/PE, surgery/trauma <4 wk, unilateral leg swelling |

**Imaging:**

| Test | Use |
|------|-----|
| **CTPA** | Gold standard for confirmation |
| V/Q scan | Pregnancy, contrast allergy, severe CKD |
| **Lower-extremity duplex** | If imaging contraindicated; positive DVT + symptoms = treat as PE |
| Bedside echo | Hemodynamic instability — RV strain, McConnell sign |

**ECG findings:**

| Finding | Frequency |
|---------|-----------|
| Sinus tachycardia | Most common |
| **S1Q3T3** | Classic but uncommon |
| New RBBB, RV strain (T inversion V1-V4) | Suggestive |
| A-fib | Less specific |

**Severity stratification:**

| Severity | Definition |
|----------|-----------|
| Massive (high-risk) | **Hypotension** (SBP <90) or shock or arrest |
| Submassive (intermediate-risk) | Normotensive **+ RV dysfunction** (echo, CT) **+ ↑ troponin / BNP** |
| Low-risk | Normotensive, no RV strain or biomarker elevation |

**Treatment by severity:**

| Severity | Treatment |
|----------|-----------|
| Low-risk | DOAC outpatient (apixaban, rivaroxaban) — if hemodynamically stable + no comorbidity |
| Intermediate | Anticoagulate; consider catheter-directed thrombolysis if deteriorating |
| **Massive** | **Systemic thrombolysis (tPA 100 mg over 2h)** + heparin OR catheter-directed thrombolysis OR surgical embolectomy |

Cardiac arrest from PE: tPA 50 mg bolus during CPR if confirmed.

**Anticoagulation choices:**

| Agent | Notes |
|-------|-------|
| Apixaban, rivaroxaban | DOAC — first-line for most non-cancer; **no parenteral lead-in** required |
| Dabigatran, edoxaban | Need 5-10 days parenteral lead-in |
| Warfarin | INR 2-3; bridge with heparin |
| LMWH (enoxaparin) | First-line in cancer (or DOAC), pregnancy |
| UFH | Acute, severe renal failure, planned thrombolysis |

**Duration:**

| Cause | Duration |
|-------|----------|
| Provoked (surgery, immobility, hormonal) | 3 months |
| Unprovoked first event | 3-6 months minimum, consider extended |
| Recurrent / cancer-associated / persistent risk | Indefinite |
| Antiphospholipid syndrome | **Warfarin indefinitely** (DOACs inferior) |

**Thrombolysis contraindications (absolute) — same as ACS:**
- Prior intracranial hemorrhage
- Known intracranial vascular lesion / neoplasm
- Ischemic stroke <3 mo
- Aortic dissection
- Active bleeding

**Hypercoagulability workup (when?):**

| Workup if |
|-----------|
| Unprovoked PE/DVT under 50 |
| Recurrent VTE |
| Family history |
| Unusual sites (cerebral, splanchnic) |

Tests: Factor V Leiden, prothrombin G20210A, antiphospholipid antibodies, antithrombin, protein C/S, JAK2 (splanchnic), homocysteine.

**Common gotchas:**
- **D-dimer rises** in pregnancy, age, infection, malignancy, post-op — only rules **out** when low
- **Subsegmental PE on CT** in stable patient with low pre-test prob and no DVT — selected patients can be observed without anticoag
- **Pulmonary infarction** is rare (<10%) because lungs have dual blood supply
- **Saddle embolus** alone doesn't define massive PE — hemodynamics do
- IVC filter: only if anticoag absolutely contraindicated and recurrent VTE despite therapy

**Rule of thumb:** Wells → D-dimer (if low) or CTPA (if high). Hypotension = massive = thrombolyse. RV dysfunction without hypotension = monitor closely. DOAC for most outpatient. APS = warfarin only.
