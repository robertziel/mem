### Asthma

**Diagnosis:**

| Test | Finding |
|------|---------|
| Spirometry | FEV1/FVC <0.7 with **reversibility** (>12% and 200 mL ↑ post-BD) |
| Methacholine challenge | ≥20% drop in FEV1 (rules in if positive) |
| FeNO | ↑ in eosinophilic airway inflammation |
| Peak flow | Variable, diurnal |

**GINA severity / control assessment (4 questions, last 4 weeks):**

| Question | Answer |
|----------|--------|
| Daytime symptoms >2×/wk | Y/N |
| Nighttime awakening | Y/N |
| Reliever use >2×/wk | Y/N |
| Activity limitation | Y/N |

| Number "yes" | Control |
|--------------|---------|
| 0 | Well controlled |
| 1-2 | Partly controlled |
| 3-4 | Uncontrolled |

**GINA stepwise therapy (≥12y, 2024) — major shift away from SABA monotherapy:**

| Step | Reliever (PRN) | Controller |
|------|----------------|------------|
| 1-2 | **As-needed ICS-formoterol (low dose)** | None / same as reliever |
| 3 | ICS-formoterol PRN | Daily low-dose ICS-formoterol |
| 4 | ICS-formoterol PRN | Daily medium-dose ICS-formoterol |
| 5 | ICS-formoterol PRN | High-dose ICS-LABA + LAMA + biologic referral |

**Track 1** (preferred): ICS-formoterol used both as controller + reliever (MART/AIR).
**Track 2** (alternative): ICS daily + SABA PRN.

**Severity (NIH classification):**

| Class | Symptoms |
|-------|----------|
| Intermittent | ≤2×/wk daytime, ≤2×/mo night, normal FEV1 |
| Mild persistent | >2×/wk daytime, 3-4×/mo night, FEV1 ≥80% |
| Moderate persistent | Daily, >1×/wk night, FEV1 60-80% |
| Severe persistent | Continual, frequent night, FEV1 <60% |

**Drug classes:**

| Class | Examples | Use |
|-------|----------|-----|
| ICS | Budesonide, fluticasone, mometasone | Cornerstone controller |
| LABA | Formoterol, salmeterol | Always with ICS (boxed warning if alone) |
| LAMA | Tiotropium | Add-on in severe |
| LTRA | Montelukast | Adjunct, exercise/aspirin asthma; **suicidal ideation warning** |
| Biologics | Omalizumab (anti-IgE), mepolizumab/reslizumab/benralizumab (anti-IL-5/R), dupilumab (IL-4Rα), tezepelumab (TSLP) | Severe Th2-high asthma |
| Theophylline | Rare; narrow TI |
| SABA | Albuterol — rescue |

**Phenotypes drive biologics:**

| Phenotype | Marker | Biologic |
|-----------|--------|----------|
| Allergic | ↑IgE, perennial allergens | Omalizumab |
| Eosinophilic | Blood eos ≥300 | Mepolizumab, benralizumab, reslizumab |
| T2-high (broad) | Eos / FeNO | Dupilumab, tezepelumab |

**Acute exacerbation (severity assessment):**

| Severity | Speech | RR | SpO2 | PEF | PaCO2 |
|----------|--------|-----|------|-----|-------|
| Mild-moderate | Sentences | <30 | ≥92 | >50% | Low or normal |
| Severe | Words | >30 | <92 | <50% | Low or normal |
| **Life-threatening** | Silent chest, exhausted, altered MS | — | — | <33% | **Normal or rising** (ominous) |

**Treatment of acute exacerbation:**

| Step | Treatment |
|------|-----------|
| 1 | Albuterol (continuous if severe) ± ipratropium |
| 2 | Systemic steroid (prednisone 40-60 PO or IV methylpred) |
| 3 | Magnesium sulfate IV (severe / not improving) |
| 4 | Heliox, NIV (carefully), intubation if failing |
| 5 | Avoid β-blockers, sedatives without airway control |

**Triggers / clinical patterns to recognize:**

| Pattern | Trigger |
|---------|---------|
| Aspirin / NSAID-induced (Samter triad) | Aspirin, polyps, asthma — leukotriene-driven |
| Exercise-induced | Cold/dry air, post-exercise FEV1 drop |
| Occupational | Onset / improvement related to work |
| Allergic / atopic | IgE, dust mite, cat, cockroach, mold |
| Cough-variant | Cough as sole symptom; reverses with bronchodilator |

**Common gotchas:**
- **Rising or normal PaCO2** in a tiring asthmatic = impending failure (should be **low** in tachypnea); don't be reassured
- **Silent chest** = severe — not improvement
- **LABA without ICS** is contraindicated in asthma (mortality signal — black-box warning)
- **Aspirin asthma** (Samter triad: asthma + polyps + ASA) responds to **leukotriene modifiers**
- ICS use → oral candidiasis, dysphonia (rinse mouth); growth velocity transient ↓ in kids (catches up)
- **Montelukast** carries FDA warning for neuropsychiatric effects

**Rule of thumb:** ICS-formoterol PRN is now the floor of asthma therapy (GINA Track 1). Severity by symptoms × control. Exacerbation severity: silent chest or rising CO2 = critical. Phenotype the patient before reaching for biologics.
