### IBD: Crohn vs Ulcerative Colitis

**Side-by-side comparison:**

| Feature | Crohn disease | Ulcerative colitis |
|---------|---------------|-------------------|
| Distribution | **Anywhere** mouth → anus; terminal ileum + colon most common; **skip lesions** | Colon only, **continuous** from rectum proximally |
| Depth | Transmural | Mucosa + submucosa |
| Rectal involvement | Often spared | **Always** (starts there) |
| Granulomas | Yes (non-caseating) | No |
| Bloody diarrhea | Less common | **Hallmark** (bloody, mucousy) |
| Fistulas, strictures, abscesses | **Common** | Rare |
| Perianal disease | Common | Rare |
| Cobblestoning, creeping fat, string sign | Yes | No |
| Cancer risk | Yes (long-standing colonic disease) | **Higher** — colorectal cancer ↑ with duration + extent |
| Extraintestinal manifestations | Both, slightly different distributions | Both |
| Surgery | Palliative (recurs) | **Curative** (proctocolectomy) |
| Smoking | Worsens | Protective (don't recommend!) |
| pANCA | ~ 5-20% | ~ 60-70% |
| ASCA | ~50-60% | ~10% |

**Extraintestinal manifestations (overlap, but skew):**

| System | Manifestation |
|--------|---------------|
| Eyes | Uveitis, episcleritis |
| Skin | Erythema nodosum (parallels disease), pyoderma gangrenosum (UC > Crohn, doesn't parallel) |
| Joints | Peripheral / axial arthritis, ankylosing spondylitis |
| Liver | **Primary sclerosing cholangitis (UC > Crohn)** — beads on cholangiogram, ↑ alk phos, ↑ cholangiocarcinoma risk |
| Hematologic | Iron-, B12-, folate-deficiency anemia |
| Renal | Stones (oxalate in Crohn — fat malabs binds Ca, oxalate absorbed) |
| MSK | Osteoporosis (steroids, vitamin D malabs) |

**Severity (Truelove-Witts for UC):**

| Severity | Stools/d | Blood | HR | Hgb | ESR |
|----------|----------|-------|-----|-----|-----|
| Mild | <4 | Small | <90 | normal | <30 |
| Moderate | 4-6 | Moderate | <90 | mild ↓ | ≤30 |
| Severe | ≥6 | Heavy | >90 or fever | <10.5 | >30 |

**Diagnostic workup:**

| Test | Use |
|------|-----|
| Colonoscopy with biopsies | Definitive — pattern + histology |
| MRE / CT enterography | Crohn (small bowel involvement) |
| Fecal calprotectin | Distinguishes IBD from IBS; trends activity |
| C-diff testing | Always before treating flare |
| Stool studies (cultures, ova/parasites) | Exclude infection |

**Treatment by severity (top-down vs step-up — increasing trend toward early biologic in moderate-severe):**

| Drug class | Agents | Use |
|------------|--------|-----|
| 5-ASA | Mesalamine (oral, topical) | Mild-moderate UC induction + maintenance; less role in Crohn |
| Steroids | Prednisone, **budesonide** (ileocolic Crohn, lower systemic) | Induction only — never maintenance |
| Immunomodulators | Azathioprine, 6-MP, MTX (Crohn) | Steroid-sparing maintenance; check **TPMT** before thiopurine |
| TNF-α inhibitors | Infliximab, adalimumab, certolizumab, golimumab (UC only) | Moderate-severe; screen TB / HBV before |
| Anti-integrin | Vedolizumab | Gut-selective; safer infection profile |
| IL-12/23 | Ustekinumab | Crohn, UC |
| JAK inhibitor | Tofacitinib (UC), upadacitinib | Watch for VTE, infection, malignancy in older |
| S1P modulator | Ozanimod (UC) | Newer |

**Acute severe UC (hospitalized):**
- IV methylprednisolone
- VTE prophylaxis (high VTE risk)
- Day 3 reassessment → if no response: infliximab or cyclosporine **rescue**
- Failure → colectomy

**Toxic megacolon:**

| Criteria (any 3 systemic + colon dilation): |
|----------------------------------------------|
| Colonic dilation **>6 cm** on imaging |
| HR >120 |
| Fever >38.6 |
| WBC >10.5 |
| Anemia, dehydration, electrolyte derangement, altered mental status |

Treatment: bowel rest, NG decompression, IV steroids, broad-spectrum antibiotics; **no anticholinergics, no opioids**, surgery if no improvement in 24-72h.

**Cancer surveillance:**

| Disease | Screening colonoscopy |
|---------|----------------------|
| UC pancolitis | Begin **8 years** after diagnosis, every 1-3 yrs |
| UC left-sided | Begin 8 years, every 1-3 yrs |
| Crohn colonic | Begin 8 years, every 1-3 yrs |
| PSC + IBD | **Annual** colonoscopy |

**Common gotchas:**
- **Always r/o C. diff** before treating IBD flare (and CMV in steroid-refractory)
- **Smoking is protective** for UC, **harmful** for Crohn — but NEVER advise smoking
- **Backwash ileitis** (mild ileal inflammation in pancolitis) does NOT mean Crohn
- **Indeterminate colitis** ~10% — treat empirically
- Anti-TNF screen: **PPD/IGRA, HBV serologies** mandatory; CXR
- **Pyoderma gangrenosum** does NOT parallel disease activity; don't debride (pathergy)

**Rule of thumb:** Bloody diarrhea + rectum-up continuous = UC. Skip lesions, transmural, perianal/fistulas, terminal ileum = Crohn. Treat by severity; biologic earlier in moderate-severe; colectomy cures UC, not Crohn.
