### GI Bleeding

**Upper vs lower:**

| Feature | Upper GI bleed (UGIB) | Lower GI bleed (LGIB) |
|---------|----------------------|----------------------|
| Source | Above ligament of Treitz | Below ligament of Treitz |
| Presentation | Hematemesis, melena, **coffee ground** | Hematochezia |
| BUN:Cr | **>20-30:1** (digested protein → ↑BUN) | Normal |
| NG aspirate | Bloody / coffee ground (positive in 50% — neg doesn't rule out) | Negative |
| Common causes | PUD, varices, Mallory-Weiss, gastritis, esophagitis, malignancy | Diverticular, angiodysplasia, hemorrhoid, IBD, ischemic colitis, malignancy |

**Massive UGIB can present as hematochezia** if transit is fast.

**Initial resuscitation (any GI bleed):**

| Step | Action |
|------|--------|
| 1 | Two large-bore IVs (16-18g) |
| 2 | Type & cross, CBC, BMP, coags, LFTs, lactate |
| 3 | IV fluids (NS or LR), then PRBCs (target Hgb >7; >8 if cardiac) |
| 4 | Reverse anticoagulation if bleeding despite therapy |
| 5 | Restrictive transfusion improves outcomes vs liberal |

**Hgb transfusion thresholds:**

| Setting | Threshold |
|---------|-----------|
| Stable, no cardiac disease | 7 g/dL |
| Cardiac disease / actively bleeding | 8 g/dL |
| Variceal bleed | 7 g/dL (over-transfusion → ↑ portal pressure → re-bleed) |

**UGIB-specific therapy:**

| Cause | Acute therapy |
|-------|---------------|
| All UGIB | **PPI** (pantoprazole 80 mg bolus + drip or BID) |
| Variceal bleed | **Octreotide** (50 mcg bolus + 50 mcg/h drip) + ceftriaxone (↓ infection mortality) + endoscopic banding |
| PUD with high-risk stigmata | Endoscopic clip / inject / cautery + PPI drip 72h |
| Mallory-Weiss | Usually self-limited; endoscopy if persistent |
| Refractory variceal | Balloon tamponade (Blakemore/Minnesota) bridge → TIPS |

**Glasgow-Blatchford score** — pre-endoscopy risk; **score 0** = outpatient candidate. Components: BUN, Hgb, SBP, HR, melena, syncope, hepatic/cardiac disease.

**Forrest classification (PUD on endoscopy):**

| Class | Finding | Re-bleed risk |
|-------|---------|---------------|
| Ia | Active spurting | Very high |
| Ib | Active oozing | High |
| IIa | Visible vessel | High |
| IIb | Adherent clot | Moderate |
| IIc | Flat pigmented spot | Low |
| III | Clean base | Lowest |

Endoscopic intervention for I-IIa (some IIb).

**LGIB common causes (older patients):**

| Cause | Clue |
|-------|------|
| Diverticular | Painless, large-volume, often left colon (sigmoid most affected, but right diverticula bleed more) |
| Angiodysplasia | Slow / chronic, R colon, aortic stenosis (Heyde), CKD |
| Hemorrhoid | Bright red, on toilet paper, painless (internal) |
| IBD | Diarrhea, abdominal pain |
| Ischemic colitis | Abrupt LLQ pain → bloody diarrhea, "watershed" splenic flexure |
| Colorectal cancer | Iron-deficiency anemia, weight loss, change in bowel habit |
| Post-polypectomy | History |

**LGIB workup:**

| Test | When |
|------|------|
| Colonoscopy | Definitive — within 24h after prep |
| CT angiography | Brisk bleed (≥0.3-0.5 mL/min) — localizes |
| Tagged RBC scan | Slower bleeds (≥0.1 mL/min) |
| Mesenteric angiography | Therapeutic (embolization) for active bleed not amenable to endoscopy |

**Variceal bleeding chain:** **resuscitate → octreotide + ceftriaxone → endoscopic banding → TIPS if refractory**. Mortality high; 6-week mortality ~20%.

**Anticoagulation reversal:**

| Drug | Reversal |
|------|----------|
| Warfarin | 4-factor PCC (Kcentra) + IV vitamin K (FFP if PCC unavailable) |
| Heparin | Protamine |
| LMWH | Protamine (partial) |
| Dabigatran | Idarucizumab |
| Apixaban / rivaroxaban | Andexanet alfa or 4-factor PCC |
| Antiplatelet | Platelets (controversial; no benefit in ICH per PATCH trial) |

**Common gotchas:**
- **NG lavage** negative does NOT exclude UGIB (esp. duodenal — pylorus may be closed)
- BUN:Cr >20-30:1 is a clue for UGIB (digested blood + prerenal volume loss)
- **Variceal bleed**: the antibiotic (ceftriaxone) is a **mortality intervention** — don't skip
- **Aortoenteric fistula** — UGIB after AAA repair, often a "herald bleed" days before exsanguination — endoscope + CT
- Coffee-ground emesis without active bleeding still needs PPI + endoscopy

**Rule of thumb:** Two large IVs, transfuse to Hgb 7 (8 if cardiac), PPI for all UGIB, octreotide + ceftriaxone for variceal. UGIB endoscopy <24h. LGIB → colonoscopy after prep; CTA for brisk active bleed.
