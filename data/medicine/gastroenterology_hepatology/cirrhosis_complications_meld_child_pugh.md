### Cirrhosis Complications

**Most common etiologies:**

| Cause | Clue |
|-------|------|
| Alcohol | History; AST:ALT ≈ 2:1 |
| HCV | Risk factor history; treat → cure with DAAs |
| HBV | Vertical / endemic / IVDU |
| NASH / MASH | Obesity, DM, metabolic syndrome |
| Autoimmune hepatitis | ANA, ASMA, IgG |
| PBC | AMA, female, pruritus, ↑alk phos |
| PSC | UC association, beads on MRCP |
| Hemochromatosis | C282Y/H63D, ferritin/TSAT high |
| Wilson | Young, neuro, Kayser-Fleischer, ↓ ceruloplasmin |
| α1-AT def | Emphysema + liver |

**Severity scores:**

| Score | Components |
|-------|-----------|
| Child-Pugh A/B/C | Bilirubin, albumin, INR, ascites, encephalopathy |
| **MELD** (transplant) | Bilirubin, INR, Cr, Na (MELD-Na), now MELD 3.0 |

MELD ≥15 → consider transplant referral.

**Complications and their treatment:**

| Complication | Mechanism | Treatment |
|--------------|-----------|-----------|
| Ascites | Portal HTN + Na/water retention | Salt restrict (<2 g/d), spironolactone + furosemide (100:40 ratio), large-volume paracentesis with albumin if ≥5 L |
| **SBP** | Bacterial translocation | **Cefotaxime / ceftriaxone**; PMN ≥250 cells/mm³ in ascitic fluid is diagnostic; albumin 1.5 g/kg day 1 + 1 g/kg day 3 reduces HRS |
| Variceal bleed | Portal HTN | Resuscitate, octreotide, ceftriaxone, banding, TIPS if refractory; primary prevention with non-selective β-blocker (carvedilol/propranolol) or banding |
| Hepatic encephalopathy | NH3 + other toxins | **Lactulose** (titrate to 2-3 BMs/d) ± **rifaximin**; identify trigger (infection, GI bleed, dehydration, electrolyte) |
| Hepatorenal syndrome (HRS) | Splanchnic vasodilation → renal vasoconstriction | **Albumin + terlipressin** (or norepinephrine + albumin); ultimate Tx is liver transplant |
| Hepatopulmonary syndrome | Intrapulmonary shunting | Orthodeoxia (↓SpO2 standing); transplant cures |
| Hepatocellular carcinoma | Cirrhotic regeneration → dysplasia → HCC | **Surveillance: US ± AFP every 6 mo**; LI-RADS for diagnosis |
| Coagulopathy | ↓ synthesis II, VII, IX, X | INR rises; **rebalanced** hemostasis — don't treat numbers, treat bleeding |
| Hyponatremia | ADH ↑, water retention | Fluid restrict; tolvaptan (caution); rapid correction → ODS |

**SBP diagnosis (ascitic fluid):**

| Finding | Threshold |
|---------|-----------|
| **PMN ≥250/mm³** | Diagnostic |
| Positive culture (single organism) | Confirms |
| Multiple organisms / very high WBC | Secondary peritonitis — surgery! |

Routine SBP prophylaxis: ciprofloxacin or TMP-SMX in patients with prior SBP, low-protein ascites, or active variceal bleed.

**West Haven encephalopathy grading:**

| Grade | Findings |
|-------|----------|
| 0 | Subclinical (only neuropsych testing) |
| 1 | Mild confusion, inverted sleep |
| 2 | Lethargy, asterixis |
| 3 | Somnolent but rousable |
| 4 | Coma |

Triggers: infection (esp. **SBP**), GI bleed, dehydration, electrolyte abn, sedatives, constipation, TIPS, dietary protein.

**Decompensation milestones:**

| Event | Action |
|-------|--------|
| Ascites | Diuretics + salt restriction |
| Variceal bleed | β-blocker / banding |
| Encephalopathy | Lactulose + rifaximin |
| HCC | Imaging Q6 months |
| HRS | Vasoconstrictors + albumin + transplant referral |

**MELD-driven listing** for liver transplant — exceptions for HCC (Milan criteria), hepatopulmonary syndrome.

**Common gotchas:**
- **TIPS** worsens encephalopathy — relative contraindication if pre-existing severe encephalopathy
- **Rapid correction of Na** in cirrhosis → osmotic demyelination
- **Don't transfuse FFP / platelets** "to fix INR" — INR doesn't reflect hemostasis well in cirrhosis
- **Spironolactone gynecomastia** — switch to amiloride or eplerenone
- AST:ALT >2:1 + GGT high = alcoholic liver disease; ALT > AST in NAFLD usually
- **AKI in cirrhosis** workup: pre-renal (most), HRS, ATN, intrinsic renal — needs albumin trial first

**Rule of thumb:** Cirrhosis decompensation = ascites, bleed, encephalopathy, HRS. Each has a clear-cut therapy. SBP needs PMN ≥250 → cefotaxime + albumin. MELD ≥15 → transplant evaluation.
