### CBC Interpretation

**Components:**

| Component | Normal range (adult) |
|-----------|---------------------|
| WBC | 4-11 ×10⁹/L |
| RBC | 4-5.5 ×10¹²/L |
| Hgb | M 14-17, F 12-15 g/dL |
| Hct | M 41-50%, F 36-44% |
| MCV | 80-100 fL |
| MCH | 27-33 pg |
| MCHC | 32-36 g/dL |
| RDW | 11.5-14.5% |
| Platelets | 150-400 ×10⁹/L |

**Differential (adult, %):**

| Cell | Normal |
|------|--------|
| Neutrophils | 50-70 |
| Lymphocytes | 20-40 |
| Monocytes | 2-10 |
| Eosinophils | 1-4 |
| Basophils | 0-1 |

**WBC differential — what each cell tells you:**

| Cell ↑ | Causes |
|--------|--------|
| **Neutrophils** | Bacterial infection, stress, steroids, exercise, post-op, pregnancy, leukemoid reaction, CML |
| **Lymphocytes** | Viral (EBV, CMV, hep, HIV), pertussis, CLL, ALL |
| **Monocytes** | Chronic infection (TB, endocarditis), autoimmune, MDS, CMML |
| **Eosinophils** | **NAACP**: Neoplasia (Hodgkin, eosinophilic leukemia), Asthma/Allergy, Addison/Adrenal insuff, Connective tissue, Parasites; drug reaction (DRESS) |
| **Basophils** | CML (high specificity), allergic, hypothyroid |

| Cell ↓ | Causes |
|--------|--------|
| Neutrophils | Drugs (chemo, antithyroid, clozapine), severe infection / sepsis, BM failure, autoimmune, cyclic |
| Lymphocytes | HIV, steroid, chemo, radiation, sepsis |
| All | Aplastic anemia, BM infiltration, severe sepsis, B12 / folate def, hypersplenism, immunosuppression |

**ANC (Absolute Neutrophil Count):**

| ANC | Risk |
|-----|------|
| ≥1500 | Normal |
| 1000-1500 | Mild neutropenia |
| 500-1000 | Moderate |
| <500 | **Severe (febrile neutropenia)** — empirical antibiotics |
| <100 | Profound; high mortality |

**Febrile neutropenia (ANC <500 + fever ≥38.3 single or ≥38.0 sustained):**

| Step | Action |
|------|--------|
| Cultures (blood × 2, urine, line, sources) | — |
| **Empirical antipseudomonal β-lactam** within 1h | Cefepime, pip-tazo, meropenem |
| Add vanc if catheter / skin / mucositis / hemodynamic instability | — |
| Add antifungal after ~5-7 days persistent fever | Echinocandin or voriconazole or amphotericin |
| MASCC score | Risk stratification (high vs low) |

**Anemia — see anemia workup cheatsheet; quick orientation:**

| MCV | Category |
|-----|----------|
| <80 | Microcytic |
| 80-100 | Normocytic |
| >100 | Macrocytic |

**RDW (red cell distribution width):**

| RDW | Use |
|-----|-----|
| Elevated | Anisocytosis — IDA, mixed anemia, recent transfusion / hemorrhage |
| Normal | Thalassemia, ACD typically (uniform RBCs) |

**Mentzer index** = MCV / RBC count. <13 → thalassemia; >13 → IDA.

**Platelets:**

| Platelet | Significance |
|----------|--------------|
| >1000 (1 million) | Reactive thrombocytosis (infection, bleeding, iron def, post-splenectomy, malignancy) or **essential thrombocythemia** (myeloproliferative) |
| 150-450 | Normal |
| <150 | Thrombocytopenia (see below) |
| <50 | Bleeding risk with surgery / trauma |
| <20 | Spontaneous bleeding risk |
| <10 | High spontaneous bleed risk → transfuse |

**Thrombocytopenia differential:**

| Mechanism | Examples |
|-----------|----------|
| ↓ Production | BM failure, leukemia, chemo, B12/folate, alcohol, viral |
| ↑ Destruction | ITP, TTP, HUS, DIC, HIT, drug-induced (heparin, vanc, sulfa, quinine), post-transfusion purpura |
| Sequestration | Hypersplenism, cirrhosis |
| Dilution | Massive transfusion |
| Pseudothrombocytopenia | EDTA-induced clumping — repeat in citrate |

**Smear (peripheral blood smear) — what to look for:**

| Finding | Significance |
|---------|--------------|
| **Schistocytes** (helmet, fragmented) | MAHA: TTP, HUS, DIC, HELLP, mech valve, malignant HTN |
| **Spherocytes** | HS, AIHA |
| **Bite cells, Heinz bodies** | G6PD deficiency, oxidative |
| **Sickle cells** | Sickle disease |
| **Target cells** | Thalassemia, liver disease, post-splenectomy |
| **Howell-Jolly bodies** | Asplenia / hyposplenia |
| **Basophilic stippling** | Lead poisoning, thalassemia, sideroblastic |
| **Teardrop cells (dacrocytes)** | Myelofibrosis, marrow infiltration |
| **Pencil cells** | IDA |
| **Pappenheimer bodies** | Sideroblastic, asplenia |
| **Ringed sideroblasts** | MDS, sideroblastic anemia |
| **Hypersegmented neutrophils** | B12 / folate deficiency |
| **Smudge cells** | CLL |
| **Auer rods** | AML (esp. APML) |
| **Reactive (atypical) lymphocytes** | Viral (EBV, CMV) |
| **Rouleaux** | High protein states (myeloma, inflammation) |
| **Left shift** (bands, metamyelocytes) | Bacterial infection, marrow stress |
| **Toxic granulation, Döhle bodies, vacuolation** | Severe infection |
| **Blasts** | Leukemia / lymphoma |
| **nRBCs (nucleated RBCs)** | Severe stress, marrow infiltration, myelofibrosis, neonates (normal) |

**Special situations:**

| Situation | CBC clue |
|-----------|----------|
| Pseudohyperkalemia | Marked thrombocytosis or leukocytosis (in vitro release) |
| Pseudohyponatremia | Severe hyperlipidemia / hyperproteinemia |
| Reactive thrombocytosis vs essential | Iron studies, JAK2; reactive resolves with cause |
| Cold agglutinins | Falsely low RBC count, ↑ MCV/MCH |

**Common gotchas:**
- **Pseudothrombocytopenia (EDTA clumping)** — repeat in citrate or heparin; clinical bleeding doesn't match the count
- **"Left shift"** with bands, ↑ neutrophils → bacterial infection
- **Always look at the smear** in unexplained anemia or thrombocytopenia
- **Schistocytes + thrombocytopenia** = MAHA — urgent workup (TTP, HUS, DIC)
- **Lymphocytosis in elderly** = consider CLL (smudge cells)
- **Eosinophilia** with foreign travel → parasites; with new drug → DRESS
- **Tear-drop cells + nRBCs** → think myelofibrosis (BM-replacing process)

**Rule of thumb:** CBC + diff + RDW + smear gives a vast initial picture. WBC pattern → infection vs hematologic. MCV → anemia category. Plt mechanism (production / destruction / sequestration / dilution). Smear is free; always look.
