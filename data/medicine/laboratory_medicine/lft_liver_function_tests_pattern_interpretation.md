### Liver Function Tests (LFTs) — Pattern Interpretation

**Components — what they measure:**

| Test | What it reflects |
|------|------------------|
| **AST (SGOT)** | Hepatocellular damage; also muscle, heart |
| **ALT (SGPT)** | Hepatocellular damage; **liver-specific** |
| **Alk phos** | Cholestasis, bone, placenta, intestine |
| **GGT** | Cholestasis, **alcohol** induction, drugs (anticonvulsants) |
| **Total bilirubin** | Bilirubin overall |
| **Direct (conjugated)** | Cholestasis / hepatocellular |
| **Indirect (unconjugated)** | Hemolysis, Gilbert, Crigler-Najjar |
| **Albumin** | Synthetic function (3-week half-life) |
| **PT / INR** | Synthetic function (acute, hours-days) |

**Three pattern recognition framework:**

| Pattern | AST/ALT | Alk phos | Bilirubin | Causes |
|---------|---------|----------|-----------|--------|
| **Hepatocellular** | ↑↑↑ | mild ↑ | Variable | Viral hepatitis, drug-induced (acetaminophen, ischemia), autoimmune, NAFLD/NASH, hereditary (Wilson, hemochromatosis, α1AT), shock liver |
| **Cholestatic** | mild ↑ | **↑↑↑** | Conjugated ↑ | Bile duct obstruction (stone, stricture, malignancy), PBC, PSC, drug-induced cholestasis, infiltrative |
| **Mixed** | ↑↑ | ↑↑ | Variable | Drug-induced, sepsis, autoimmune flare |

**R ratio** = (ALT/ULN) / (AlkP/ULN). >5 hepatocellular; <2 cholestatic; 2-5 mixed.

**AST/ALT ratio clues:**

| Pattern | Suggests |
|---------|----------|
| **AST:ALT >2:1** | **Alcoholic** liver disease |
| AST:ALT >2 + AST often <500 | Alcoholic |
| ALT > AST | Most viral, NAFLD, drug-induced |
| Both **>1000** | Acetaminophen, ischemia (shock liver), acute viral, autoimmune flare |
| AST/ALT >4 | Wilson disease (rare) |

**Acute hepatic injury patterns:**

| Cause | Pattern |
|-------|---------|
| **Acetaminophen toxicity** | AST/ALT in 1000s, sudden, often very high; also coagulopathy + acidosis + AKI in severe; treat with NAC |
| **Ischemic ("shock liver")** | AST/ALT in 1000s, **rapid rise and fall** (1-3 days); LDH usually high too; resolves with hemodynamics |
| Acute viral | AST/ALT 500-5000+; jaundice; +viral serologies |
| Autoimmune | High; + ANA, ASMA, IgG; treat steroids |

**Cholestasis workup:**

| Step | Detail |
|------|--------|
| Confirm | GGT (mirrors alk phos in liver origin); if alk phos ↑ but GGT normal → bone source |
| Imaging | **RUQ US first** — duct dilation? gallstones? mass? |
| If ducts dilated | MRCP / ERCP — stone, stricture, mass |
| If ducts not dilated | Consider intrahepatic — PBC (AMA), PSC (MRCP shows beading; UC association), drugs, infiltrative |
| Antibodies | AMA (PBC), pANCA (PSC) |

**Bilirubin patterns:**

| Type | Causes |
|------|--------|
| **Indirect (unconjugated) hyperbilirubinemia** | Hemolysis (↑LDH, ↓ haptoglobin, ↑ retic), Gilbert (mild, fasting/stress, otherwise normal), Crigler-Najjar (severe, neonates) |
| **Direct (conjugated)** | Hepatocellular injury, cholestasis (intra- or extrahepatic), Dubin-Johnson, Rotor |

**Synthetic function tests:**

| Test | Note |
|------|------|
| **PT / INR** | Acute (factor VII has shortest t½) — first to rise in liver failure |
| **Albumin** | Chronic (3-wk t½) |
| **Glucose** | Hypoglycemia in severe acute liver failure |
| **Ammonia** | Encephalopathy correlate (imperfect) |

**Acute liver failure (ALF) — definition:**

| Criterion |
|-----------|
| **INR ≥1.5 + encephalopathy** in patient without prior cirrhosis, illness <26 weeks |

| Cause | Frequency |
|-------|-----------|
| Acetaminophen | Most common in US |
| Idiosyncratic drug | INH, phenytoin, antibiotics, herbals, kratom |
| Viral (HAV, HBV, HEV) | Less in US |
| Autoimmune | — |
| Wilson | Younger, hemolysis with low alk phos and Kayser-Fleischer |
| Ischemia | Shock states |
| HELLP, AFLP | Pregnancy |

**ALF management:** transfer to transplant center; NAC for any acute (helps non-acetaminophen too); manage encephalopathy, ICP (severe), bleeding (don't reflex transfuse FFP for INR alone), infections, hypoglycemia, AKI.

**King's College Criteria** — emergency liver transplant.

**Chronic LFT abnormality workup (>6 months):**

| Test |
|------|
| HBV (HBsAg, anti-HBc, anti-HBs) |
| HCV antibody → RNA |
| Iron studies (hemochromatosis): ferritin, TSAT >45%, HFE genotype |
| Ceruloplasmin (Wilson) |
| α1-antitrypsin level + phenotype |
| ANA, ASMA, IgG (autoimmune hepatitis) |
| AMA, pANCA (PBC, PSC) |
| US for fatty liver / fibroscan |
| TSH |

**Fatty liver disease (NAFLD / MASLD):**

| Item | Detail |
|------|--------|
| Spectrum | Steatosis → NASH (with inflammation) → fibrosis → cirrhosis |
| Risk | Metabolic syndrome, T2DM, obesity |
| Treatment | Weight loss (≥7-10%), exercise, treat metabolic syndrome; **resmetirom** (THR-β agonist) approved for NASH with fibrosis; pioglitazone, vitamin E in selected; GLP-1 agonists |

**Common gotchas:**
- **Acetaminophen toxicity timing**: levels at **4h post-ingestion**, plot on Rumack-Matthew nomogram; NAC works even after 8h
- **AST:ALT >2 + GGT high + macrocytosis** → alcohol
- **ALT, AST normal does NOT rule out cirrhosis** — synthetic / compensated cirrhotics can be enzyme-normal
- **Wilson** can present with **AST:ALT >4** + low alk phos + hemolysis (Coombs-negative)
- **Drug-induced** is the most common cause of ALF idiosyncratically and mimics anything
- **Don't transfuse FFP for INR alone** in cirrhotic / ALF patients — INR doesn't reflect bleeding risk well

**Rule of thumb:** Pattern (R ratio) → category. Hepatocellular = viral/drug/ischemia/autoimmune/NAFLD; cholestatic = obstruction/PBC/PSC. Synthetic (PT/albumin) tells severity. ALF = INR ≥1.5 + encephalopathy → transfer to transplant center, give NAC.
