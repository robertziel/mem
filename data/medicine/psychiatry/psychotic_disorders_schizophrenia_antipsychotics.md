### Psychotic Disorders & Antipsychotics

**DSM-5 psychotic disorders by duration:**

| Disorder | Duration | Symptoms |
|----------|----------|----------|
| **Brief psychotic disorder** | <1 month | ≥1 of: delusions, hallucinations, disorganized speech, disorganized/catatonic behavior |
| **Schizophreniform** | 1-6 months | Schizophrenia criteria |
| **Schizophrenia** | **≥6 months** total (with ≥1 month of active phase) | ≥2 of: delusions, hallucinations, disorganized speech, disorganized behavior, **negative symptoms**; one must be from first 3 |
| **Schizoaffective** | Mood episode with concurrent psychosis + psychosis ≥2 wk **without** mood episode | Mixed |
| **Delusional disorder** | ≥1 month | Non-bizarre delusions, otherwise functional; **no hallucinations** required |
| **Substance/medical-induced** | — | Direct cause |
| **Shared psychotic / folie à deux** | — | Now under "other" — delusion shared with close other |

**Symptom domains:**

| Type | Examples |
|------|----------|
| **Positive** | Hallucinations (auditory most common), delusions, disorganized speech/behavior |
| **Negative** | **5 A's**: Affect (flat), Avolition, Anhedonia, Alogia, Asociality |
| **Cognitive** | Working memory, attention, executive — major functional driver |
| Mood | Depression, suicidality common |

**Schizophrenia epidemiology:**

| Item | Detail |
|------|--------|
| Lifetime prevalence | ~1% |
| Onset | Late teens-20s (♂ earlier than ♀) |
| Genetic | High heritability; twin concordance ~50% |
| Suicide | ~5-10% lifetime |
| Substance use comorbidity | Very common |

**Antipsychotic classes:**

| Generation | Examples | Mechanism |
|------------|----------|-----------|
| **First (typical)** | Haloperidol, fluphenazine, chlorpromazine, perphenazine | D2 antagonist; high-potency (haldol) → EPS; low-potency (chlorpromazine) → anticholinergic + sedation |
| **Second (atypical)** | Risperidone, olanzapine, quetiapine, aripiprazole, ziprasidone, paliperidone, lurasidone, asenapine, clozapine, brexpiprazole, cariprazine | D2 + 5-HT2A; **less EPS, more metabolic** |
| **Third (partial agonist)** | Aripiprazole, brexpiprazole, cariprazine | D2 partial agonist + 5-HT |

**Side effects to recognize:**

| AE | Drug class | Detail |
|----|-----------|--------|
| **Acute dystonia** | High-potency typicals | Hours-days; treat **benztropine, diphenhydramine** |
| **Akathisia** | Both, more typicals | Inner restlessness; β-blocker, benzo, dose adjust |
| **Parkinsonism** | High-potency typicals | Bradykinesia, tremor, rigidity; benztropine, dose ↓ |
| **Tardive dyskinesia** | Typicals (more), atypicals | Months-years; involuntary face/tongue movements; **VMAT2 inhibitors (valbenazine, deutetrabenazine)**; switch to clozapine |
| Hyperprolactinemia | Risperidone, paliperidone, typicals | Galactorrhea, amenorrhea, sexual dysfunction; aripiprazole alternative |
| **Metabolic** | **Olanzapine, clozapine** worst; quetiapine, risperidone moderate; aripiprazole, ziprasidone, lurasidone less | Weight, glucose, lipids — monitor every visit / quarterly / yearly |
| QT prolongation | Ziprasidone, IV haloperidol, thioridazine | ECG before/after |
| Anticholinergic | Low-potency typicals, clozapine | Dry mouth, constipation, urinary retention |
| Sedation | Quetiapine, olanzapine, chlorpromazine | — |
| **Agranulocytosis** | **Clozapine** | REMS — weekly CBC × 6 mo |
| **Myocarditis, seizures** | Clozapine | First weeks |
| **Neuroleptic malignant syndrome (NMS)** | Any antipsychotic | Lead-pipe rigidity, fever, autonomic, ↑CK, ↑WBC; **stop drug, supportive, dantrolene, bromocriptine** |
| Hyperthermia | Especially in summer; chlorpromazine | — |

**Clozapine:**

| Indication |
|-----------|
| Refractory schizophrenia (≥2 antipsychotic failures) |
| **Reduces suicide risk** (FDA-approved indication) |

| Required | Detail |
|----------|--------|
| ANC monitoring | Weekly × 6 mo, biweekly × 6 mo, then monthly |
| Watch | Myocarditis, seizures, agranulocytosis, GI hypomotility (severe constipation), drooling |

**Acute agitation / first break:**

| Step | Detail |
|------|--------|
| 1 | Verbal de-escalation, environment |
| 2 | **Oral if accepted** (olanzapine, risperidone, lorazepam) |
| 3 | IM if needed: haloperidol + lorazepam ± diphenhydramine ("B-52"), or olanzapine IM, ziprasidone IM (avoid benzo + olanzapine IM together) |
| 4 | Search trigger: substance, medical (delirium ≠ psychosis) |

**Maintenance:**

| Agent | Use |
|-------|-----|
| LAI (long-acting injectable) | Adherence concerns; haloperidol decanoate, risperidone microspheres / consta, paliperidone palmitate, aripiprazole monohydrate |
| Adjunct mood stabilizer / antidepressant | Schizoaffective, depressive symptoms |

**Differential of psychosis:**

| Cause |
|-------|
| Substance: amphetamines, cocaine, cannabis (esp. high-THC), hallucinogens, PCP, alcohol withdrawal, steroid |
| Medical: thyroid (hyper/hypo), neurosyphilis, B12 deficiency, lupus cerebritis, autoimmune encephalitis (NMDA-R), brain tumor, temporal lobe epilepsy, HIV, prion |
| Delirium: acute, fluctuating, attentional, often reversible |
| Mood disorder with psychotic features |
| Personality disorder (cluster A — schizotypal, paranoid) |
| Postpartum psychosis (urgent) |

**Common gotchas:**
- **Auditory hallucinations** more typical for primary psychiatric; **visual / tactile** more often medical / substance
- **First-episode psychosis** under 30 → check NMDA-R antibody, autoimmune encephalitis, MRI
- **NMS vs serotonin syndrome**: NMS = lead-pipe rigidity, hyporeflexia; serotonin = clonus, hyperreflexia, GI
- **Clozapine constipation can be fatal** (ileus → perforation)
- **EPS** time course: acute dystonia (hours-days), parkinsonism (days-weeks), akathisia (weeks), tardive (months-years)
- **Postpartum psychosis** — psychiatric emergency, hospitalize, infanticide risk

**Rule of thumb:** Schizophrenia ≥6 mo + ≥2 symptoms (incl. positive). Choose antipsychotic by side-effect profile (metabolic vs EPS vs prolactin). Clozapine for refractory + suicidality. NMS → stop drug + supportive. First-episode → search medical/substance cause.
