### Mood Disorders — MDD vs Bipolar

**DSM-5 mood disorders summary:**

| Disorder | Episodes | Hallmark |
|----------|----------|----------|
| **MDD** | ≥1 major depressive episode (MDE), no mania/hypomania | Sustained sadness/anhedonia + neurovegetative |
| **Persistent depressive disorder (dysthymia)** | Depressed mood ≥2 yrs, less severe | Chronic, low-grade |
| **Bipolar I** | ≥1 manic episode | Euthymia/depression + mania |
| **Bipolar II** | ≥1 hypomanic + ≥1 MDE; **no mania** | Less severe high |
| **Cyclothymia** | ≥2 yrs (1 in kids) of subsyndromal hypomania + depression | Chronic mood instability |
| **Disruptive mood dysregulation disorder** | Children — chronic irritability + outbursts | Pediatric only |
| Premenstrual dysphoric disorder | Mood changes luteal phase | — |

**Major depressive episode — criteria (≥5 of 9, ≥2 weeks; must include depressed mood or anhedonia):**

| **SIG E CAPS** |
|----------------|
| Sleep ↑/↓ |
| Interest ↓ (anhedonia) |
| Guilt/worthlessness |
| Energy ↓ |
| Concentration ↓ |
| Appetite/weight Δ |
| Psychomotor change |
| Suicidal ideation |
| Mood depressed |

**Mania (≥7 days; or any duration if hospitalized) — DIG FAST:**

| Letter | Symptom |
|--------|---------|
| D | Distractibility |
| I | Insomnia / decreased need for sleep |
| G | Grandiosity |
| F | Flight of ideas / racing thoughts |
| A | Activities increased / Agitation |
| S | Speech (pressured, more talkative) |
| T | Thoughtlessness (risky behavior) |

≥3 (≥4 if mood only irritable) + abnormally elevated/irritable mood + impairment / hospitalization / psychosis = **mania**.

**Hypomania:** ≥4 days, **no marked impairment, no psychosis, no hospitalization**.

**Differentiating MDD vs Bipolar II depression — can look identical:**

| Clue suggesting bipolar | Detail |
|-------------------------|--------|
| Earlier age of onset (<25) | — |
| Family history of bipolar | — |
| Prior antidepressant-induced "switch" / activation | — |
| Hypersomnia, hyperphagia (atypical features) | — |
| Postpartum onset | — |
| Brief, recurrent depressions | — |
| Psychotic features | — |
| Treatment-resistant depression | — |

**Treatment:**

| Disorder | First-line |
|----------|-----------|
| MDD | **SSRI / SNRI** + psychotherapy (CBT, IPT); add bupropion or mirtazapine if needed |
| Treatment-resistant MDD | Augment (lithium, T3, atypical antipsychotic — aripiprazole, quetiapine); switch class; **ECT, esketamine** |
| MDD with psychosis | Antidepressant + antipsychotic, or **ECT** |
| Bipolar mania | **Lithium**, valproate, atypical antipsychotic (olanzapine, risperidone, quetiapine, aripiprazole); admit if severe |
| Bipolar depression | **Quetiapine, lurasidone, olanzapine-fluoxetine, lamotrigine, lithium, cariprazine, lumateperone**; **avoid antidepressant monotherapy** (switch risk) |
| Bipolar maintenance | Lithium (gold standard), lamotrigine (depression-prevention), valproate, atypicals |
| Postpartum | **Brexanolone** or zuranolone if severe; SSRI; check for bipolar |

**Antidepressant classes:**

| Class | Notes / side effects |
|-------|----------------------|
| SSRI | First-line; sexual dysfunction, GI, weight, hyponatremia |
| SNRI | Same + ↑ BP; pain symptoms (duloxetine, venlafaxine) |
| Bupropion | Activating, no sexual SE, **lowers seizure threshold** (avoid eating disorders) |
| Mirtazapine | Sedating, ↑ appetite — useful in cachectic / insomnia |
| TCA | Anticholinergic, **lethal in OD**, QT/QRS widening |
| MAOI | Tyramine crisis (food + drug interactions); 2-week washout from SSRI (5 weeks fluoxetine) |
| Trazodone | Insomnia adjunct (low dose); priapism rare |
| Vilazodone, vortioxetine | Newer, fewer sexual SE |
| Esketamine (intranasal) | TR depression; dissociation; REMS |

**Lithium pearls:**

| Item | Detail |
|------|--------|
| Therapeutic level | 0.6-1.2 mEq/L (acute up to 1.5) |
| Toxicity | Tremor, ataxia, dysarthria, AKI, seizures (>2.5 → dialysis) |
| Adverse | **Nephrogenic DI**, hypothyroidism (check baseline + Q6mo), Ebstein anomaly (1st trimester) |
| Drugs that ↑ levels | NSAIDs, ACEi/ARB, thiazides |
| Narrow therapeutic index | Monitor levels |

**ECT — when to use:**

| Indication |
|-----------|
| Severe MDD with psychosis |
| Catatonia |
| Suicidality requiring rapid response |
| Treatment-resistant |
| Pregnancy (preferred over many drugs) |
| Severe mania refractory |
| Postpartum psychosis |

**Suicide risk assessment:**

| **SAD PERSONS** |
|-----------------|
| Sex (male), Age, Depression, Previous attempt, Ethanol, Rational thinking loss, Social support lacking, Organized plan, No spouse, Sickness |

Always assess: ideation, plan, intent, means, history, current. Document.

**Common gotchas:**
- **Antidepressant monotherapy in bipolar** can cause manic switch / rapid cycling — always pair with mood stabilizer
- **SSRI takes 4-6 wks** for full effect; warn about early activation, GI, sexual SE; discontinuation syndrome (taper)
- **Serotonin syndrome** — fever, autonomic, hyperreflexia, clonus (lower extremity > upper); cyproheptadine, supportive
- **MAOI + SSRI / triptan / meperidine / dextromethorphan / linezolid** — serotonin syndrome
- **Lithium toxicity precipitants**: dehydration, NSAID, ACEi, thiazide
- **Neuroleptic malignant syndrome** ≠ serotonin syndrome — NMS = lead-pipe rigidity, hyporeflexia, fever, ↑CK; treat dantrolene, bromocriptine

**Rule of thumb:** Mood + neurovegetative ≥2 wk = MDD. Mania ≥7 days or any hospitalized = bipolar I. Don't antidepressant-monotherapy bipolar. Lithium gold standard for bipolar maintenance. ECT for severe / urgent / refractory.
