### Anxiety, OCD, Trauma-Related Disorders

**DSM-5 separates anxiety / OCD-related / trauma-related into distinct chapters; clinically still grouped:**

| Disorder | Hallmark |
|----------|----------|
| **GAD** | Excessive worry ≥6 mo about multiple things + 3 of 6 (restlessness, fatigue, concentration, irritability, muscle tension, sleep) |
| **Panic disorder** | Recurrent **unexpected panic attacks** + 1 mo worry about more attacks or behavioral change |
| **Agoraphobia** | Fear of ≥2 of: public transit, open spaces, enclosed spaces, lines/crowds, being outside home alone |
| **Social anxiety disorder** | Fear of scrutiny / embarrassment in social situations |
| **Specific phobia** | Marked fear of specific object/situation |
| **Selective mutism** | Failure to speak in specific social settings (children) |
| **Separation anxiety disorder** | Excessive distress with separation |
| **OCD** | Obsessions (intrusive) + compulsions (rituals) ≥1 hr/day or impairment |
| **Body dysmorphic disorder** | Preoccupation with perceived defect |
| **Hoarding disorder** | Persistent difficulty discarding |
| **Trichotillomania, excoriation** | Hair-pulling, skin-picking |
| **PTSD** | Trauma exposure + intrusion + avoidance + negative cognition + arousal **>1 month** |
| **Acute stress disorder** | Same symptoms but **3 days–1 month** |
| **Adjustment disorder** | Stressor-related, doesn't meet other criteria |

**Panic attack criteria:** sudden surge of intense fear + ≥4 of: palpitations, sweating, trembling, SOB, choking, chest pain, nausea, dizziness, **chills/heat, paresthesia, derealization, fear of losing control, fear of dying**, peaks <10 min.

**Treatment overview:**

| Disorder | First-line |
|----------|-----------|
| GAD | SSRI / SNRI + CBT |
| Panic | SSRI / SNRI + CBT (interoceptive exposure); benzo short-term bridge |
| Social anxiety | SSRI / SNRI + CBT; β-blocker / benzo for performance-only |
| Specific phobia | **Exposure therapy** (most effective) |
| **OCD** | **SSRI (high doses)** or clomipramine + **ERP (exposure response prevention)** |
| **PTSD** | Trauma-focused CBT (prolonged exposure, CPT) + **SSRI (sertraline, paroxetine)**; **prazosin** for nightmares |
| Acute stress | Watchful waiting + brief CBT; avoid benzo (worsens PTSD) |

**Why benzos are second-line:**
- Tolerance, dependence, withdrawal (seizures with abrupt stop)
- Cognitive impairment, falls (elderly)
- Worsens PTSD outcomes
- Polysubstance / overdose risk with opioids

**Use cases for benzos:**
- Acute / very brief during SSRI ramp-up
- Procedural anxiety
- Alcohol withdrawal
- Status epilepticus
- Severe agitation with antipsychotic

**Anti-anxiety medications:**

| Drug | Notes |
|------|-------|
| SSRI / SNRI | First-line |
| Buspirone | GAD; **no sedation, no dependence**; 2-week onset |
| Hydroxyzine | Antihistamine; PRN |
| Pregabalin / gabapentin | GAD adjunct (Europe approved); social anxiety |
| Propranolol | Performance anxiety, somatic symptoms |
| Benzodiazepines | Short-term only |

**OCD specifics:**

| Item | Detail |
|------|--------|
| First-line meds | SSRI at higher doses than for depression (e.g., sertraline 200, fluoxetine 60-80) |
| Slower onset of response (8-12 weeks) | — |
| Augmentation | Atypical antipsychotic (risperidone, aripiprazole) |
| Severe / refractory | Clomipramine, deep brain stimulation |
| Therapy | **ERP > CBT alone** |
| Comorbid | Tic disorders, depression, anxiety |

**PTSD specifics:**

| Cluster | Examples |
|---------|----------|
| Intrusion | Flashbacks, nightmares, intrusive memories |
| Avoidance | Of trauma reminders |
| Negative cognition / mood | Anhedonia, distorted blame, detachment |
| Arousal / reactivity | Hypervigilance, startle, sleep, irritability, reckless |

| Treatment | Detail |
|-----------|--------|
| Trauma-focused therapy | **Prolonged exposure**, CPT, EMDR |
| SSRI / SNRI (sertraline, paroxetine, venlafaxine) | First-line meds |
| Prazosin | Nightmares |
| Avoid benzodiazepines | Worsens PTSD |
| Newer | Topiramate, atypical antipsychotics (augmentation) |

**Differentiating panic attack from medical emergency:**

| Symptom | Panic | Medical |
|---------|-------|---------|
| Chest pain + palpitations | Often, peak <10 min | Sustained, exertion-related, ECG changes |
| Tachycardia | Yes | Yes |
| Tremor / sweating | Yes | Hypoglycemia, thyroid storm, pheo |
| Workup | TSH, ECG, glucose, drug screen, troponin if first/severe | Same |

**Common gotchas:**
- **Don't assume anxiety in a new presentation** without workup — pheo, hyperthyroid, arrhythmia, PE, MI mimic
- **Benzodiazepines worsen PTSD** outcomes
- **OCD needs higher SSRI doses + ERP** — undertreatment is common
- **Prazosin for PTSD nightmares** — orthostatic at start
- **Beta-blocker propranolol** for performance anxiety, not chronic anxiety
- **Buspirone takes 2 weeks** — not for acute relief
- "Selective mutism" looks like shyness; it's an anxiety disorder requiring treatment

**Rule of thumb:** Anxiety / OCD / PTSD all → SSRI (high-dose for OCD) + therapy (ERP for OCD, trauma-focused for PTSD, CBT for GAD/panic, exposure for phobia). Benzos are short-term bridges. Prazosin for PTSD nightmares. Always rule out medical mimics first time.
