### Levels of Prevention

**Three classic levels:**

| Level | Goal | Examples |
|-------|------|----------|
| **Primary** | Prevent disease before it occurs | Vaccination, smoking cessation counseling, helmets, seatbelts, fluoridation, exercise, healthy diet |
| **Secondary** | Detect disease early to halt progression | Cancer screening (mammogram, colonoscopy, Pap), BP screening, HbA1c, HIV testing, mammography |
| **Tertiary** | Reduce complications/disability of established disease | Cardiac rehab, glycemic control to prevent micro/macrovasc, anticoagulation in AF to prevent stroke, retinal screening in DM |
| (Sometimes Quaternary) | Avoid overmedicalization / iatrogenic harm | Avoiding unnecessary tests, deprescribing |

**Examples by intervention:**

| Intervention | Level |
|--------------|-------|
| MMR vaccine in child | Primary |
| Flu vaccine in elderly | Primary |
| Folate in pregnancy | Primary |
| HPV vaccine | Primary |
| Mammogram in 50yo | Secondary |
| Colonoscopy in 45yo | Secondary |
| HbA1c every 3 months in DM | Tertiary (prevent complications) |
| Cardiac rehab post-MI | Tertiary |
| Seatbelt | Primary |
| Bike helmet | Primary |
| Aspirin **after** MI (secondary prevention of CV events) | Tertiary (despite "secondary prevention" terminology in cardiology — different definition!) |
| Aspirin in healthy 70yo for MI prevention | Primary |
| Annual eye exam in DM | Tertiary |
| Quit smoking program in healthy patient | Primary |

**Cardiology terminology overlap (confusing):**
- "Primary prevention" in cardiology = before any clinical event = primary in epi
- "**Secondary prevention**" in cardiology = preventing **recurrent** events after MI/stroke = **tertiary** in epi sense

Be aware of this dual usage.

**Determinants of health (broader view):**

| Determinant | Examples |
|-------------|----------|
| Genetic / biological | Inheritance, age, sex |
| Behavioral | Smoking, diet, exercise, alcohol, drugs, sex, sleep |
| Environmental | Air, water, housing, occupation, climate |
| Social | Income, education, culture, family, community |
| Healthcare access | Insurance, providers, geography, cost |
| Public policy | Laws, regulations, funding |

**Health Belief Model (predicts behavior change):**

| Construct | Detail |
|-----------|--------|
| Perceived susceptibility | "Can this happen to me?" |
| Perceived severity | "Is it serious?" |
| Perceived benefits | "Will the action help?" |
| Perceived barriers | "What's in the way?" |
| Cues to action | Triggers (symptom, news, family event) |
| Self-efficacy | "Can I do it?" |

**Stages of Change (Transtheoretical Model):**

| Stage | Patient |
|-------|---------|
| Precontemplation | Not thinking about change |
| Contemplation | Considering |
| Preparation | Plan to act soon |
| Action | Recently changed (<6 mo) |
| Maintenance | Sustained (≥6 mo) |
| Relapse | Reverted (normal part of cycle) |

**Motivational interviewing — OARS:**

| Letter | Skill |
|--------|-------|
| O | Open-ended questions |

| R | Reflective listening |
| S | Summarize |

Plus: elicit change talk, roll with resistance, support self-efficacy.

**Health promotion vs disease prevention:**

| Health promotion | Disease prevention |
|------------------|-------------------|
| Build positive health (well-being, fitness, resilience) | Avoid specific disease |
| Wider scope (population, lifestyle) | Specific (vaccine, screening) |
| Empowerment-focused | Risk-reduction-focused |

**5 A's (counseling framework, e.g., smoking cessation):**

| A | Action |
|---|--------|
| **Ask** | Tobacco use status |
| **Advise** | Quit |
| **Assess** | Willingness |
| **Assist** | Resources, medications, plan |
| **Arrange** | Follow-up |

**Smoking cessation pharmacotherapy:**

| Option | Notes |
|--------|-------|
| **NRT** (patch + short-acting) | Combination most effective |
| **Varenicline** | Most effective monotherapy; NPS warning removed |
| **Bupropion** | Useful if depression / weight concern; lowers seizure threshold |
| Combinations | NRT + varenicline / bupropion |
| Behavioral counseling | Quitlines, apps, group |

**Prevention pearls / common pitfalls:**

| Item | Detail |
|------|--------|
| Vaccinate everyone eligible | Lethal under-vaccination is common; especially flu, COVID, pneumo, zoster, RSV in elderly |
| Tobacco | Largest preventable cause of premature death; brief counseling at every visit |
| Alcohol | SBIRT (Screening, Brief Intervention, Referral to Treatment); ~10% of mortality |
| Diet / exercise | Mediterranean diet, 150 min moderate / 75 vigorous + strength 2× weekly |
| Mental health | Screen for depression / anxiety / suicide; address SDOH |
| Falls | In elderly: vision, footwear, home safety, vitamin D, exercise (Tai Chi, balance) |
| Overdiagnosis | Be aware: PSA, mammography in low risk, thyroid nodules, low-grade prostate cancer |

**Common gotchas:**
- **Tertiary in epidemiology = "secondary prevention" in cardiology** — same intervention different label
- **Overdiagnosis is real** — PSA, thyroid, mammography in lowest-risk groups
- **Primary > secondary > tertiary** in cost-effectiveness usually — vaccination, smoking cessation are huge
- **Behavior change requires stage-matched intervention** — don't "preach" to a precontemplator
- **Quaternary prevention** (avoiding overmedicalization) is increasingly recognized
- **Health disparities** — interventions must reach populations most at risk
- **Population vs individual** preventive efforts — both needed (Geoffrey Rose)

**Rule of thumb:** Primary = before disease. Secondary = early detection. Tertiary = limit complications. Vaccination + smoking cessation + screening per USPSTF + lifestyle counseling = high-yield primary care prevention. Match intervention to behavior-change stage.
