### Cell Injury, Necrosis, Apoptosis

**Reversible vs irreversible cell injury:**

| Feature | Reversible | Irreversible |
|---------|-----------|--------------|
| ATP | ↓ (Na/K pump fails) | Severely ↓ |
| Cellular swelling | Yes | Yes |
| Mitochondrial swelling | Slight | Severe + amorphous Ca densities |
| Plasma membrane | Intact | **Ruptured** |
| Nuclear changes | None | Pyknosis → karyorrhexis → karyolysis |
| Calcium influx | Mild | Massive (mitochondrial damage) |
| Reversal possible? | Yes | **No** |

**Necrosis vs apoptosis:**

| Feature | Necrosis | Apoptosis |
|---------|----------|-----------|
| Cause | Pathologic injury | Programmed (physiologic or pathologic) |
| Cell size | Swelling | Shrinkage |
| Membrane | Ruptured | Intact (blebs) |
| Nucleus | Pyknosis → karyorrhexis → karyolysis | Fragmentation, condensation |
| Inflammation | **Yes** | No |
| ATP required? | No | **Yes** |
| Pattern | Random groups of cells | Single cells |

**Apoptosis pathways:**

| Pathway | Trigger | Key molecules |
|---------|---------|--------------|
| Intrinsic (mitochondrial) | DNA damage, withdrawal of growth factor, hypoxia | **Bcl-2** (anti-), **Bax/Bak** (pro-), cytochrome c, Apaf-1, caspase-9 |
| Extrinsic (death receptor) | Fas-FasL (immune), TNF | FADD, caspase-8 |
| Cytotoxic T-cell | CTL-target | **Perforin** + **granzyme**, caspase activation |

Final common path: **caspase-3** executes apoptosis.

**Necrosis types:**

| Type | Cause | Examples |
|------|-------|----------|
| Coagulative | Ischemia (most organs) | MI, kidney infarct, splenic infarct |
| Liquefactive | Brain ischemia, abscess | Stroke, bacterial infections |
| Caseous | TB, fungal | Granulomas |
| Fat | Pancreatitis, breast trauma | "Soap" formation (saponification) |
| Fibrinoid | Immune-mediated vascular damage | Vasculitis, malignant HTN, preeclampsia |
| Gangrenous | Limb ischemia (dry/wet) | DM, PAD; wet = + bacterial infection |

**Brain is unique** — uses **liquefactive** (lots of lipid + lysosomal enzymes from microglia).

**Free radical injury:**

| Source | Mechanism |
|--------|-----------|
| Reperfusion (ischemia → flow restored) | O2 returns → ROS surge |
| Radiation | Ionizes water → OH• |
| Drugs (CCl4, acetaminophen, doxorubicin) | Metabolite radicals |
| Inflammation | Neutrophil/macrophage NADPH oxidase (oxidative burst) |
| Iron / copper | Fenton reaction (Hb breakdown, hemochromatosis) |

**Antioxidants:** glutathione, vitamin C/E, catalase, SOD, glutathione peroxidase.

**Hypoxic injury sequence:**
1. ↓ O2 → ↓ ATP
2. Na/K pump fails → cellular swelling
3. Anaerobic glycolysis → ↓ pH → chromatin clumping
4. Detachment of ribosomes → ↓ protein synthesis
5. Ca++ influx → enzyme activation (phospholipases, proteases, endonucleases, ATPases)
6. Membrane damage → **point of no return**

**Most vulnerable cells (hypoxia order):**

| Time to die | Tissue |
|-------------|--------|
| 3-5 min | Neurons (especially CA1 hippocampus, cerebellar Purkinje) |
| 30 min | Cardiomyocytes |
| 2 h | Hepatocytes (centrilobular zone 3 first) |
| Hours-days | Skeletal muscle, fibroblasts |

**Intracellular accumulations:**

| Substance | Disease |
|-----------|---------|
| Lipid (steatosis) | Alcohol, NASH, malnutrition, hepatotoxin |
| Protein | α1-antitrypsin (PAS+ globules), Mallory bodies (alcohol) |
| Glycogen | DM, glycogen storage diseases |
| Lipofuscin | Aging ("wear and tear") |
| Hemosiderin | Iron overload, hemorrhage, chronic transfusion |
| Calcium (dystrophic) | Necrotic tissue, atherosclerotic plaque, TB |
| Calcium (metastatic) | Hypercalcemia → kidney, lung, gastric mucosa |

**Common gotchas:**
- **Reperfusion injury** — letting blood back in causes free-radical damage; sometimes worse than ischemia alone
- **Coagulative necrosis** preserves cell outline; **liquefactive** dissolves it
- **Caseous = TB / fungi** until proven otherwise
- **Fibrinoid necrosis** = immunologic vessel damage (vasculitis, malignant HTN)
- **Apoptosis is silent** — no inflammation, often missed without TUNEL or caspase IHC

**Rule of thumb:** Necrosis = bad, messy, inflammatory. Apoptosis = controlled, ATP-needed, silent. Type of necrosis tells the cause: coagulative=ischemia, liquefactive=brain/abscess, caseous=TB, fat=pancreas, fibrinoid=vessel, gangrene=limb.
