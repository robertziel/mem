### Inflammation — Acute and Chronic

**Five cardinal signs (Latin):**

| Sign | English | Mechanism |
|------|---------|-----------|
| Rubor | Redness | Vasodilation |
| Calor | Heat | ↑ blood flow |
| Tumor | Swelling | ↑ vascular permeability → edema |
| Dolor | Pain | Bradykinin, PGE2, sensitization |
| Functio laesa | Loss of function | All of above |

**Acute vs chronic:**

| Feature | Acute | Chronic |
|---------|-------|---------|
| Onset | Minutes-hours | Days-weeks-years |
| Cellular infiltrate | **Neutrophils** | **Lymphocytes, plasma cells, macrophages** |
| Tissue findings | Edema, exudate | Fibrosis, granulomas, tissue destruction |
| Outcome | Resolution, abscess, healing | Scar, organ dysfunction, neoplasia |

**Acute inflammation steps:**
1. **Vascular** — vasodilation, ↑ permeability (histamine, bradykinin)
2. **Cellular** — neutrophil margination → rolling (selectins) → adhesion (integrins) → transmigration (PECAM/CD31) → chemotaxis
3. **Phagocytosis** — opsonization (IgG, C3b) → engulfment → killing (ROS, NO)

**Adhesion molecules:**

| Step | Molecules |
|------|-----------|
| Rolling | Sialyl-Lewis X (leukocyte) ↔ E-/P-selectin (endothelium, induced by TNF/IL-1) |
| Tight adhesion | Integrins (LFA-1, Mac-1) ↔ ICAM-1, VCAM-1 |
| Transmigration | PECAM-1 (CD31) |

**LAD type 1** = β2 integrin defect → no adhesion → leukocytes can't exit → no pus.

**Mediators:**

| Mediator | Source | Action |
|----------|--------|--------|
| Histamine | Mast cells, basophils, platelets | Vasodilation, ↑ permeability |
| Serotonin | Platelets | Vasoconstriction (acute) |
| Prostaglandins | COX1/2 from arachidonic acid | Pain, fever, vasodilation |
| Leukotrienes (LTB4) | LOX from arachidonic acid | Neutrophil chemotaxis |
| Leukotrienes (LTC4/D4/E4) | LOX | Bronchoconstriction, ↑ permeability |
| Bradykinin | Kallikrein-kinin system | Pain, vasodilation, ↑ permeability |
| Complement (C3a, C5a) | Liver | C5a chemotaxis; C3b opsonin |
| TNF, IL-1, IL-6 | Macrophages | **Acute-phase**, fever, leukocytosis |
| IL-8 | Macrophages | Neutrophil chemotaxis |
| NO | Endothelium, macs | Vasodilation, antibacterial |

**Arachidonic acid pathway (drug targets):**

```
Phospholipid → (phospholipase A2 — blocked by steroids)
  → Arachidonic acid → 
    COX (blocked by NSAIDs/aspirin) → PGs, TxA2
    LOX → leukotrienes (LT receptor blocked by montelukast; 5-LOX by zileuton)
```

**Acute-phase reactants (driven by IL-6):**

| ↑ | ↓ |
|---|---|
| CRP, ferritin, fibrinogen, hepcidin, serum amyloid A, complement | Albumin, transferrin |

**Hepcidin** ↑ → ↓ iron release from macrophages → **anemia of chronic disease**.

**Granulomatous inflammation (Type IV):**

| Organism | Disease |
|----------|---------|
| TB, atypical mycobacteria | TB (caseating) |
| Fungi (histo, blasto, coccidio, crypto) | Fungal granuloma |
| Treponema pallidum | Syphilitic gumma |
| Brucella, Bartonella | Brucellosis, cat-scratch |
| Schistosoma | Schistosomiasis |
| Foreign body | Suture, talc, beryllium |
| Sarcoidosis | **Non-caseating** |
| Crohn disease | Non-caseating |
| GPA (Wegener) | Necrotizing |

**Granuloma cells:** epithelioid macrophages + multinucleated giant cells + lymphocyte rim. **Th1 + IFN-γ** activates macrophages.

**Effusion types:**

| Type | Pattern | Cause |
|------|---------|-------|
| Transudate | Low protein, low LDH | ↑ hydrostatic (HF) or ↓ oncotic (cirrhosis, nephrotic) |
| Exudate | High protein/LDH | Inflammation, infection, malignancy, PE |

**Light's criteria** (any one → exudate): pleural protein/serum protein >0.5; pleural LDH/serum LDH >0.6; pleural LDH > 2/3 upper normal serum.

**Outcomes of inflammation:**

| Outcome | Setting |
|---------|---------|
| Resolution | Mild injury, intact basement membrane |
| Healing by scar | Severe injury, BM lost |
| Abscess | Pyogenic bacteria walled off |
| Chronic inflammation | Persistent stimulus |

**Common gotchas:**
- **CRP** rises faster (6-12h) and falls faster than ESR — better for **monitoring** trends
- **Sarcoid + Crohn = non-caseating**; **TB = caseating**
- **Aspirin** irreversibly acetylates COX (lasts platelet lifetime); **NSAIDs** reversible
- **Steroids** block phospholipase A2 → both PG and LT pathways → broader anti-inflammatory than NSAID
- **Anemia of chronic disease**: ↑ ferritin (storage trapped), ↓ iron, ↓ TIBC — distinguishes from IDA (↓ ferritin, ↑ TIBC)

**Rule of thumb:** Acute = neutrophils + edema; chronic = lymphocytes + fibrosis. Granuloma = Type IV with Th1-driven macrophage transformation. Exudate = inflammatory; transudate = pressure problem.
