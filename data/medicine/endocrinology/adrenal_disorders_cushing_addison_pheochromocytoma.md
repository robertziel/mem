### Adrenal Disorders

**Cushing syndrome (cortisol excess):**

| Cause | Mechanism | ACTH |
|-------|-----------|------|
| **Iatrogenic** (most common) | Exogenous steroid | ↓ |
| Cushing **disease** | Pituitary adenoma → ↑ACTH | ↑ |
| Ectopic ACTH | Small cell lung, carcinoid | **↑↑** |
| Adrenal adenoma / carcinoma | Autonomous cortisol | ↓ |
| Pseudo-Cushing | Alcohol, depression, obesity | ↑ |

**Clinical features (recognize the gestalt):**

| Feature | Why |
|---------|-----|
| Central obesity, moon face, buffalo hump | Cortisol effect |
| Purple striae, easy bruising, thin skin | Catabolic on collagen |
| Proximal weakness | Catabolism |
| HTN, glucose intolerance, hypokalemia | Mineralocorticoid + insulin resistance |
| Osteoporosis | ↓ bone formation |
| Hirsutism, irregular menses | Androgen excess (adrenal cancer) |
| Mood disorder, psychosis | Direct CNS |

**Cushing workup:**

| Step | Test |
|------|------|
| 1. Confirm hypercortisolism | **Any 2** of: 24h urine free cortisol; late-night salivary cortisol; **low-dose dexamethasone suppression test** (1 mg overnight or 2 mg × 2d) — fail to suppress |
| 2. Localize | **ACTH** — high (pituitary or ectopic) vs low (adrenal) |
| 3. Pituitary vs ectopic | **High-dose dex** (8 mg) suppresses pituitary; ectopic doesn't. **CRH stimulation** → pituitary responds, ectopic doesn't. **Inferior petrosal sinus sampling** definitive |
| 4. Imaging | MRI pituitary; CT/MRI adrenal; CT chest/abdomen for ectopic |

**Treatment:**

| Cause | Treatment |
|-------|-----------|
| Pituitary | Transsphenoidal surgery; radiation backup; pasireotide, mifepristone, ketoconazole |
| Adrenal | Adrenalectomy |
| Ectopic | Treat tumor; ketoconazole / metyrapone for cortisol control |
| Iatrogenic | Taper steroid carefully (HPA suppression) |

**Adrenal insufficiency (Addison / secondary):**

| Feature | Primary (Addison) | Secondary (pituitary / hypothalamic) |
|---------|-------------------|--------------------------------------|
| Cortisol | ↓ | ↓ |
| Aldosterone | ↓ | Normal (RAAS independent) |
| ACTH | **↑** | ↓ |
| Hyperpigmentation | **Yes** (POMC → MSH) | No |
| Hyperkalemia | Yes | No |
| Hyponatremia | Yes | Yes |
| Vol depletion | Marked | Less marked |
| Cause | Autoimmune (adrenalitis), TB, hemorrhage (Waterhouse-Friderichsen), metastases, infiltrative | Pituitary tumor, exogenous steroid stop, Sheehan |

**Diagnosis:**

| Test |
|------|
| 8 AM cortisol <3 = adrenal insufficiency; >18 rules out |
| **ACTH stimulation (cosyntropin)** — cortisol <18 at 30-60 min = adrenal insufficiency (secondary may need longer test) |
| ACTH level — primary high, secondary low |

**Adrenal crisis:**

| Trigger | Stress (infection, surgery, missed steroid) in chronic adrenal insufficiency |

**Treatment of crisis:**
1. **Hydrocortisone 100 mg IV** stat → 200 mg/24h drip
2. IVF (NS) for volume + glucose
3. Search trigger
4. Transition to oral once stable

**Chronic replacement:**

| Drug | Dose |
|------|------|
| Hydrocortisone | 15-25 mg/day, divided (more in AM) |
| Or prednisone | 3-5 mg AM |
| **Fludrocortisone** | 0.05-0.2 mg/d (only in primary AI — for aldosterone) |
| Stress dose | 2-3× usual for illness; high stress / surgery → IV hydrocortisone |

**Pheochromocytoma (catecholamine-secreting tumor):**

| Triad | Episodic headache, sweating, palpitations |
|---|---|
| Other | HTN (paroxysmal or sustained), pallor, anxiety, weight loss, hyperglycemia |

**Rule of 10's**: 10% extra-adrenal (paraganglioma), 10% bilateral, 10% malignant, 10% familial (MEN2, VHL, NF1, SDH-mutations).

**Workup:**

| Step | Test |
|------|------|
| 1 | Plasma free **metanephrines** (best initial); 24h urinary metanephrines |
| 2 | Imaging (CT/MRI adrenal, MIBG scan if no adrenal lesion) |
| 3 | Genetic testing if young / familial / multifocal |

**Treatment:**
1. **α-blockade first** (phenoxybenzamine or doxazosin) for 7-14 days
2. Then **β-blocker** (avoid β before α — unopposed α → hypertensive crisis)
3. Volume expansion + high-salt diet
4. Surgery (laparoscopic adrenalectomy) — definitive

**Hyperaldosteronism (Conn syndrome):**

| Clue | HTN + hypokalemia + metabolic alkalosis |
| Causes | Adrenal adenoma, bilateral hyperplasia |
| Screen | **Aldosterone:renin ratio (ARR) >20-30** with elevated aldosterone |
| Confirm | Salt loading / saline infusion → no suppression |
| Localize | CT adrenal + adrenal vein sampling (lateralizes) |
| Treat | Adenoma → adrenalectomy; bilateral → spironolactone or eplerenone |

**Congenital adrenal hyperplasia (most common: 21-hydroxylase deficiency):**
- Salt wasting + virilization (girls — ambiguous genitalia; boys — precocious puberty)
- Elevated 17-OH progesterone
- Treat: hydrocortisone + fludrocortisone

**Common gotchas:**
- **Don't β-block pheo first** — unopposed α-stimulation can be fatal
- **Skip cosyntropin** if patient is critical and clinical picture obvious — give stress-dose hydrocortisone (use **dexamethasone** if you must preserve test integrity, then test later)
- **Hyperpigmentation absent in secondary AI** (no ACTH overproduction)
- **Metanephrines elevation** can be from **stress, drugs (TCA, MAOI, decongestants, levodopa)** — repeat off offenders
- **Spironolactone gynecomastia** → eplerenone

**Rule of thumb:** Cushing → confirm cortisol → ACTH → high-dose dex / IPSS → image. Addison → cosyntropin → ACTH levels. Pheo: metanephrines → α-block before β-block. Conn: ARR + salt loading + adrenal vein sampling.
