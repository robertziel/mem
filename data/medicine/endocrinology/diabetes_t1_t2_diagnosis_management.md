### Diabetes — T1 vs T2

**T1 vs T2:**

| Feature | Type 1 | Type 2 |
|---------|--------|--------|
| Mechanism | Autoimmune β-cell destruction (anti-GAD, anti-IA-2, anti-insulin, anti-ZnT8) | Insulin resistance + relative insulin deficiency |
| Onset | Childhood / young adult (LADA later) | Adulthood (younger increasingly) |
| Body habitus | Often lean | Often overweight / metabolic syndrome |
| Insulin requirement | **Always** | Variable (none → full) |
| DKA | Common | Uncommon (HHS more typical) |
| C-peptide | Low | Normal / high |
| Autoantibodies | Positive | Negative |
| HLA association | DR3, DR4 | None |

**Diagnostic criteria (any one, confirmed if asymptomatic):**

| Test | Threshold |
|------|-----------|
| Fasting plasma glucose | ≥126 mg/dL |
| 2h OGTT (75g) | ≥200 mg/dL |
| Random glucose + symptoms | ≥200 mg/dL |
| **HbA1c** | ≥6.5% |

Pre-diabetes: FPG 100-125, OGTT 140-199, A1c 5.7-6.4%.

**Targets (general adult):**

| Target | Goal |
|--------|------|
| HbA1c | <7% (individualized: <6.5% if achievable safely; <8% if frail/elderly/short life expectancy) |
| Fasting glucose | 80-130 |
| Postprandial (2h) | <180 |
| BP | <130/80 |
| LDL | <70 in ASCVD; <100 otherwise |
| Albuminuria | <30 mg/g |

**T2 medications (ADA 2024-style stratified):**

| Class | Examples | Notes |
|-------|----------|-------|
| **Metformin** | — | First-line if no contraindication; weight-neutral; GI; lactic acidosis (rare); avoid if eGFR <30 |
| **GLP-1 RA** | Semaglutide, liraglutide, tirzepatide (GIP/GLP-1) | Weight loss, CV + renal benefit; nausea; pancreatitis risk |
| **SGLT2 inhibitor** | Empagliflozin, dapagliflozin, canagliflozin | CV + renal + HF benefit; UTI / GU mycotic; **euglycemic DKA**; Fournier rare |
| Sulfonylurea | Glipizide, glimepiride | Cheap; **hypoglycemia**; weight gain |
| DPP-4 inhibitor | Sitagliptin, linagliptin | Weight neutral; pancreatitis risk; less efficacy |
| Thiazolidinedione | Pioglitazone | Weight gain, edema, fracture, HF; insulin sensitizer |
| Insulin | Basal (glargine, detemir, degludec); prandial (lispro, aspart, glulisine) | Most potent; hypoglycemia, weight gain |
| α-glucosidase inhibitor | Acarbose | GI; small effect |
| Amylin analog | Pramlintide | Adjunct |

**ADA 2024 — independent of A1c, prefer based on comorbidities:**

| Comorbidity | Preferred class |
|-------------|-----------------|
| ASCVD / high risk | GLP-1 RA or SGLT2i with proven CV benefit |
| Heart failure | SGLT2i |
| CKD (proteinuria) | SGLT2i (eGFR ≥20-25) ± GLP-1 RA; finerenone |
| Need weight loss | GLP-1 RA, SGLT2i, tirzepatide |
| Cost-sensitive | Metformin + sulfonylurea + insulin |

**T1 management essentials:**

| Component | Note |
|-----------|------|
| **Insulin** (basal-bolus) or pump | Always required |
| Carb counting | Insulin-to-carb ratio + correction factor |
| CGM | Increasingly standard |
| Hypoglycemia preparedness | Glucagon kit, education, family training |

**Sick-day rules (T1)**: continue basal insulin, check ketones, hydrate, contact MD if persistent ketones / vomiting.

**Complications screening:**

| Complication | Screen |
|--------------|--------|
| Retinopathy | Annual dilated eye exam; T2 from diagnosis, T1 within 5 years |
| Nephropathy | Annual ACR + eGFR |
| Neuropathy | Annual monofilament + symptom screen |
| Foot care | Annual exam + daily self-check |
| ASCVD risk | BP, lipids, smoking, statin |

**Acute complications:**

| | DKA | HHS |
|---|------|-----|
| Type | T1 (sometimes T2) | T2 mostly |
| Glucose | Often >250, can be euglycemic on SGLT2i | **>600** |
| pH / HCO3 | Acidosis (pH <7.3, HCO3 <18) | Mild / none |
| Anion gap | High | Normal / mild |
| Ketones | High (β-hydroxybutyrate) | Minimal |
| Mental status | Variable | **Often altered, coma** |
| Treatment | IVF + insulin drip + K replacement | IVF (large volume) + insulin + K |

**Insulin pearls:**

| Insulin | Onset | Peak | Duration |
|---------|-------|------|----------|
| Lispro/aspart/glulisine | 15 min | 1-2h | 3-5h |
| Regular | 30 min | 2-4h | 5-8h |
| NPH | 1-2h | 4-12h | 12-18h |
| Glargine (Lantus) | 1-2h | flat | 22-24h |
| Detemir | 1-2h | minimal | 12-24h |
| Degludec | 1h | flat | >42h |

**Hypoglycemia:**

| Glucose | Action |
|---------|--------|
| 54-70 | Conscious — 15g carb, recheck 15 min |
| <54 | Severe; if conscious, glucose tabs/juice; if unconscious, **IM glucagon** or IV D50 |

**Common gotchas:**
- **Metformin** held for contrast / surgery if eGFR border; restart 48h
- **Euglycemic DKA on SGLT2i** — keep clinical suspicion despite normal glucose; hold for 3-4 days periop or sick days
- **A1c misleading** in: hemoglobinopathy, recent transfusion, hemolysis, iron deficiency, pregnancy → use fructosamine or CGM
- **Honeymoon period** in T1 (residual β-cell function) — don't stop insulin
- **Steroid-induced hyperglycemia** — most pronounced post-meal; cover with NPH timed to steroid

**Rule of thumb:** All T1s need insulin. T2: metformin first if appropriate, then add by comorbidity (SGLT2i for HF/CKD; GLP-1 for ASCVD/weight). DKA → IV fluids + insulin + K. Match insulin profile to needs.
