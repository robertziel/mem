### Childhood Exanthems

**Six classic "numbered" exanthems:**

| # | Disease | Pathogen | Hallmark |
|---|---------|----------|----------|
| 1 | **Measles (rubeola)** | Paramyxovirus | High fever, **3 C's** (cough, coryza, conjunctivitis), **Koplik spots**, then maculopapular rash spreading **head → toe** |
| 2 | **Scarlet fever** | Group A Strep (toxin) | "Strawberry tongue", sandpaper rash, circumoral pallor, Pastia lines, post-strep pharyngitis |
| 3 | **Rubella (German measles)** | Rubella togavirus | Mild fever, **post-auricular lymphadenopathy**, pink macular rash, Forchheimer spots palate; **fetal: TORCH (cataracts, deafness, PDA)** |
| 4 | "Filatov-Dukes" — likely staphylococcal scalded skin or atypical scarlet fever (historical) | — | — |
| 5 | **Erythema infectiosum** ("fifth disease") | **Parvovirus B19** | "Slapped cheek", lacy reticular rash on trunk; aplastic crisis in sickle cell; hydrops fetalis |
| 6 | **Roseola infantum (exanthem subitum)** | **HHV-6 / HHV-7** | High fever 3-5 days → fever **breaks** → **rash appears** (rose-pink macules, trunk first); often associated with febrile seizures |

**Other common viral exanthems:**

| Disease | Pathogen | Clue |
|---------|----------|------|
| Hand-foot-mouth | Coxsackie A16, EV-71 | Vesicles on hands, feet, mouth |
| Herpangina | Coxsackie A | Posterior pharyngeal vesicles/ulcers, fever |
| Varicella (chickenpox) | VZV | Crops of vesicles in **different stages**, intensely pruritic; fever + malaise |
| Mononucleosis | EBV | Fever + exudative pharyngitis + posterior cervical LN + splenomegaly; **rash if amox/ampi given** |
| Pityriasis rosea | HHV-6/7 (likely) | "Herald patch", Christmas-tree distribution, oval salmon plaques |
| Gianotti-Crosti | Many viral | Symmetric papules on face, buttocks, extensor extremities; resolves |
| Kawasaki disease | Idiopathic, vasculitis | See below |

**Measles essentials:**

| Item | Detail |
|------|--------|
| Incubation | 8-12 days |
| Prodrome | 3 C's, Koplik spots (small white "grains of salt" on buccal mucosa) |
| Rash | Erythematous maculopapular, head → toe, becomes confluent, fades head → toe |
| Complications | Otitis (most common), pneumonia, diarrhea, encephalitis, **subacute sclerosing panencephalitis (SSPE)** years later |
| Vitamin A | Reduces mortality in deficient children |
| Prevention | MMR vaccine (live) |
| Public health | Reportable; isolate, contact tracing |

**Scarlet fever:**

| Treatment | Penicillin or amoxicillin × 10 days |
| Why treat | Prevent rheumatic fever (PSGN not prevented by treatment) |
| Tongue | "White → strawberry" |
| Sequelae | Rheumatic fever (cardiac), PSGN (renal) |

**Varicella:**

| Item | Detail |
|------|--------|
| Lesions | Vesicles "dewdrop on rose petal", crops in different stages |
| Treatment | Supportive; **acyclovir for ≥12 yr, immunocompromised, secondary cases in household** |
| Complications | Bacterial superinfection (Strep, Staph), pneumonia, cerebellar ataxia, encephalitis, Reye if aspirin given |
| Prevention | Vaccine (live) |
| Pregnancy | VariZIG for exposed seronegatives; congenital varicella syndrome |
| Reactivation | **Zoster (shingles)** |

**Mononucleosis pearls:**

| Feature |
|---------|
| Atypical lymphocytosis (>10%), heterophile antibody (Monospot) |
| Avoid contact sports for ≥3 wk (splenic rupture) |
| Amoxicillin → maculopapular rash in ~80% (not true allergy) |

**Kawasaki disease (KD):**

| Criteria — **5 days fever + 4 of 5 (CRASH and burn):** |
|--------------------------------------------------------|
| **C**onjunctivitis (bilateral, non-purulent) |
| **R**ash (polymorphic) |
| **A**denopathy (cervical, ≥1.5 cm, often unilateral) |
| **S**trawberry tongue / red lips / oropharyngeal changes |
| **H**ands/feet (erythema, edema, periungual desquamation later) |
| Burn: prolonged fever |

| Item | Detail |
|------|--------|
| Risk | **Coronary artery aneurysms** if untreated |
| Treatment | **IVIG 2 g/kg + high-dose aspirin** (uniquely indicated in pediatrics here) |
| Imaging | Echo at diagnosis, 1-2 wk, 4-6 wk |
| Refractory | Second IVIG, infliximab, steroids |

**Pediatric viral rashes — recognition by pattern:**

| Pattern | Disease |
|---------|---------|
| Cephalocaudal spread + fever + 3 C's | Measles |
| Slapped cheek then lacy rash | Erythema infectiosum (Parvo) |
| High fever × 3-5 d → rash AS fever breaks | Roseola |
| Vesicles in crops, mucous membranes | Varicella |
| Sandpaper + strawberry tongue | Scarlet fever |
| Vesicles palms / soles / mouth | Hand-foot-mouth |
| Fever + bilateral non-purulent conj + LN + extremity changes | **Kawasaki** |

**Common gotchas:**
- **Don't give aspirin** routinely in viral illness (Reye); **Kawasaki is the exception**
- **Amoxicillin in mono** = morbilliform rash (drug + viral interaction; not true allergy)
- **Parvovirus B19** in pregnancy → fetal hydrops; in sickle cell → aplastic crisis
- **Measles is highly contagious** (R0 12-18) — airborne precautions
- **MMR / varicella** are live vaccines — avoid in immunocompromised, pregnancy
- **Children of mothers with VZV** at birth (5 days before to 2 days after) → VariZIG to neonate
- **Streptococcal pharyngitis treatment** does prevent rheumatic fever but **not PSGN**

**Rule of thumb:** Pattern of fever and rash narrows it. Cephalocaudal + 3 C's + Koplik = measles. Slapped cheek = parvo. Fever then rash = roseola. Vesicles in crops = varicella. CRASH and burn = Kawasaki → IVIG + aspirin.
