### Neonatal Resuscitation & Initial Assessment

**Apgar score (1 + 5 min, sometimes 10):**

| Sign | 0 | 1 | 2 |
|------|---|---|---|
| **A**ppearance | Blue/pale | Body pink, extremities blue | Pink |
| **P**ulse | Absent | <100 | ≥100 |
| **G**rimace (reflex) | None | Grimace | Cough/sneeze/cry |
| **A**ctivity (tone) | Limp | Some flexion | Active |
| **R**espiration | Absent | Slow/irregular | Strong cry |

**Apgar is descriptive, not used to direct resuscitation** (which starts at <30 sec if needed). Persistent low scores (<5 at 5+ min) → consider hypoxic-ischemic encephalopathy, cooling protocol if ≥36 wk.

**Initial steps — newborn algorithm (NRP, simplified):**

| Step | Detail | Time |
|------|--------|------|
| 1. Initial assessment | Term? Tone? Crying/breathing? | <30 sec |
| 2. If yes to all | Routine care: dry, warm, skin-to-skin, delayed cord clamp ≥30-60 sec |
| 3. If no to any | Warm, dry, stimulate, position airway, suction if obstructed |
| 4. Reassess at 30 sec | HR + breathing + color |
| 5. **If HR <100, apnea, or gasping** | **Positive pressure ventilation** (PPV) with room air (term) or 21-30% (preterm <35 wk) |
| 6. If HR <60 despite 30 sec PPV | **Chest compressions (3:1)** + intubate + 100% O2 |
| 7. If HR <60 after 60 sec compressions | **Epinephrine** IV/IO (preferred) or ETT |
| 8. Volume expansion | NS 10 mL/kg if hypovolemia / poor response |

**Cord clamping:**

| Time | Effect |
|------|--------|
| Immediate (<30 sec) | Was traditional; less Hb to baby |
| **Delayed (≥30-60 sec)** | Recommended in vigorous term + preterm — ↓ IVH, ↑ iron stores |

**Newborn vitals (term):**

| Vital | Range |
|-------|-------|
| HR | 110-160 |
| RR | 30-60 |
| BP varies | Mean ≈ gestational age in wk for first day |
| SpO2 | Slowly rises; **at 10 min ≥85% preductal** |
| Temp (axillary) | 36.5-37.5°C |

**SpO2 target by minute (NRP):**

| Minute | Target SpO2 (preductal, right hand) |
|--------|--------------------------------------|
| 1 | 60-65% |
| 2 | 65-70% |
| 3 | 70-75% |
| 4 | 75-80% |
| 5 | 80-85% |
| 10 | 85-95% |

**Newborn screening (US standard):**

| Category | Examples |
|----------|----------|
| Metabolic / endocrine | PKU, MSUD, organic acidemias, fatty acid oxidation, MCAD, congenital hypothyroidism, CAH, galactosemia |
| Hemoglobinopathies | Sickle cell, thalassemia |
| CF | IRT |
| **Critical congenital heart disease** | Pulse oximetry pre/post-ductal (≥3% diff or both <95% → echo) |
| Hearing | OAE / ABR |
| Bilirubin | Risk-based, transcutaneous / serum |
| Newer | SCID (TREC), SMA, Krabbe, ALD (state-dependent) |

**Vitamin K + erythromycin + Hep B:**

| | When |
|---|------|
| **Vitamin K IM** | Within 6h — prevent hemorrhagic disease of newborn |
| **Erythromycin eye ointment** | Prevent gonococcal ophthalmia |
| **Hep B vaccine #1** | Within 24h |

**Common immediate concerns:**

| Issue | Detail |
|-------|--------|
| Meconium-stained amniotic fluid | If non-vigorous → routine resuscitation **without intubation for suction** (current NRP) |
| Hypoglycemia | At-risk: SGA/LGA, infant of diabetic mother, preterm; check ≥2h, treat <40-45 |
| Respiratory distress | TTN (transient tachypnea), RDS (preterm, surfactant), MAS, sepsis, congenital heart |
| Cyanosis | Differential cyanosis (pre/post-ductal split) → coarc, interrupted arch with PDA |
| Hypothermia | Polyethylene wrap, warmed blankets, kangaroo |
| **Hypoxic-ischemic encephalopathy (HIE)** | Cooling protocol if ≥36 wk + criteria; 33-34°C × 72h within 6h |

**Jaundice:**

| Type | Time | Cause |
|------|------|-------|
| Physiologic | 2-3 days, peak day 5 | Immature UGT |
| Pathologic | <24h | **Hemolysis** (ABO, Rh, G6PD), sepsis |
| Breastfeeding jaundice | First week, dehydration | Inadequate intake |
| Breast milk jaundice | After first week, persists | Substance in milk inhibiting bilirubin metabolism |

| Treatment | Detail |
|-----------|--------|
| Phototherapy | Threshold by hour-specific nomogram |
| Exchange transfusion | Severe / signs of bilirubin encephalopathy |

**Common gotchas:**
- **Apgar doesn't direct resuscitation** — start before the 1-min score
- **HR <100 is the threshold to start PPV** — don't wait for cyanosis or apnea
- **Most babies need only stimulation** — most resuscitation is breathing support, rarely compressions/epi
- **Cooling for HIE** within 6h of birth — narrow window, high impact on neuro outcome
- **Critical CHD pulse ox screening** at 24h — small SpO2 differences matter
- **Hep B vaccine within 24h** for HBsAg+ moms — also HBIG; for unknown status — give vaccine within 12h, give HBIG if mother positive
- **Group B strep** — IV penicillin to mother in labor; if mom inadequately treated → observe newborn ≥48h

**Rule of thumb:** Term + tone + crying → routine + skin-to-skin + delayed clamp. HR <100 / apnea → PPV with room air. HR <60 after PPV → compressions + intubate. Vit K + Hep B + erythromycin universally. HIE → cool within 6h.
