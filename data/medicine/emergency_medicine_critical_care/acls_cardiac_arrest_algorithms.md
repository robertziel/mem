### ACLS — Cardiac Arrest Algorithms

**Two arrest rhythm groups:**

| Shockable | Non-shockable |
|-----------|---------------|
| **VF** (ventricular fibrillation) | **PEA** (pulseless electrical activity) |
| **Pulseless VT** | **Asystole** |

**BLS first** — recognize arrest, call for help, **start CPR** (push hard, push fast, allow recoil), AED.

**CPR quality:**

| Metric | Target |
|--------|--------|
| Rate | 100-120/min |
| Depth | 5-6 cm (2-2.4 in) adult |
| Recoil | Full chest recoil between compressions |
| Interruptions | Minimize (<10 sec to check pulse, switch) |
| Compression-ventilation ratio (no advanced airway) | 30:2 |
| With advanced airway | Continuous compressions + 1 breath every 6 sec |

**Shockable rhythm algorithm (VF / pulseless VT):**

| Step | Action |
|------|--------|
| 1 | **Defibrillate** (biphasic 120-200 J or device-recommended) |
| 2 | Resume CPR immediately × 2 min |
| 3 | Rhythm check |
| 4 | Defibrillate again if shockable |
| 5 | **Epinephrine 1 mg IV/IO** every 3-5 min — start after 2nd shock |
| 6 | Resume CPR × 2 min |
| 7 | If still shockable: **Amiodarone 300 mg IV/IO** (or lidocaine); 2nd dose 150 mg |
| 8 | Throughout: **search reversible causes (H's and T's)** |

**Non-shockable algorithm (PEA / asystole):**

| Step | Action |
|------|--------|
| 1 | CPR × 2 min |
| 2 | **Epinephrine 1 mg IV/IO** ASAP (then every 3-5 min) |
| 3 | Rhythm check every 2 min |
| 4 | If becomes shockable → defibrillate |
| 5 | **Search reversible causes** |
| 6 | Continue until ROSC, asystole >20 min, or termination criteria |

**Reversible causes — H's and T's:**

| H's | T's |
|-----|-----|
| Hypoxia | **Tension** pneumothorax |
| Hypovolemia | **Tamponade** (cardiac) |
| Hydrogen ion (acidosis) | **Toxins** (drugs) |
| Hyper/hypo-K | **Thrombosis (PE)** |
| Hypothermia | **Thrombosis (MI)** |
| Hypoglycemia | Trauma |

**Airway management:**
- Bag-mask ventilation initially
- Advanced airway (SGA or ETT) if needed; **don't interrupt compressions** for placement >10 sec
- ETCO2 (end-tidal CO2) is the **best monitor of CPR quality and ROSC** (sudden ↑ to >40 = ROSC)

**Vascular access:**
- **IV first**, **IO if not quickly available** (humeral or tibial)
- Central line **not** required during arrest

**Drugs in arrest:**

| Drug | Dose | Notes |
|------|------|-------|
| Epinephrine | 1 mg IV/IO every 3-5 min | All arrests; earlier in non-shockable |
| Amiodarone | 300 mg, then 150 mg | Refractory shockable |
| Lidocaine | 1-1.5 mg/kg, then 0.5-0.75 | Alternative to amiodarone |
| Magnesium | 1-2 g IV | Torsades only (not routine) |
| Calcium | 1 g | Hyperkalemia, hypocalcemia, CCB OD |
| Bicarbonate | 1 mEq/kg | TCA OD, severe acidosis, hyperkalemia (situational) |

**Bradycardia algorithm (with pulse):**

| Step | Detail |
|------|--------|
| Stable | Monitor, treat cause |
| **Unstable (hypotension, altered MS, ischemic chest pain, HF)** | **Atropine 1 mg IV** (max 3 mg) → if ineffective: **transcutaneous pacing**, **dopamine 5-20 mcg/kg/min** or **epinephrine 2-10 mcg/min** drip, **transvenous pacing** |
| Refractory | Treat cause (β-blocker / CCB OD → Ca + glucagon + insulin/dextrose); pace |

**Tachycardia algorithm (with pulse):**

| Stable / unstable? |
|---------------------|
| **Unstable + tachy** → **synchronized cardioversion** (or defib if pulseless / VF) |

| Stable | Detail |
|--------|--------|
| **Narrow + regular** (SVT) | Vagal maneuvers → adenosine 6 mg → 12 mg → CCB or β-blocker |
| Narrow + irregular (AF) | Rate or rhythm control; anticoagulation per CHA₂DS₂-VASc; cardiovert if <48h or TEE/anticoag-protected |
| **Wide + regular** | Could be VT; if stable → amiodarone; if rule-out SVT with aberrancy → adenosine cautious; if unstable → cardiovert |
| Wide + irregular | AF with WPW or polymorphic VT — avoid AV-blockers |

**Torsades de pointes:**

| Cause | QT prolongation (drugs, electrolyte) |
| Treat | **Magnesium 2 g IV**, correct electrolytes, stop offending drugs, overdrive pacing if recurrent; defibrillate if pulseless |

**Post-cardiac arrest care:**

| Goal | Detail |
|------|--------|
| Airway | Secure; **avoid hyperventilation** |
| Oxygenation | Target SpO2 92-98% (avoid hyperoxia) |
| BP | MAP ≥65 with vasopressors; norepi |
| **Targeted temperature management** | 32-36°C × 24h for comatose post-ROSC; rewarm slowly |
| Coronary angiography | STEMI → emergent; consider in shockable arrest without obvious non-cardiac cause |
| Glucose | 140-180 |
| Treat cause | — |
| **Neuroprognosis** ≥72h | Avoid early withdrawal |

**Ineffective / stop CPR criteria (general):**

| Consider termination |
|----------------------|
| 20+ min asystole without ROSC, no reversible cause |
| End-tidal CO2 <10 after 20 min |
| Witnessed arrest, no shockable rhythm, prolonged downtime |
| Family / advance directive considerations |

**Common gotchas:**
- **High-quality, uninterrupted CPR** is the #1 predictor of ROSC and outcome
- **Defibrillate first** in shockable rhythm — every minute delayed reduces survival ~10%
- **Epi early** in non-shockable but **after 2nd shock** in shockable (recent guideline trend)
- **Don't** routinely give bicarb / Ca / atropine in asystole/PEA
- **ETCO2 sudden rise** = ROSC; **persistent <10** = poor prognosis
- **Hypothermia / drowning / drug OD** — extended resuscitation reasonable
- **Pulseless VT = treat as VF** (defibrillate, not cardiovert)

**Rule of thumb:** Shockable → shock + CPR + epi after 2nd shock + amiodarone for refractory. Non-shockable → CPR + epi early. Always search H's and T's. Post-ROSC: TTM, MAP ≥65, avoid hyperventilation/hyperoxia, coronary angio if appropriate.
