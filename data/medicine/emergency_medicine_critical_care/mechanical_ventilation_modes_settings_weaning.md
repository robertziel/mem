### Mechanical Ventilation

**Indications for intubation:**

| Indication |
|-----------|
| Failure to oxygenate (PaO2 <60 on max non-invasive support) |
| Failure to ventilate (rising PaCO2, acidosis, fatigue) |
| Inability to protect airway (GCS, secretions) |
| Need for sedation / paralysis |
| Anticipated deterioration (transport, procedure) |

**Common modes:**

| Mode | Description |
|------|-------------|
| **Volume A/C (VC)** | Set tidal volume + RR; every breath delivers full Vt; pressure varies with compliance |
| **Pressure A/C (PC)** | Set inspiratory pressure + RR; volume varies with compliance |
| **PRVC** | Targets volume but pressure-controlled; auto-adjusts |
| **SIMV** | Synchronized intermittent mandatory; spontaneous breaths in between |
| **PS (Pressure Support)** | Patient-triggered, pressure-supported; used for weaning |
| **CPAP** | No support, just PEEP; weaning |
| **APRV / BiLevel** | Inverse-ratio with brief release; refractory hypoxemia |
| **NIV (BiPAP / CPAP)** | Non-invasive; first-line for COPD exacerbation, cardiogenic pulm edema |

**Initial settings (typical adult):**

| Setting | Starting value |
|---------|---------------|
| Mode | VC A/C |
| Tidal volume | **6-8 mL/kg ideal body weight** (4-6 mL/kg in ARDS — lung-protective) |
| RR | 12-16 |
| FiO2 | Start 100%, wean to keep SpO2 ≥92% (88-92% in COPD) |
| PEEP | 5; titrate higher in ARDS / hypoxemia |
| I:E ratio | 1:2 (longer expiration in obstructive disease) |

**Lung-protective ventilation (ARDS, NEJM ARMA):**

| Parameter | Target |
|-----------|--------|
| Tidal volume | **6 mL/kg IBW** |
| Plateau pressure | **<30 cm H2O** |
| Driving pressure | <15 cm H2O |
| PEEP / FiO2 | Higher PEEP table for moderate-severe ARDS |
| Permissive hypercapnia | Allow pH ≥7.15-7.20 |
| Prone positioning | Severe ARDS (P/F <150) — mortality benefit |
| **Neuromuscular blockade** | Severe ARDS short-term (controversial) |

**Berlin ARDS criteria:**

| Criterion |
|-----------|
| Onset within 1 wk of insult |
| Bilateral opacities on CXR/CT not explained by HF |
| Not fully explained by cardiac failure / fluid overload |
| **PaO2/FiO2 ratio**: mild <300, moderate <200, severe <100 (with PEEP ≥5) |

**Two oxygenation problems:**

| Problem | Adjust |
|---------|--------|
| Low SpO2 | ↑ FiO2, ↑ PEEP, recruitment maneuvers, prone, paralyze |
| High PaCO2 | ↑ RR, ↑ Vt (within plateau limits), ↓ instrumental dead space |

**Auto-PEEP (intrinsic PEEP):**
- Patient can't fully exhale before next breath (obstructive disease)
- Worsens hypotension, barotrauma
- **Disconnect** patient from vent → check for return to baseline; fix by ↑ expiratory time, ↓ RR, ↓ Vt, treat bronchospasm

**Common ventilator alarms:**

| Alarm | Causes |
|-------|--------|
| **High pressure** | Bronchospasm, mucus plug, pneumothorax, tube biting / kinking, asynchrony, ↓ compliance |
| Low pressure / volume | Disconnect, leak, cuff issue, extubation |
| High RR | Pain, hypoxia, agitation, fever, acidosis |
| Low MV | Sedation, neuro |

**Weaning readiness (SBT):**

| Criteria |
|----------|
| FiO2 ≤40%, PEEP ≤5 |
| Hemodynamically stable |
| Adequate cough, secretions manageable |
| Mental status / following commands |
| No active infection requiring high support |

**Spontaneous breathing trial (SBT):**
- 30-120 min on PS 5-8 + PEEP 5 (or T-piece)
- **RSBI** = RR / Vt(L); **<105 predicts success**
- Failure: tachypnea, ↓SpO2, agitation, HR/BP swings, pCO2 ↑

**Sedation / analgesia:**

| Goal | Detail |
|------|--------|
| Light sedation | RASS −1 to 0 |
| Daily sedation interruption ("sedation vacation") | Improves outcomes |
| Pain first | Fentanyl, hydromorphone |
| Sedation | Propofol (short t½, hypotension, **PRIS** in high-dose), dexmedetomidine (no respiratory depression), midazolam (avoid prolonged) |

**Ventilator-associated complications:**

| Complication | Detail |
|--------------|--------|
| **VAP (ventilator-associated pneumonia)** | Bundles to prevent: HOB 30-45°, oral care chlorhexidine, sedation interruption, DVT/stress prophylaxis, daily SBT |
| **VTE** | Prophylaxis |
| GI bleed | PPI / H2 blocker if at risk |
| Pressure injury | Repositioning, skin care |
| **Barotrauma / pneumothorax** | High plateau, asynchrony |
| Auto-PEEP | See above |
| Delirium | Dexmedetomidine, daily reorientation, ABCDEF bundle |

**Extubation:**

| Step | Detail |
|------|--------|
| Pass SBT | — |
| Cuff leak test | If concern for laryngeal edema |
| Suction | — |
| Coordinate with team | Have reintubation supplies ready |
| Post-extubation | Watch for stridor, work of breathing, oxygenation |

**Common gotchas:**
- **Lung-protective Vt is by IBW not actual** — heavy ARDS patient still gets 6 mL/kg of ideal weight
- **High plateau >30** = barotrauma risk; ↓ Vt, accept hypercapnia
- **Asynchrony** is common — adjust trigger, flow, mode
- **Permissive hypercapnia** is acceptable as long as pH >7.15-7.20
- **Auto-PEEP** mimics tension pneumothorax — disconnect to confirm
- **Sedation interruption** + minimal sedation reduces ICU LOS and delirium
- **Don't extubate** without protected airway / cough

**Rule of thumb:** Vt 6-8 mL/kg IBW (6 in ARDS); plateau <30; PEEP 5+; FiO2 to SpO2 92-98% (88-92% COPD). NIV first for COPD/CPE. Daily SBT + sedation interruption. Lung-protective + prone + paralysis for severe ARDS.
