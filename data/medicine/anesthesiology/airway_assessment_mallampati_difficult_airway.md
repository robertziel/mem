### Airway Assessment & Difficult Airway

**Pre-induction airway assessment — LEMON:**

| Letter | Item |
|--------|------|
| **L** | **Look** externally — facial trauma, beard, large incisors, large tongue, edema |
| **E** | **Evaluate 3-3-2** rule (mouth opens 3 finger-breadths, hyoid-mentum 3, hyoid-thyroid 2) |
| **M** | **Mallampati** class |
| **O** | **Obstruction** (epiglottitis, foreign body, mass, edema) |
| **N** | **Neck mobility** (cervical spine, RA, ankylosing spondylitis, trauma) |

**Mallampati classification (mouth open, tongue out, no phonation):**

| Class | Visible structures |
|-------|--------------------|
| I | Soft palate, uvula, pillars |
| II | Soft palate, part of uvula |
| III | Soft palate, base of uvula |
| IV | Hard palate only |

Class III/IV → higher risk of difficult intubation.

**Difficult mask ventilation predictors (BONES):**

| Letter | Item |
|--------|------|
| B | Beard |
| O | Obese (BMI >26) |
| N | No teeth |
| E | Elderly (>55) |
| S | Snorers / OSA |

**Difficult laryngoscopy/intubation predictors:**

| Item |
|------|
| Mallampati III-IV |
| Short thyromental distance (<6 cm) |
| Restricted neck mobility (chin-to-chest, occiput-to-wall) |
| Limited mouth opening (<3 cm) |
| Receding mandible / micrognathia |
| Large tongue, prominent incisors |
| Prior difficult intubation |
| Anatomic syndromes (Pierre Robin, Treacher Collins, Down) |
| Burns, radiation, neck mass, recent surgery |

**ASA physical status (preoperative risk):**

| Class | Description |
|-------|-------------|
| I | Normal healthy |
| II | Mild systemic disease (well-controlled HTN, mild lung disease) |
| III | Severe systemic disease (poorly controlled DM, COPD on O2) |
| IV | Severe disease, constant threat to life (recent MI, severe valvular) |
| V | Moribund — not expected to survive without operation |
| VI | Brain-dead, organ donor |
| **E** | Emergency added to any |

**Preoxygenation:**

| Goal |
|------|
| 3 min tidal volume breaths or 8 vital capacity breaths of 100% O2 |
| Extends safe apnea time |
| Especially important in children, obese, pregnant, critically ill |

**Apneic oxygenation** — nasal cannula 15 L/min during intubation extends safe apnea time.

**Rapid sequence intubation (RSI):**

| Step | Detail |
|------|--------|
| Preoxygenate | 100% O2 |
| Pretreatment (selective) | Lidocaine, fentanyl |
| Induction | Etomidate, ketamine, propofol |
| Paralysis | **Succinylcholine** (rapid; 1 mg/kg) or **rocuronium** (1.2 mg/kg) |
| Pass tube, confirm with ETCO2 | — |
| Post-intubation sedation + analgesia | Propofol/dexmedetomidine + fentanyl |

**Induction agents:**

| Agent | Pros | Cons |
|-------|------|------|
| **Propofol** | Smooth, rapid; antiemetic | **Hypotension** (esp. hypovolemic) |
| **Etomidate** | Hemodynamically neutral | **Adrenal suppression** (single dose effect uncertain) |
| **Ketamine** | Bronchodilation, analgesia, preserves BP | ↑ HR/BP, emergence delirium, ↑ secretions; relative contraindication in ↑ICP and ↑IOP (debated) |
| Midazolam | Amnesia | Hypotension, slower onset |

**Neuromuscular blockers:**

| Drug | Class | Onset / duration | Caution |
|------|-------|------------------|---------|
| **Succinylcholine** | Depolarizing | 30-60 sec / 5-10 min | **Hyperkalemia** (burns, denervation, crush, prolonged immobility, MS, MD); **malignant hyperthermia trigger**; ↑ICP/IOP transient; bradycardia (kids); pseudocholinesterase deficiency (prolonged) |
| **Rocuronium** | Non-depolarizing | 1-2 min / 30-60 min | Reversible with **sugammadex** |
| Vecuronium, cisatracurium | Non-depolarizing | Slower | Cisatracurium for renal/hepatic failure (Hofmann elimination) |

**Reversal of NMB:**

| Drug | Detail |
|------|--------|
| Neostigmine + glycopyrrolate | Acetylcholinesterase inhibitor + antimuscarinic; for non-depolarizing once spontaneous recovery starts |
| **Sugammadex** | Encapsulates rocuronium / vecuronium — rapid full reversal; **OCP interaction** (use backup) |

**Failed airway algorithm:**

| Step | Action |
|------|--------|
| Cannot intubate, can ventilate | Ventilate, attempt again with different tools (video laryngoscope, SGA, fiberoptic), wake up patient if elective |
| Cannot intubate, **cannot ventilate (CICV)** | Supraglottic airway → if fails → **emergency cricothyroidotomy** |
| Awake fiberoptic intubation | For known severely difficult airway |

**Extubation criteria:**

| Criterion |
|-----------|
| Awake / responds to commands |
| Strong cough / gag |
| Adequate spontaneous tidal volume |
| TOF ≥0.9 (full reversal of NMB) |
| Hemodynamic stability |
| Adequate gas exchange |
| No risk of laryngeal edema (cuff leak test if concern) |

**NPO guidelines (elective):**

| Intake | Hours before |
|--------|--------------|
| Clear liquids | 2 |
| Breast milk | 4 |
| Light meal / formula / non-human milk | 6 |
| Heavy / fatty meal | 8 |

**Common gotchas:**
- **Succinylcholine hyperkalemia** in burns, denervation, prolonged immobility, neuromuscular disease — fatal
- **Etomidate adrenal suppression** — bolus dose effect on outcomes uncertain; many still use, especially in unstable patients
- **Ketamine** — often best choice in shock / asthma; debated in ICP / IOP
- **Sugammadex + OCP** → reduced contraceptive efficacy
- **Cricothyroidotomy** for CICV — practice the technique; don't delay
- **Difficult airway cart** at the bedside for high-risk patients
- **Awake fiberoptic** if anatomy or comorbidity demands

**Rule of thumb:** LEMON / Mallampati / 3-3-2 / BONES screen before induction. Preoxygenate. Etomidate or ketamine if unstable; propofol if stable. Succinylcholine vs rocuronium; sugammadex reverses roc rapidly. CICV → cric. Always have backup plan.
