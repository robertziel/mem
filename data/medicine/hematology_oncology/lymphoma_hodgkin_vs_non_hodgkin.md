### Lymphoma — Hodgkin vs Non-Hodgkin

**Compare:**

| Feature | Hodgkin (HL) | Non-Hodgkin (NHL) |
|---------|-------------|-------------------|
| Cell | **Reed-Sternberg** ("owl-eye") on background | B (~85%) or T cell |
| Distribution | Localized, **contiguous nodal spread** | Often disseminated, extranodal common |
| Age | Bimodal: 20s, 60s | Increasing with age |
| EBV link | ~40% (mixed cellularity, lymphocyte-depleted) | Some subtypes (Burkitt, primary CNS in HIV) |
| Mediastinal mass | Common (esp. nodular sclerosing) | Sometimes |
| B symptoms | Common: fever, night sweats, weight loss >10%/6mo, **pruritus, alcohol-induced pain** | Variable |
| Cure rate | High (early ~90%, advanced ~70%) | Subtype-dependent (40-90%) |

**Hodgkin subtypes:**

| Subtype | Frequency | Clue |
|---------|-----------|------|
| Nodular sclerosing | ~70% | Young women, mediastinal mass; lacunar cells |
| Mixed cellularity | ~20% | EBV+ in many; older, immunocompromised |
| Lymphocyte-rich | ~5% | Best prognosis classic |
| Lymphocyte-depleted | <1% | Worst prognosis classic; often HIV |
| Nodular lymphocyte-predominant | ~5% | Distinct entity, "popcorn cells", CD20+ — treated more like indolent NHL |

**Reed-Sternberg cell:** CD15+, CD30+, CD20−, CD45−.

**NHL — high-yield subtypes:**

| Subtype | Cell | Behavior | Genetics / clue |
|---------|------|----------|-----------------|
| **Diffuse large B-cell (DLBCL)** | B | **Aggressive but curable** | Most common adult NHL; R-CHOP |
| **Burkitt** | B | **Very aggressive** | t(8;14) c-MYC; African (jaw), HIV (abdominal); "starry sky" histology; high TLS risk |
| **Follicular** | B | **Indolent** | t(14;18) BCL2; waxing/waning; can transform → DLBCL |
| **Mantle cell** | B | Aggressive but slow | t(11;14) cyclin D1; older men |
| **Marginal zone (MALT)** | B | Indolent | H. pylori (gastric MALT), Sjögren |
| **CLL / SLL** | B | Indolent | (Same disease as CLL — see leukemia) |
| **Hairy cell** | B | Indolent | TRAP+, dry tap, splenomegaly, pancytopenia |
| **Adult T-cell leukemia/lymphoma (ATLL)** | T | Aggressive | **HTLV-1**; Caribbean, Japan; hypercalcemia, lytic bone, "flower cells" |
| **Mycosis fungoides → Sézary** | T | Cutaneous → leukemic | Skin patches/plaques → tumors → blood; CD4+ |
| **Primary CNS lymphoma** | B | Aggressive | Often EBV+ in HIV |

**Lugano (formerly Ann Arbor) staging:**

| Stage | Extent |
|-------|--------|
| I | Single nodal region |
| II | ≥2 regions same side of diaphragm |
| III | Both sides of diaphragm |
| IV | Disseminated (BM, liver, lung) |

**B symptoms** (one suffix to stage): **fever >38°C, drenching night sweats, ≥10% weight loss in 6 months**.

**Workup:**

| Step | Test |
|------|------|
| 1 | Excisional lymph node biopsy (NOT FNA — needs architecture) |
| 2 | Immunohistochemistry, flow, FISH |
| 3 | PET-CT (staging + response) |
| 4 | Bone marrow biopsy in selected (DLBCL with PET-negative may skip) |
| 5 | LDH, β2-microglobulin (prognosis) |
| 6 | LP if CNS risk (HIV, Burkitt, testicular, double-hit DLBCL) |
| 7 | Echo before anthracycline; HBV / HCV / HIV before rituximab |

**Treatment overview:**

| Disease | First-line |
|---------|-----------|
| Hodgkin (early) | ABVD ± involved-site radiation |
| Hodgkin (advanced) | ABVD or BV-AVD (brentuximab vedotin); escalated BEACOPP in selected |
| DLBCL | R-CHOP × 6 (rituximab + cyclophosphamide, doxorubicin, vincristine, prednisone); pola-R-CHP for high IPI |
| Burkitt | DA-EPOCH-R or hyper-CVAD with CNS prophylaxis; **TLS prophylaxis essential** |
| Follicular | Watchful waiting if low burden; rituximab ± chemo if treating; obinutuzumab |
| Mantle cell | Intensive chemo + rituximab + autoSCT for fit; ibrutinib (BTK) |
| MALT (gastric) | **Treat H. pylori** — many regress |
| CNS lymphoma | High-dose methotrexate-based; HD-MTX/rituximab |
| Mycosis fungoides | Skin-directed (steroid, PUVA); systemic later (bexarotene, brentuximab, mogamulizumab) |
| Relapsed/refractory aggressive B-cell | **CAR-T (axicabtagene, lisocabtagene)**, autoSCT |

**Common toxicities to remember:**

| Drug | Toxicity |
|------|----------|
| Doxorubicin | Cardiomyopathy (cumulative dose) |
| Bleomycin | Pulmonary fibrosis |
| Vincristine | Peripheral neuropathy |
| Cyclophosphamide | Hemorrhagic cystitis (mesna), infertility |
| Rituximab | Infusion reactions; HBV reactivation (screen); PML rare |
| BTK inhibitors | Bleeding, AF, HTN |
| CAR-T | **Cytokine release syndrome (CRS)** → tocilizumab; ICANS (neurotoxicity) |

**Common gotchas:**
- **Excisional biopsy** preferred — FNA is inadequate for lymphoma diagnosis
- **Hodgkin's pruritus and alcohol-induced pain** — uncommon but distinctive
- **Burkitt = TLS** — anticipate, prevent (rasburicase, hydration)
- **Mediastinal mass + young female** = Hodgkin nodular sclerosing or primary mediastinal B-cell lymphoma
- **HBV reactivation** with rituximab (or any anti-CD20) — screen and treat / prophylax with entecavir or tenofovir
- **Bleomycin** total dose limit; check baseline DLCO; avoid 100% O2 long-term

**Rule of thumb:** Hodgkin → contiguous, RS cells, curable. NHL → variable. DLBCL = most common, R-CHOP. Burkitt = TLS prep. Follicular = indolent. MALT = treat H. pylori first. Excisional biopsy + PET + IHC.
